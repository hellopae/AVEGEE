- Repairs: non-special stations with `fire > 0`, completed construction and no repair in progress. Button uses the existing `canRepair` and `repairStation`; absent workers/enemies disable it. Existing 28A horizontal viewport clamp remains in use. Repair button replaces that station's entry action while damaged; clicking the building can still enter it.
- Room: `ROOM_EXIT_REACH = 0.10` in normalized scene-image coordinates. Each active room's configured bottom entrance (`room.me`, including zone/ui4 overrides in `src/data.js`) is its default exit. Override a scene in `ROOM_EXITS[station][zone] = {x, y, reach}` in `src/proximity.js`, or supply `room.exit` in room data. Exit position follows the player and clamps horizontally within the canvas; it hides away from the exit or while a minigame is open. Native dialog Esc remains available.
- Desktop card: maximum `22cqw`, smaller heading/body/padding; compact mobile card. Exit touch target is at least 44px high.
- Speech bubble: 8 × map scale font, maximum width 180 × map scale, height 16 × map scale; text constrained to bubble width. Build label fonts 15/11 × map scale, height 44 × map scale.
- Special exceptions: existing interior close/repair/action buttons for `tarang` and `sawan` remain; no prison/heaven or combat logic changed. Shared description card sizing applies to them.
