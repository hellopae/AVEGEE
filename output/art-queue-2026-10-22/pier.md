## วิธีทำและส่วนที่ต่างจากวิธีตัวอย่าง

- อ่านสเปกทั้งไฟล์ ทำเฉพาะชิ้นที่ 2 ใช้ working directory ที่ได้รับ ไม่สร้างหรือสลับ branch/worktree
- วัดต้นทางจริงก่อนวาด ขนาด chunk และ crop ตรงสเปก ค่าเดิมของขอบบันไดเป็นค่าประมาณ จึงใช้แถบเดิน x 752–886, y 128–251 เป็นเป้าหมายแทนการยึดทรงเบี้ยวเดิม
- โมเดลคืน 1442×1091 และตำแหน่งคลาด จึง normalize แนวนอนและแบ่งช่วงแนวตั้งให้บันไดเริ่ม y128 ดาดฟ้าเริ่ม y195 ขอบหน้าที่ y251 และฐาน y298 พิกัดการแปลงอยู่ใน `pier/verification.json`
- Composite ราวจากด้านซ้ายของภาพที่โมเดลวาดแบบสะท้อนอีกด้าน ให้เสาและราวมีทรงเดียวกันรอบแกน x818 (เป้าหมาย x819 ±4) ไม่สะท้อนภาพพื้นหลังเดิม
- โมเดลให้ขั้นบันไดชัดเจนเพียง 4 ช่วง จึง composite ช่วงหินที่โมเดลวาดเป็น 5 ขั้นภายใน y128–195 ขอบช่วง y128,141,155,168,182,195 รายละเอียดใน JSON ไม่วาดหินทดแทนด้วยโค้ด
- ใช้มาสก์ polygon ตามแนวท่าเดิมและท่าใหม่ feather 1.5 px แทนวงรี blur 3–4 px เพื่อลดผลกระทบต่อน้ำ/โขดหิน รวมจุดเสาทองเดิมที่ต้องลบ น้ำในช่องที่ท่าเดิมเคยบังจำเป็นต้องเติมจากภาพ generated; จึงไม่อ้างว่าน้ำภายในขอบแก้ไขทุกพิกเซลคงเดิม
- ภายนอกมาสก์และนอกกล่อง [630,60,1000,340] เท่าต้นฉบับทุกพิกเซลเมื่ออ่าน WebP กลับ มีพิกเซลเปลี่ยน 41,665 จุด ขอบเขตแบบปลายไม่รวม [712,92,941,308] ไม่มีการเปลี่ยนภาพอื่น
- พื้นหินทราย ราวหินเข้มแถบทองและยอดทองเทียบด้วยตากับสะพานหลักที่ 200% แล้ว ใกล้เคียงวัสดุและสีเดิม งานนี้ยังไม่ได้ตรวจในเกม และไม่ได้วัดมุมเอียงจากขอบภาพแบบอัตโนมัติ จึงให้ภาพขยายสำหรับ Toby ตรวจเกณฑ์ ≤2° และความกว้าง ±4 px อีกครั้ง

## การตรวจและเกณฑ์รับงาน

1. **ไฟล์ปลายทาง/ขนาด:** มี WebP ใหม่ 1024×1024 RGB lossless อ่านกลับด้วย PIL; ต้นทาง SHA256 ตรง HEAD
2. **README ชิ้นนี้:** มีรายชื่อไฟล์ ขนาดจริง prompt ที่ใช้ เหตุผลการปรับ ภาพก่อน/หลัง diff mask และ JSON
3. **ขอบเขตไฟล์:** ตรวจ git status ว่ามีเฉพาะ asset ปลายทางและ `output/art-queue-2026-10-22/`; ไม่แก้ src, index, tests, catalog/manifest, hooks, status.json, worklog.json
4. **เกณฑ์ภาพ §3:** ได้ราวคู่ตั้งตรงแบบสะท้อน 5 ขั้นและพื้นแกนเดียวกัน ใช้แถบเดินตามพิกัด; การตรวจองศาและสไตล์ขั้นสุดท้ายยังเป็นการตรวจภาพโดย Toby
5. **เกณฑ์ runtime §3:** ยังไม่ได้เสียบ path หรือเดินในเกม จึงยังไม่ได้ตรวจ ferry, รอยต่อขณะ zoom และ minimap
6. **ทดสอบ §3:** รัน `node --test tests/*.test.mjs` แล้วหยุดด้วย Ctrl-C (exit 1) หลัง log ไม่คืบหน้าเกินสองนาที มีรายงานผลสำเร็จย่อย 344 รายการ แต่ไม่มีสรุปทั้งชุด จึงไม่ถือว่าทดสอบครบ ผลและ log อยู่ใน `pier/test-result.txt` กับ `pier/node-tests.txt`; สคริปต์ตรวจพิกเซล `verify.py` จบ exit 0 ดู `pier/pixel-check.txt` ไม่ถือเป็นการรับรอง QA ภาพหรือเกม

ตรวจข้อมูลพิกเซลซ้ำได้ด้วย `python3 output/art-queue-2026-10-22/pier/verify.py` (Pillow + NumPy) สคริปต์นี้เขียนเฉพาะหลักฐาน ไม่เขียน asset เกม
