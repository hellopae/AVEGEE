# AVEGEE ART-p4-icons — README / หลักฐานส่งตรวจ

งานภาพใหม่ 22 ชิ้นเท่านั้น ไม่เชื่อมโค้ดเกม ผลตรวจด้านล่างเป็นการตรวจไฟล์และการดูภาพของผู้วาด ไม่ใช่ผล QA หรือการอนุมัติรับงาน

## ต้นแบบและข้อกำหนด

อ่าน Vera `2026-10-22-avegee-p4-ux-spec.md` §3.1, §3.4 และ §6 แบบอ่านอย่างเดียว อ้างรูปทรงและสัดส่วนเส้นจาก `img/icon-force-1.png`, `img/icon-force-2.png`, `img/icon-force-3.png` (256×256): วงเต็มเกือบขอบ เส้นขาวหนา ปลายมน เงาอ่อน สีพื้นแบนตามคำตอบผู้ใช้; คู่มาตรวัดใช้โทนทองแดงและขอบนูนจาก `img/ui/icon-justice.png` แต่ลดรายละเอียดให้เหมาะกับ 32 px

ใบงานล่าสุดขอ WebP มี alpha จึงใช้ชื่อฐานและ path `img/ui/` ตาม §6 โดยเปลี่ยน `.png` เป็น `.webp` ทั้ง 22 ไฟล์ ไม่เพิ่ม PNG ซ้ำและไม่แก้ตัวเรียกไฟล์ในเกม ผู้เชื่อมโค้ดต้องใช้ชื่อ `.webp` นี้

## วิธีวาด

วาดรูปทรงเรขาคณิตและเส้นโค้งโดยตรงด้วย Pillow ที่ 4 เท่าของกริด 256 แล้วลดด้วย Lanczos ส่งออก WebP lossless RGBA ไม่ใช้ image generation model: เป็นข้อยกเว้น simple UI icons ตามทักษะ imagegen จึงไม่มี model prompt เส้นหลัก 12–16 หน่วยบนกริด 256 (ประมาณ 1.5–2 px ที่ 32 px) พื้นวงรัศมี 120 ขอบเว้น 8 หน่วย สัญลักษณ์ขาวงาช้าง `#fffdf4` เงาพลัมอ่อน

แนววาด: กระบองเฉียง / ลูกไฟ / เกลียวสะกด / ดอกบัวธรรมชาติ / แสงกลมมีรัศมี / ดาบ / ค้อนหนักมีวงซ้อน; หน้าที่ใช้รายการตรวจ / หยดชำระ / โล่เครื่องหมายถูก / กลุ่มคน / ตา / ม้วนสำนวน; มาตรวัดใช้มือพนมและมือถอยจากไฟ; ตราใช้ปีก/ต้นอ่อน/ลูกศรย้อน; หมุดคุยใช้จุด/ลูกศร/ประกาย แยกกันด้วยรูปทรง ไม่พึ่งสีอย่างเดียว ไม่มีตัวหนังสือ สัญลักษณ์ศาสนา หรือกากบาทในภาพ (ดอกบัวเป็นรูปพืชทั่วไปตามสเปก ไม่ใช่ตราศาสนา)

## แผ่นตรวจและผลตรวจเชิงไฟล์

[contact-sheet.png](p4-icons/contact-sheet.png) แสดงครบ 22 ชิ้นที่ขนาดจริง 1:1 และขนาดย่อ 26/32/48 px บนพื้นพลัม `#27171f` กับพื้นอ่อน `#f3eee6` ภาพจริง 256 px วางคร่อมพื้นสองสี ส่วนภาพจริงขนาดเล็กกว่าแสดงแยกพื้นละหนึ่งภาพ ต้องเปิด PNG ที่ 100% เพื่อดูขนาดจริง

[validation.json](p4-icons/validation.json) บันทึก path ขนาด alpha และ SHA-256 รายชิ้น ตรวจด้วย Pillow decode จริงครบ 22 ชิ้น: WebP lossless, ขนาดตรงตาราง, RGBA, alpha ต่ำสุด 0 สูงสุด 255 ยืนยันพื้นใสนอกวงและส่วนทึบในภาพ ไม่เขียนทับไฟล์เดิม

ยังต้องให้ผู้รับตรวจความหมายและความชัดเมื่อใช้ในเกมจริง โดยเฉพาะป้าย 26 px; แผ่นย่อเป็นหลักฐานสำหรับตรวจ ไม่ใช่คำรับรองว่า QA ผ่าน
