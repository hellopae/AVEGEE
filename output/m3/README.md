3. ไม่เห็นอาคาร แท่น บ้าน เรือ คบ โคมตั้งพื้น รูปปั้น คน สัตว์ หรือต้นไม้เดี่ยวกลางลาน; มีไม้เป็นมวลตามหิน/ริมฝั่ง
4. ทางหินเทาหยกคอนทราสต์ต่ำ ส้มสว่างหลักมาจากลาวา
5. ท่าเรือ Q4 ไม่ผ่านความสมมาตร/ราวตั้งฉาก≤2°
6. ฝั่งต่ำ3ช่วง Q3 ไม่ผ่าน โดยเฉพาะท่าเกินทับช่วงกลาง
7. ตำแหน่งตัวอย่าง seed ต้นทางส่วนใหญ่0–1canvas px แต่สี/textureต่าง และในผืนจริงยังเห็นพืช/น้ำซ้อน จึงไม่รับรองรอยต่อทั้งเส้น≤12canvas px
8. เห็นหินหยก เมเปิลแดง หมอก และน้ำเขียวน้ำเงินมีฟอง ไม่มีหิมะ/น้ำแข็ง/แสงฟ้า-ม่วงที่เห็น
