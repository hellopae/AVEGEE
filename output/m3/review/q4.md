## Seed และกระบวนการ

อ่านสเปก §2, §3.1–3.3, §3.8–3.10 และ README Q1–Q3 ก่อนวาด ใช้ built-in imagegen 3 รอบ (ครั้งแรก + redraw2ครั้งตามเพดาน§3.9) ทุกครั้งใช้ prompt เดียวกันตามด้านล่าง แนบ [1] layout [2] walk [3] theme [4] seed ตามลำดับ ไม่แนบ guide ไม่ใช้ CLI/API fallback

สร้าง composite3ส่วนบนcanvas2731×1820: NW(0,0), NE(1195,0), SW(0,796) ซ้อนแนวนอน341px/แนวตั้ง228px; feather linear จาก0ถึง1 ในแถบทับ โดย SW ทับ composite NW+NE ภายหลัง แล้ว crop SE(1195,796)–(2731,1820) ได้ L บน228px ซ้าย341px ส่วนอื่น#808080 มุมร่วมจึงมีทั้งสามภาพจริง ไม่ใช่แค่เอา NE และ SW มาวางทับตรงๆ สูตร16/9ให้overlap341.333/227.556px จึงมีการปัดเศษ0.333/0.444px ภาพpreviewลดจาก2731×1820เป็น1536×1024 ไม่จำลองsubpixel stitchingของToby

เลือกครั้งที่1 เพราะโครงลาน/สะพาน/ท่าเรือใกล้layout และซากงูทะเลเป็นชุดเดียว รอบ2เพิ่มกระดูกติดฝั่งใต้ รอบ3เพิ่มกลุ่มหินกลางน้ำและซี่โครงแยกหลายชุด แม้รอบ2/3มีseed MAEต่ำกว่า (26.819/27.221เทียบ30.771ของรอบ1) ก็ไม่รักษาseedเดิมเช่นกัน ไม่แปะseedคืน/รีทัช/ย้อมสี/sharpen/ครอปภาพส่งมอบ บันทึกRGBพร้อมICC sRGBโดยค่าพิกเซลเท่ารอบ1

## จุดต่างจากสเปก

Seedไม่คงพิกเซลและสีเดิม แม้สุ่มตำแหน่งได้0–1px; ท่าเรือไม่ตรงเงื่อนไขสมมาตร/ราวตั้งตรง; ขอบฝั่งต่ำยังค้าง; ความคม1.8×และความตรงmaskทุกเส้นยังยืนยันไม่ได้ ใช้การปัดoverlapเป็น341/228ตามprompt และมีfeatherเฉพาะภาพcompositeตรวจ ภาพส่งมอบไม่ถูกblendแก้ ทั้งสามรอบใช้promptENตรง§3.8รวมnegativeสืบทอดQ1+Q3+Q4 ไม่มีpromptเพิ่มหมุดตัวเลข เพราะใบงานระบุให้ใช้ข้อความเป๊ะ
