## ผลงาน

- idle-generated.png: ภาพท่ายืนพักวาดใหม่ด้วย built-in ImageGen 4 ทิศ × 4 เฟรม
- walk-generated-v2.png: ภาพท่าเดินวาดใหม่ด้วย built-in ImageGen 4 ทิศ × 8 เฟรม รอบแก้เพิ่มท่าผ่านกลาง/เท้าชิด
- walk-generated.png: รอบแรกที่ยังยกขาซ้ำ เก็บไว้เป็นหลักฐาน ไม่ใช่ภาพที่ใช้ในพรีวิวปัจจุบัน
- idle-sheet.png / walk-sheet.png: ภาพที่ตัดเฟรมและจัดจุดยึดสำหรับพรีวิว
- metadata.json: พิกัดเฟรม เวลา จุดยึด และ hash ของภาพสร้างใหม่
- idle-prompt.txt / walk-prompt.txt: prompt ฉบับเต็มที่ใช้สร้างภาพ
- GIF แยกตามทิศ: idle-down/left/right/up.gif และ walk-down/left/right/up.gif

ต้นแบบ: img/hero-yama.png และ img/hero-yama-walk-4dir-v2.png เป็น Yama ผิวแดง มงกุฎไทย ชุดดำขลิบทองและแผงแดง มือทั้งสองกอดหนังสือปิด ไม่มีดาบ

prepare.py ทำเฉพาะการแยกเฟรมตามช่องว่างโปร่งใส ใช้การย่อแบบรักษาสัดส่วนด้วยสเกลเดียวต่อ sheet และจัด root/foot anchor ไม่มีการวาดทับหรือยืดส่วนร่างกายในการประมวลผล ภาพแต่ละท่าเป็นภาพสร้างใหม่จาก ImageGen จริง

## พรีวิวเปรียบเทียบ

เปิด index.html ผ่านเซิร์ฟเวอร์โฟลเดอร์ทดลอง: http://127.0.0.1:8793/map-book-v1/

มี 3 ช่อง: ยืนพักใหม่ / เดินเดิม 4 เฟรม / เดินใหม่ 8 เฟรม เลือกทิศและความเร็วร่วมกันได้ การเปรียบเทียบใช้รอบเดิน 800 ms เท่ากัน เพื่อเทียบท่าทาง ไม่ได้จำลองเวลารอบเดินปัจจุบันในเกม พื้นเลื่อนเป็นตัวช่วยสังเกตจังหวะ ไม่ใช่การแก้ระบบเดินหรือกล้องของเกมจริง

## การเชื่อมในอนาคต

ไม่ควรแทนชื่อไฟล์ภาพเดิมโดยตรง เพราะ geometry เปลี่ยนแล้ว กรอบใหม่ 320×480, foot anchor=(160,440), ความสูงภาพตัวละครสูงสุดประมาณ 320 px ดู metadata.json เป็นหลัก ลำดับทิศคือ down, left, right, up

ตัวเล่นเดิมอ่าน 4 เฟรมจาก src/hero-walk-assets.js และผูกกับระยะเดินจริงใน src/walk-motion.js การรับงานควรเพิ่ม renderer ที่ใช้ anchor และ 8 เฟรม ผูก phase กับระยะทางแทนใช้เวลาอย่างเดียว เพื่อให้เท้าสอดคล้องความเร็วจริง และรักษาการหยุดเดิน/เปลี่ยนทิศ ต้องประสานกับ Claude ก่อนแตะไฟล์ร่วม

ควรตรวจภาพทุกทิศ ความต่อเนื่องช่วงเฟรม8→1 และเท้าสัมผัสพื้นก่อนนำขึ้นเกม ภาพ AI ยังอาจมีรายละเอียดเปลี่ยนระหว่างเฟรม การมีจำนวนเฟรมเพิ่มขึ้นเพียงอย่างเดียวไม่ยืนยันว่าเดินเนียนแล้ว

SPA ยังขาด Aseprite runtime ผลรอบนี้เป็นการสร้างภาพด้วย ImageGen และเล่นด้วย Canvas ไม่ได้อ้างว่าเป็น native export จาก SPA
