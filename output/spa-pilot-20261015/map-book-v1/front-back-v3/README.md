# แก้ท่าเดินหน้า–หลังเฉพาะจุด

ผู้ใช้ส่ง Screen Recording 2569-10-15 at 12.02.11.mov และระบุว่าซ้าย/ขวาดูโอเค แต่หน้า/หลังขาขวาดูยกขึ้น–วางลงมากกว่าถอยไปด้านหลัง

รอบนี้แก้เฉพาะ rows down/up เก็บ left/right และ idle เดิมไว้ ตรวจ hash ของไฟล์และเทียบ pixel ของสองแถวที่ล็อกก่อนรับภาพใหม่

หลักการภาพที่ต้องตรวจ: เฟรม1กับ5ต้องเป็นคนละขาก้าวนำ เท้าส่งตัวต้องอยู่หลังสะโพกในช่วง stance แล้วจึงยกส้นขึ้น/แกว่งผ่านกลาง ห้ามให้ทั้งครึ่งรอบแรกและหลังเป็นขาเดียวกัน

first-pass.png เก็บภาพสร้างรอบแรกที่ยังวางขานำซ้ำ prompt.txt เป็น prompt เริ่มต้น ส่วน prompt-correction.txt เป็นคำสั่งแก้เฉพาะขาใต้ชายเสื้อในครึ่งรอบหลัง

generated.png คือภาพหลังแก้ นำมาใช้ทั้งสองทิศ หน้าใช้ลำดับ0–7 ส่วนหลังเรียงท่าตามจังหวะที่วาดจริงเป็น [1,4,2,0,3,5,6,7] เพื่อให้ครึ่งรอบแรกกับหลังเป็นคนละขาก้าวนำ ใช้ครบทุกท่าครั้งเดียว

เลิกตรึงปลายเท้าที่ต่ำสุดไว้ตำแหน่งเดิมทุกเฟรมสำหรับสองทิศนี้ เพราะทำให้ระยะลึกหน้า/หลังของเท้าหายไปและตัวละครเด้งตามขาที่งอ เปลี่ยนเป็นตรึงระดับมงกุฎ/แกนลำตัวพร้อม bob เพียง4pxต่อรอบ ขาปล่อยให้เคลื่อนตามภาพวาดจริง ไม่ยืดหดร่างกาย

ตรวจแยกกลุ่มสีแดงบริเวณเท้าในเฟรม1กับ5: ท่าหน้าเท้าใกล้กล้องเปลี่ยนจาก x≈132 ไป x≈168; ท่าหลัง x≈141 ไป x≈165 เท้าขวาท่าหน้าเปลี่ยนระยะลึก25px ท่าหลัง16pxตามกรอบพรีวิว ดู foot-components.json และ verification.json ตัวเลขเป็นหลักฐานตำแหน่งภาพ ไม่ใช่การรับรองความสมจริงของทุกจังหวะ

apply_frontback.py ทำเฉพาะ crop/จัดกรอบ/รักษาสัดส่วนและรวม atlas ใช้ walk-sheet-before.png เป็นฐานเพื่อคงท่าซ้าย/ขวาเดิม ไม่ใช่การวาดหรือยืดขาด้วยโค้ด

เพื่อสร้างซ้ำ: รัน prepare.py จากโฟลเดอร์แม่เพื่อสร้างฐาน v2 ก่อน แล้วรัน front-back-v3/apply_frontback.py เพื่อใส่ท่าหน้า/หลัง v3 ห้ามรัน prepare.py เพียงตัวเดียวหลังรับภาพใหม่ เพราะจะคืนสองแถวนี้กลับเป็น v2
