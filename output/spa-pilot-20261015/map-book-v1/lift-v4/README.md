# แก้เฟรมยกขาและลบเนื้อเกินข้างเขา

ผู้ใช้ชี้ว่าเฟรมยกขาเข้ากลางตัวเหมือนขาเดียว และไม่เอียงไปด้านหลัง จากคลิป 12.41.29 และ screenshot 12.41.05/12.41.15 ตรวจพบจุดหลักที่ท่าหน้าเฟรม3และ7 จึงวาดแก้เฉพาะเฟรม3/7ของท่าหน้าและหลัง รวม4ภาพ ด้วย built-in ImageGen

หลักภาพใหม่: ขารับน้ำหนักอยู่ใต้สะโพกของตัวเอง อีกขางอเข่าและเอนไปด้านหลัง ต้องเห็นขาสองข้างแยกกัน ห้ามชูขาตรงกลางเหมือนขาเดียว รักษาท่าอื่นที่ดีแล้วไว้

ระหว่างสร้างภาพ ผู้ใช้ชี้เนื้อเกินข้างเขาซ้ายจาก screenshot 12.46.48 จึงแก้ภาพท่าหน้า2เฟรมซ้ำด้วย ImageGen ลบเฉพาะติ่งสีแดงหลังเขาหลัก เก็บเขาหลัก ใบหู หนังสือ และท่าขาใหม่ไว้ ไฟล์ unclean-down-* คือก่อนเก็บส่วนเกิน ไม่ใช่ภาพที่จะใช้ในพรีวิว

apply_lift.py ใช้เพียงการ crop/ย่อแบบรักษาสัดส่วนให้ขนาดมงกุฎเท่ากรอบเดิม และจัดตำแหน่งคงที่ ไม่มีการยืดขาหรือวาดแก้รูปร่างด้วยโค้ด เปลี่ยนแค่4เฟรมใน atlas อีก28เฟรมเดินและท่ายืนทั้งหมดต้องเหมือนเดิม ตรวจpixel/hashใน verification.json

ลำดับสร้างซ้ำทั้งชุด: prepare.py → front-back-v3/apply_frontback.py → lift-v4/apply_lift.py แต่ละรุ่นมี baseline ภาพและmetadataของตัวเองอยู่แล้ว
