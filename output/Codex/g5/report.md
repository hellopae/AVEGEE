## สิ่งที่ทำและตัวเลข

- พื้นลานโซนไทยใช้ polygon สัดส่วนภาพ 0–1 ตามพื้นที่สว่างของ reference ตรวจทุกช่วงการเดินด้วย `walkSegmentInside()` ของระบบเดิม ตัดแท่น/ราว/บันได/ไห/เตาขวาออก รวมทางลงถึงขอบพรม ฉากกระทะของโซนอื่นคง polygon ของฉากเดิม เนื่องจากไม่มีภาพ mask อ้างอิงของโซนเหล่านั้น
- ปุ่มเร่งไฟอยู่เหนือแถวกระทะ: ไม่มีดวงที่ถึงกระทะแล้วหรืออยู่ระหว่างเดินทาง = ปิดปุ่มพร้อมเหตุผล จากนั้นยมบาทเดินไป `[.5,.54]` แล้วจึงเปิดให้กด QTE เข็มแดงบนแถบแนวนอน โซนเขียว 42–58% ใช้เวลาสูงสุด 8 วินาทีหลังถึงจุดยืน
- ถูก: `progress += (need - progress) * .2` ทุกดวงที่กำลังอยู่ในกระทะของสถานีนั้น รวมทุกใบ ไม่กระทบดวงที่ยังมาไม่ถึง พลาดไม่เพิ่ม progress ไม่ใช้ MP/เงิน คูลดาวน์ 20 วินาทีหลังผลรอบนั้น; จอง 20 วินาทีตั้งแต่เปิดรอบด้วยเพื่อกันเปิด/ปิดซ้ำ
- ถูกแล้วใช้ท่าโจมตียมบาทและสไปรท์ลูกไฟเดิมพุ่งใต้กระทะ ไฟโหม ~2.2 วินาที พลาดมีเพียงไฟฟู่ขนาดเล็ก
- ปุ่มฝึกควบคุมไฟลอยเหนือเพลิง แสดงเมื่อมีเพลิงในทีม แยกจากปุ่มฝึกตัวละครเก่า เลือกยมบาทหรือเพลิง วงขาวหดเข้าวงเขียว (คลาดรัศมีไม่เกิน 12% ถือว่าถูก) ถูก 5 ครั้งสำเร็จ พลาด 3 ครั้งจบ รอบที่ปล่อยผ่านวงเขียวโดยไม่กดนับเป็นพลาด ลูกไฟขยายทีละขั้น
- สำเร็จให้ระดับ +1 สูงสุด 3 ระดับ: ดาเมจลูกไฟคำนวณ `round(base * (1 + level * .05))` ของผู้ฝึกคนนั้นเท่านั้น ดาเมจฐาน 40 เป็น **40 / 42 / 44 / 46** ที่ระดับ 0 / 1 / 2 / 3 ไม่เปลี่ยนตัวเลขสมดุลอื่นและไม่เพิ่มดาเมจโจมตีธรรมดาหรือ flameCharge
- เกมมีวาระทำงาน (`tick`) แต่ไม่มีวันปฏิทิน จึงใช้พักฝึก **5 นาทีจริงหลังสำเร็จต่อคน** ฝึกพลาด/ยกเลิกไม่เสียทรัพยากรและไม่เริ่มพักฝึก บันทึกระดับกับ timestamp ลงเซฟ แยก Yama และ Plerng ด้วย actor ID ของแต่ละสาขา เซฟเก่าเริ่มระดับ 0
- แสดงระดับในหน้าข้อมูลยมบาทและเพลิง ข้อความใหม่มี TH+EN ทั้งหมด
- สร้าง close-up pixel art ใหม่ 2 ใบ (ประมาณ 16:9, 1672×941 ไม่มีข้อความ) และลูกไฟ PNG 512×512 พื้นใส ตรวจ alpha ต่ำสุด 0 สูงสุด 255 ใช้ `prep()` ทีละไฟล์ ไม่ใช้ ingest หรือ make-manifest ไม่แตะ raw/Exam ภาพเดิม เพิ่ม manifest/preload ด้วยมือและ bump cache
- ปุ่มเร่งไฟย้ายเข้า layer ของ canvas เฉพาะห้องกระทะเพื่อให้ anchor ตรงภาพทุกจอ จอเล็กแยกปุ่มฝึกซ้ายกับเร่งไฟขวา QTE close-up รักษาสัดส่วนภาพและปุ่มลูกไฟอยู่นอกภาพ
