## ตรวจเองตามเช็กลิสต์ §4.5 — ข้อมูลสำหรับผู้ตรวจรับ

1. เปิดไฟล์ปลายทางใหม่ด้วย Pillow: ครบสามไฟล์ ขนาดและ RGBA ตามตาราง; ตรวจ chunk `VP8L` เป็น lossless ทั้งสาม ขอบ bbox ห่างจากอ้างอิงไม่เกิน 1 px (สูงสุด 0.42% ของแกนภาพ)
2. ใช้ HSV เฉพาะ ROI ที่บันทึกไว้กับทั้งโครงและภาพใหม่: Pillow H=5..43, S>150, V>240, A>200 เป็นการวัดแกนสว่างของเปลว ไม่ใช่การทดสอบตัวอ่านไฟของเกม
   - โคม: centroid ใหม่ (256.78,295.21); Δy=-12.23 px = -1.10% ของความสูง (เกณฑ์ ±3%)
   - คบ: centroid ใหม่ (128.04,56.21); Δy=-9.09 px = -2.17% ของความสูง (เกณฑ์ ±3%)

   จากภาพที่เปิดดู เห็นเปลวหลักหนึ่งกลุ่มใน cage/ชาม ไม่มีเปลวแยก ไม่มีควัน ดู mask ที่ `s4/flame-mask-{lamp,torch}.png` สี cyan ในไฟล์ mask เป็น annotation เท่านั้น
3. เปิดภาพคบที่ 240×419 ใน `s4/torch-native-comparison.png`: เห็นชาม เสา แถบแดง และฐานหินแยกชัด แต่ชาม/ฐานกว้างกว่าโครงที่มองเห็นจริง (ดูข้อแตกต่างด้านล่าง)
4. เปิดหินเทียบโครง: สามก้อนหลัก เงาเทาเขียว มอส ใบเมเปิล ไม่มีรอยแตกเรือง/ถ่าน/ลาวาที่มองเห็น ตัวกรองส้มสว่าง H≈10–45°, S≥80%, V≥85% ยังพบ 23 พิกเซล จึงยังต้องให้ Toby ตรวจผลแสงกลางคืนจริง ไม่รับรองว่าเกมจะไม่อ่านใบไม้บางพิกเซลเป็นไฟ
5. เปิดภาพขอบ 400% บน #202020 และ #E0E0E0 ทั้งสามชิ้น ไม่เห็นเส้น cyan/magenta ที่ crop ที่ตรวจ; ตัวกรองส่วนเกินช่องสี key >45 พบ 0 พิกเซลที่ alpha>0 ทั้งสามไฟล์ หลักฐาน `s4/*-edges-400pct.png` และ `s4/*-{dark,light}-native.png` ตัวกรองนี้ไม่ใช่หลักประกันทุกชนิดของ halo
6. เปิด `s4/contact-zone2-material.png` เทียบกับ st-krata-asia: ใช้หินเทาเขียว แดง และทองร่วมกัน ไม่มีรูปเคารพ ม่านจื่อ หรือตัวอักษรที่เห็นในสาม sprite สุดท้าย ยังไม่มีภาพ S1–S3 ใหม่ใน worktree จึงตรวจการเข้าชุดกับ S1–S3 โดยตรงไม่ได้

## จุดต่างจากสเปก / ข้อจำกัดที่ต้องตรวจต่อ

- ตัววาดไม่ได้ส่ง canvas ขนาดปลายทางตรงทุกชิ้น จึงเก็บ PNG ดิบแล้วทำ export ตามขนาดบังคับ; พื้นหลังดิบใกล้ cyan/magenta แต่ไม่ได้เป็น hex คงที่ทุกพิกเซล แม้ prompt ระบุ exact key จึงใช้ matte แบบมี tolerance และ despill
- alpha>0 bbox ของโครงมีเศษ alpha จาง: bbox ที่ alpha≥16 ของโคมคือ (125,8,400,1107), คบ (68,0,180,417), หิน (108,169,1159,1085) ซึ่งเล็กกว่า bbox ที่สเปกให้วัดอย่างมาก งานใหม่นี้อิง alpha>0 ตามคำสั่งตรงตัว ไม่สร้างพิกเซลโปร่งจางเทียมเพื่อเลียนเศษนั้น ผลคือกรงโคม ชาม/ฐานคบ และมวลหินดูกว้าง/ใหญ่กว่าโครงที่เห็นจริง แม้ตัวเลข bbox อยู่ใน ±2%; silhouette จึงไม่เหมือนโครงทุกส่วน ต้องให้ Toby พิจารณาสเกลตอนเสียบ
- centroid วัดได้อยู่ใน ±3% แต่ขนาดเปลวและรูปชามไม่ได้ตรงโครงทุกพิกเซล การวัด HSV/ROI เป็นประมาณการที่ทำซ้ำได้ ไม่ใช่ segmentation เชิงความหมาย
- โคมร่างแรกมีโคมห้อยพร้อมลายคล้ายอักษร จึงแก้ด้วย image_gen ให้เหลือกรงกลางอันเดียวและลวดลายเรขาคณิต รอบแก้ใช้ร่างเป็น edit target และ st-krata-asia เป็นวัสดุ
- ไม่ได้ตรวจในเกม ไม่ได้ทดสอบเงา/ไฟซ้อน/กลางคืน/ตำแหน่งวาง และไม่ได้ตรวจรับเชิงวัฒนธรรมแทนผู้รับผิดชอบ
