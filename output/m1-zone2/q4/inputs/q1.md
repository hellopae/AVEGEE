## จุดต่างจากสเปกและข้อจำกัดที่ส่งต่อ

1. หมุด ≈ ถูกปรับบันทึกตามขอบภาพที่วัดจริง โดยเฉพาะลานกลางและสะพานโค้งเหนือ ไม่เปลี่ยน source/layout ของเกม
2. Walk ใช้ nearest-neighbor เพื่อให้เหลือสองสีตาม §3.4; layout/guide ใช้ Lanczos ตามสเปก ไม่มีการเบลอ layout ก่อนวาด
3. ภาพวาดเพิ่มหัวเสาทองตามบันไดบางจุดมากกว่าต้นฉบับ และลานไม่มี worn patch เข้มกลางวงรีชัดเท่าข้อความ prompt ลานกลางมีลายกลีบเรขาคณิตแทนลายรอยแตกเรียบเดิม ส่งให้ Chris ตรวจการอ่านลายด้วย ไม่มีการแต่งภาพเพื่อกลบความต่าง
4. ไม่สร้าง Q2–Q4, sprite, tile/preview สำหรับเกม หรือ seed ของควอแดรนต์ถัดไป เพราะนอกใบงาน Q1
5. ภาพ raw ปลายทางถูก gitignore (`.gitignore:5:img/raw/`) จึงเก็บสำเนา byte-identical ใน output เพื่อให้ wrapper ส่งต่อได้ ไม่เปลี่ยน .gitignore ไม่ stage/commit ไฟล์เอง
6. ความคมที่1.8× และความตรง mask ทุกเส้นยังต้องตรวจตอนเสียบ ไม่อ้าง QA ผ่าน ไม่มีการทดสอบเกมหรือ deploy
