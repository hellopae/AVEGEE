# ART-m1-zone2-q5 — ภาพซ่อมสำหรับตรวจ ยังไม่ครบเกณฑ์รับงาน

ทำใน worktree/branch ที่ได้รับ `codex/20261023T060215Z-4c7f2b03` เท่านั้น ใช้ภาพจริงจาก M3 `review/quadrants` และสเปก Mind §3.11 ไม่มีการแก้โค้ด, tests, index.html, hooks, status.json หรือ worklog.json ไม่สร้าง worktree/branch ไม่เรียก agent ไม่ commit/push/merge/deploy

## ไฟล์ส่งมอบและสิ่งที่แก้

- `q5/quadrants/q-{nw,ne,sw,se}.png`: ครบ 4 ไฟล์ 1536×1024 RGB พร้อม ICC sRGB; NW คัดลอกเหมือนต้นฉบับทุกไบต์, SW/SE แก้ฝั่งและท่า, NE/SE แก้รอยต่อน้ำ ใช้แพตช์ร่วมกันในบริเวณซ้อน
- `q5/terrain/`: ผืนตรวจ `full.png` 4915×3277, 20 WebP tiles, `zone2-terrain-v1-preview.webp` 1536×1024, preview PNG lossless, guide overlay 50%, mask overlay และ stitch-report.json ทั้งหมดเป็นงานตรวจ ไม่เสียบ runtime
- `q5/evidence/`: before/after/diff-x4 ทุกกลุ่มซ่อมและจุดเฝ้าระวัง 9 กลุ่ม (ครอปจากผืน native), diff ต่อควอแดรนต์, guide และ mask ต้นทาง
- `q5/verification.json`: ขนาด/โหมด/ICC/hash/bbox ที่เปลี่ยน, ค่ามุมราว, หน้าต่างวัดรอยต่อ, ผลเทียบพิกเซลจุดเฝ้าระวัง และข้อจำกัด
- `q5/inputs/`, `q5/edits/`: crop ต้นทาง, ภาพวาด, แพตช์ registered, มาสก์นุ่ม, ค่าประกอบภาพ และ prompt set ใน `edits/prompts.md` ใช้ built-in imagegen 4 ครั้ง (รวมแก้เสาท่าเรือซ้ำ)

ครอปจากควอแดรนต์ต้นทาง → imagegen edit → ลงทะเบียนกลับกรอบเดิม → composite ด้วยมาสก์นุ่ม 6–8 canvas px ตาม §3.11 ภาพต้นทาง M3 ไม่ถูกเขียนทับ ไม่มีการวาดทับทั้งผืน ภาพท่าเรือรุ่นแรกมี 6 เสา จึงเก็บเป็นหลักฐานแต่ไม่ใช้โดยตรง รุ่นเลือกมี 4 เสาและจัดแนวราวด้วย mesh เฉพาะแพตช์

## ผลตรวจตามรายการใบงาน

| เกณฑ์ | หลักฐาน/ผลที่ตรวจได้ | ข้อค้าง |
|---|---|---|
| 1. ลบท่าเกินและทำฝั่งต่ำ 3 ช่วง | ไม่เห็นท่าเกินใน crop หลังแก้; ฝั่งซ้ายและกลางเป็นหินลาดต่ำแทนผา; ฝั่งขวาลดผาบริเวณซ้ายท่าจริง ดู `shore-left-*`, `extra-pier-shore-middle-*`, `shore-right-real-pier-*` | ฝั่งกลางยังมีปลายหินลาดลงถึง y≈690 ขณะที่ระบุ nominal y≈676 ต้องให้ผู้ตรวจพิจารณาขอบขึ้นจริง/ความต่ำทั้ง 3 ช่วง ไม่ถือว่าครบเกณฑ์จากการดูภาพอย่างเดียว |
| 2. ท่าเรือ ราว≤2° เสาเท่ากัน และ deck | ตรวจภาพ native เห็น 4 เสา; fit จุดสีทองจากผืน lossless y681–704 ได้มุมราวซ้าย 0.160° ขวา −0.481° (74 แถวต่อราว); วัดขอบ deck ด้วยตาประมาณ x875–919/y697–718 ±2 preview px | มุม fit วัดเฉพาะแกนสีทอง ไม่ใช่รับรองทุกขอบราว; ความสูงเสายังต้องตรวจอิสระ ขอบ deck ขวาเกิน walk-mask x916.8 ราว 2.2 px แม้อยู่ในกรอบ deck โดยประมาณ ต้องตรวจ interior กับราวอีกครั้ง |
| 3. รอยต่อ NE–SE | ใช้แพตช์เดียวทั้งคู่ เห็นน้ำและแนวหินต่อเส้นเดียวชัดขึ้น; หน้าต่าง x990–1040/y490–530 และ x1120–1170/y490–530 ค้น shift ±7 preview px ได้ดีที่สุด (0,0) ทั้งคู่; RGB residual 8.662 และ 6.689/255 | ไม่ใช่การวัดแนวขอบทุกเส้น/ทั้งแถบ คงต้องตรวจขอบ feather และการเปลี่ยนสี; ยังไม่รับรองรอยต่อทั้งเส้น≤12 canvas px |
| 4. ต่อผืนและตรวจจุดเฝ้าระวัง guide/mask±16 | stitch จริงขนาด 4915×3277 ครบ20 tiles; ถนนกลาง x742–798/y580–790, ลานใต้ x615–925/y787–930, krajok x1340–1460/y525–680, สะพานลาวา2จุด **พิกเซลต่าง 0** เมื่อเทียบกับผืน lossless ที่ต่อใหม่จาก M3 ด้วยสคริปต์เดียวกัน; มี guide/mask overlay ให้ตรวจ | พิกเซลไม่เปลี่ยนพิสูจน์ว่าแพตช์ไม่กระทบจุดเฝ้าระวัง แต่ไม่พิสูจน์ว่าต้นทางตรง guide/mask ทุกขอบอยู่แล้ว จึงยังไม่รับรอง ±16 ทุกขอบ |
| 5. ชุดไฟล์/หลักฐาน/ข้อห้าม | ครบ4ควอแดรนต์ RGB sRGB, ภาพก่อน/หลัง/diff, verification.json, ผืนและ README อยู่ใต้ output/m1-zone2 เท่านั้น | ไม่มีผลทดสอบการเดินจริง/เกม เพราะใบงานวาดภาพเท่านั้น |

เก็บ mask เดิมจาก M3 เป็น reference ไม่แก้ mask เกม ตัวอย่างช่วงเดินจาก mask ที่ y700 คือ x746–793 และ y852 คือ x611–924 ค่านี้เป็นขอบ mask ไม่ใช่ผลตรวจแนวภาพโดยอัตโนมัติ สเปกกำหนด≤12 **canvas ของควอแดรนต์** (≈6.75 preview px); ห้ามสับสนกับพิกเซลผืนขยาย

## คำสั่งตรวจที่รัน

1. `python3 scripts/stitch-town-terrain.py --zone asia --src output/m1-zone2/q5/quadrants --out output/m1-zone2/q5/terrain --keep-full output/m1-zone2/q5/terrain/full.png` — ต่อผืนจริง exit 0 หลังประกอบควอแดรนต์ชุดสุดท้าย
2. คำสั่งเดิมพร้อม `--dry-run` — อ่านครบ4ไฟล์ exit 0
3. Python/Pillow/NumPy assertions: ขนาด/โหมด/ชื่อ ICC sRGB ทั้ง4, NW SHA256 เท่าเดิม, จำนวน20tiles, guard boxes 5 กลุ่มไม่มีพิกเซลเปลี่ยน, abs(line-fit angle)≤2 — จบโดยไม่มี assertion error; ค่าจริงอยู่ verification.json ไม่ใช้ผลเชิงกลแทนการรับงานภาพ
4. เปิดดูภาพต้นทาง, ภาพวาด, ผืนหลังต่อ และ crop native ท่า/น้ำ/สะพานจริง เปรียบเทียบกับ guide และสร้าง overlays
5. `git diff --check` exit 0 (ชุดส่งมอบเป็นไฟล์ใหม่ จึงตรวจเพิ่มด้วย assertions ข้างต้น); `git status --short` พบเพียง output/m1-zone2 ใหม่ ไม่มีการรันชุดเทสต์ runtime เพราะไม่แก้โค้ด
