## วิธีเตรียมไฟล์และหลักฐาน

- อ่านสเปก Mind ทั้งไฟล์และใช้เฉพาะ S3; วัดภาพอ้างอิงด้วย PIL ก่อนวาด: [reference-measurements.json](s3/reference-measurements.json) มีขนาด โหมด alpha bbox และ SHA-256 ของ 11 ภาพ รวมต้นโครง 4 ต้น แผนที่ธีม สถานี 4 ชิ้น preview และ guide (guide ไม่แนบให้ตัววาด)
- ตัด key ด้วยความเด่นของช่องสี (magenta: min(R,B)−G >25; cyan: min(G,B)−R >25) รวมช่องว่างระหว่างใบ; หด alpha เข้า 1 px ด้วย minimum filter 3×3; despill สีขอบด้วยพิกเซลภายในที่ใกล้ที่สุด; fit เนื้อภาพทั้งชิ้นเข้ากรอบปลายทางด้วย Lanczos โดยไม่ตัดส่วนต้นไม้ทิ้ง แล้ว despill ซ้ำหลังย่อ
- กรอบ fit S3a=(1,6,1188,1286), S3b=(25,6,1193,1286), S3c=(6,6,1193,1286), S3d=(1,8,1001,1301). เลือกระยะด้านข้างต่างกันเล็กน้อยเพื่อให้โคนอยู่ใกล้กลางและขอบยังอยู่ใน tolerance ±2% ของต้นโครง
- ตำแหน่งโคนวัดด้วย midpoint ของ min/max x ที่ alpha≥128 ใน 8% ล่างของ canvas เป็นตัวประมาณเชิงรูปทรง ไม่ใช่ผลทดสอบ collision ในเกม
- ภาพประกอบ: [contact-sheet.png](s3/contact-sheet.png), [zone1-comparison.png](s3/zone1-comparison.png) (โซน 1 แถวบน โซน 2 แถวล่าง); `s3/s3{a,b,c,d}-dark-light.png` วางบน #202020 / #E0E0E0 ที่ขนาดจริง; `s3/s3{a,b,c,d}-edges-400.png` แสดงขอบพุ่ม/กิ่ง/ราก 3 จุดที่ 400% บนทั้งสองพื้น

## จุดที่ต่างจากสเปกและเหตุผล

1. PNG ดิบของแปะก๊วยออกมา 1101×1429 จึงย่อเนื้อภาพทั้งชิ้นลง canvas 1024×1328; เก็บต้นฉบับจริงไว้ ไม่ครอปส่วนต้นไม้
2. พื้น key ที่ image_gen วาดมีการแกว่งของ RGB เล็กน้อย ไม่ได้เป็น #FF00FF/#00FFFF ทุกพิกเซลตามที่สั่ง; เก็บดิบเดิมและค่ามุมภาพจริงใน raw-measurements.json ใช้ chroma dominance แยกและ despill ก่อนส่งออกโปร่งใส แทนการแอบเปลี่ยน PNG ดิบ
3. ระยะว่างล่างของสามต้นแรก =26/1312=1.9817% (ประมาณ 2%) เพื่อให้ bbox ต้นหลักที่ต้นโครงกินถึง y=1312 ยังต่างไม่เกิน 2%; landmark =27/1328=2.0331%
4. มีรอบแก้สี/ตำแหน่งรากเพิ่มเติมจาก prompt ต้นฉบับ; เลือก S3a/S3d จากรอบ refinement และ S3b/S3c จากรอบ anchor เพราะสมดุลสี/โคนดีกว่า เก็บ prompt ที่ใช้จริงทั้งหมดด้านล่าง รวมรอบที่ไม่ได้เลือก
5. พิกเซลเข้าช่วงเสี่ยงไฟยังมี S3a=2, S3b=2, S3c=333, S3d=137 (alpha≥128). มักเป็นไฮไลต์ขนาดเล็ก ไม่เห็นแสงเรืองเป็นมวลจากการดูภาพ แต่ยังต้องตรวจกลางคืนตอนเสียบเกม; ไม่ปรับโค้ดแสงหรือ TREE_TINT. ตามสเปก Toby ต้องพิจารณาปิด tint สำหรับโซน 2 เอง

## การตรวจที่รันจริง

- Python3/PIL + NumPy: ขนาด โหมด alpha bbox, ขอบ ±2%, พุ่ม ≥95%, โคน ±2%, ขอบ canvas โปร่งใส, ตัวนับ chroma-key, HSV สีเสี่ยงไฟ และ SHA-256 อ้างอิงไม่เปลี่ยน
- ตรวจไฟล์ WebP ว่าเป็น VP8L และ decode เทียบพิกเซลก่อนบันทึกตรงทุกค่า
- git status --porcelain --untracked-files=all: ตรวจ scope ของไฟล์ใหม่; ไม่มี tracked file เดิมเปลี่ยน
- เปิดดู contact sheet, ภาพเทียบโซน 1 และ edge crops 400% ทั้ง 4 ชิ้น
- ไม่รัน unit/game/browser tests เพราะไม่มีโค้ดเกมเปลี่ยน; ไม่ได้ตรวจการแสดงผล การชน สเกลจริง หรือแสงกลางคืนในเกม
