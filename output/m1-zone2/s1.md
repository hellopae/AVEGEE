## วิธีส่งออกและจุดต่างจากสเปก

- ต้นฉบับ image_gen 1536×1024 RGB บน magenta #FF00FF อยู่ใน `raw/town-judgment-asia-v2-generated.png` เก็บโดยไม่แก้ไข
- ตัด magenta, despill, resample Lanczos เฉพาะตัว sprite จาก bbox `(43,10,1494,1002)` ให้กรอบ `(20,10,1492,1008)` (กว้างเพิ่มประมาณ 1.45%, สูงเพิ่มประมาณ 0.60%) แล้ว inset alpha 1 px ด้วย MinFilter(3) ตาม §4.1 ไม่มีการวาดเติมฉากหรือแก้ runtime
- เหตุผลการปรับ framing: alpha จางในโครงทำให้ bbox ดิบเริ่ม x=0; กรอบรอบแรกเริ่ม x=43 เกิน tolerance 30.72 px จึงขยายกรอบเล็กน้อยให้ใกล้ bbox ที่สเปกระบุ การ resample เล็กน้อยนี้เป็นขั้นเพิ่มจาก prompt ไม่ใช่การวาดโครงใหม่
- ฐานล่างสุดอยู่ y=1006 (bbox exclusive y=1007) เหลือ 17 px; รักษากรอบใกล้โครงซึ่งเหลือ 16 px แทนการบังคับแตะขอบ canvas ที่ y=1023 ข้อความ “ชิดขอบล่าง” จึงตีความตามโครงและ tolerance ที่ระบุ
- Prompt หลักและ negative คงข้อความอังกฤษตามสเปก มีท้าย prompt เพิ่มขนาดและพิกัดช่วยจัดกรอบ พิกัดในท้ายนั้นเป็นการกะจากภาพ ไม่ใช่ผล segmentation แม้ถ้อยคำใช้ “measured reference framing”; ผลวัดจริงแยกไว้ใน JSON
- เก็บ raw PNG ใน `output/m1-zone2/raw/` ตามสเปก; ภาพเปรียบเทียบ/ขอบและ cutout PNG อยู่ใน `output/m1-zone2/s1/` ตามใบงาน ไม่ใช้ `img/raw/map-zone2/` เพราะเป็นปลายทางของงานควอแดรนต์

## Self-check ตาม §4.2 (ข้อสังเกต ไม่ใช่คำตัดสินรับงาน)

1. **ขนาด/โหมด/bbox:** เปิดไฟล์ปลายทางด้วย Pillow ได้ 1536×1024 RGBA; bbox `(21,11,1491,1007)` ต่างโครง `(21,11,1,1)` px เทียบ tolerance `(30.72,20.48,30.72,20.48)` px บันทึกใน `verification.json`
2. **บันได:** กะจากภาพ treads x≈583–940 หรือ 37.96–61.20% รวม perspective อยู่ในช่วง 39–61% ±2 จุดเปอร์เซ็นต์ ขอบเสาและสิงโตไม่นับเป็นขั้นบันได ค่าเป็น visual estimate ไม่มี segmentation แยกขั้น
3. **บัลลังก์และคบ 2 ต้น:** กะยอดบัลลังก์โครง `(768,16)`/ใหม่ `(755,15)`; centroid พิกเซลเปลวสีส้มเหลืองโครงซ้าย `(450.40,124.95)`/ขวา `(1084.86,125.70)` และใหม่ `(431.98,97.70)`/`(1078.74,98.24)` ต่าง x ไม่เกิน 18.42 px และ y ไม่เกิน 27.46 px เทียบ ±3% =46.08/30.72 px วิธี threshold และ ROI อยู่ใน JSON; centroid เป็น proxy ของตำแหน่งคบ ไม่ใช่การตรวจ placement ในเกม
4. **รูปเคารพ/บัว/ม่านจื่อ/ข้อความ:** เปิดภาพเต็มและ crop แล้วไม่พบรูปเคารพ ข้อความที่อ่านได้ ดอกบัว หรือม่านจื่อ ลายเป็นเมฆโค้งและสี่แฉก สิงโตเป็นสิงโตหินเฝ้าตามสเปก ไม่มีตัวละคร/สัตว์มีชีวิต ไม่มีตราศาสนาที่ระบุได้จากการตรวจครั้งนี้ ยังไม่มีคำตัดสินจากผู้ตรวจวัฒนธรรม
5. **ขอบ:** ตรวจ composites เต็มภาพและ crops 400% บน #202020/#E0E0E0 ใช้ alpha inset 1 px; ตัวตรวจ key residue ไม่พบ visible pixels ที่ R และ B มากกว่า G เกิน 40 พร้อมกัน (0 pixels) ไม่มีแถบ magenta ที่เห็นในภาพตรวจ เปลวมีขอบแดงตามสีไฟจริง การนับสีไม่ใช่หลักฐานสมบูรณ์ของ fringe ทุกชนิด
6. **เข้าชุด Sala:** contact sheet เทียบโครงโซน 1 และ Sala ในภาพเดียว เห็นหินเทาหยก ลายเมฆ ทอง แดงแลคเกอร์ และสิงโตหินที่ต่างจากหินดำ/ลายเปลวไทยเดิม ไม่มีหลังคาเพิ่มเพราะโครงเป็นแท่นเปิด ข้อนี้เป็นข้อสังเกตทางภาพรอผู้ตรวจยืนยัน
