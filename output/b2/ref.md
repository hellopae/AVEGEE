## วิธีอ่านหลักฐาน

`ffprobe` รายงานความยาว 34.258600 วินาที ภาพ 2340×1080, 60 fps เวลาทั้งหมดด้านล่างนับจากต้นไฟล์นี้ ไม่ใช่ตัวเลขเวลาของเครื่องเล่นที่ติดอยู่ในภาพ (ประมาณ 0:45–1:19) ภาพมีแถบควบคุมวิดีโอทับอยู่ตลอด จึงอาจบังชื่อหัวข้อและปุ่มบางส่วน

- [ภาพรวมทุก 1 วินาที](ref-frames/contact-1s.jpg): เรียงซ้ายไปขวา บนลงล่าง ใช้หาช่วงโดยประมาณ ไม่ใช้ระบุจุดเริ่มเอฟเฟกต์แบบละเอียด
- `end-01.png`–`end-13.png`: เฟรม n=1680,1710,…,2040 หรือเวลา 28.0,28.5,…,34.0 วินาที ตามลำดับ ภาพขนาดต้นฉบับ
- `combat-01.png`–`combat-04.png`: เวลา 2.0,9.0,12.0,26.0 วินาที ตามลำดับ ย่อเหลือ 1170×540
- ตรวจภาพนิ่งที่เลือกเปรียบเทียบกัน การเปลี่ยนผ่านระหว่างเฟรมท้ายมีความละเอียด 0.5 วินาที ไม่ได้ยืนยันเวลาระดับมิลลิวินาทีหรือเสียงประกอบ

คำสั่งตัดเฟรมหลัก (เรียกจากราก working directory):

```sh
ffmpeg -hide_banner -loglevel error -i /Users/agapae/agapae-work/refs/battle-ref-20261022.mp4 -vf "fps=1,scale=585:-1,tile=5x7" -frames:v 1 output/b2/ref-frames/contact-1s.jpg
ffmpeg -hide_banner -loglevel error -i /Users/agapae/agapae-work/refs/battle-ref-20261022.mp4 -vf "select='gte(n,1680)*not(mod(n-1680,30))'" -vsync vfr -frames:v 13 output/b2/ref-frames/end-%02d.png
ffmpeg -hide_banner -loglevel error -i /Users/agapae/agapae-work/refs/battle-ref-20261022.mp4 -vf "select='eq(n,120)+eq(n,540)+eq(n,720)+eq(n,1560)',scale=1170:-1" -vsync vfr output/b2/ref-frames/combat-%02d.png
```
