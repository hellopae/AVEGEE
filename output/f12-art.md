สถานะ: **ส่งงานบางส่วน ยังไม่ครบเกณฑ์ข้อ 2** ไม่ใช่การรับรอง QA หรือการรับงานแทนเจ้าของภาพ

ไฟล์ใช้งาน: `img/frontier-route/zone1-2-v4.webp` — 1672×941 RGB, WebP lossless โดยไม่เขียนทับ v3

## งานที่ทำ

- สำรวจและวงตำแหน่ง 27 จุดใน `f12-art/objects.json` และ `f12-art/qa/objects.png` พิกัด normalized ใช้จุดกำเนิดมุมซ้ายบน x/1672 และ y/941
- ใช้ built-in imagegen แก้ v3 โดยมี mask ของเจ้าของภาพประกอบ คัดลอกผลดิบไว้ที่ `f12-art/generated-clean.png` ภาพนี้เป็นวัตถุดิบ ไม่ใช่ภาพส่งมอบ เพราะ generator เปลี่ยนบริเวณอื่นด้วย
- ประกอบเฉพาะ patch หมายเลข **5, 7, 9, 10, 11, 12, 17, 18, 19, 27**: กลุ่มก้อนหิน/เศษหินบริเวณทางเชื่อม ทางแยกกลาง ทางเหนือถ้ำ ทางโค้งบน ทางโค้งขวา และกอพืชบนทางลงซ้าย โดยใช้พื้นจาก imagegen มีภาพขยายเทียบใน `selected-details.png`
- รายการนี้คือ patch ที่แก้ ไม่ใช่คำยืนยันว่าทุกวัตถุใน patch หายทั้งชิ้น ดูข้อจำกัดด้านล่าง
- เก็บพื้นที่เดินเดิมเป็นฐาน ตัด alpha ด้วย mask เดิม ใช้ feather มี support 2px และกันบันได/น้ำด้วย source restoration ไม่เปลี่ยนพิกเซลแม้แต่นอก mask เดิม

## ที่ตั้งใจเก็บและข้อจำกัด

- ราวสะพาน ราวบันได ขอบทาง ขั้นบันได และแอ่งน้ำซ้ายกลางเก็บไว้ รายการกรอบป้องกันอยู่ใน `qa/verification.json`
- ต้นไม้ใหญ่บนเกาะกลางลานซ้ายบน อาคาร ประตู หน้าผา และต้นไม้ที่มีฐานนอกพื้นที่เดินเก็บไว้
- จุดสีส้มใน `objects.png` คือวัตถุที่ยังเก็บไว้: เสา/ต้นไม้/พุ่มที่คร่อมขอบ mask หรือสัมพันธ์กับโครงสร้างริมทาง ไม่ควรอ่านวงสีส้มว่า “ลบแล้ว”
- การทดลองประกอบครั้งแรกพบภาพต้นไม้/เสาขาดเมื่อเก็บเฉพาะชิ้นนอก mask จึงคืนวัตถุเหล่านั้นทั้งชิ้นแทนการส่งภาพที่มีชิ้นส่วนลอย จุดสำคัญที่ยังเหลือคือเสาซ้ายบน หมายเลข 1, ต้นไม้ทางแยกกลาง 6/8 และแนวพุ่มเหนือลานล่าง 22–25
- ดังนั้น **ยังมีสิ่งกีดขวาง/ส่วนวัตถุใน mask และไม่ยืนยันข้อ 2** การลบทั้ง silhouette ของจุดเหล่านี้ต้องมีขอบเขตแก้ภาพที่ครอบคลุม silhouette และยังต้องรักษาราว/บันได ภายใต้ขอบเขตที่ได้รับในรอบนี้เลือกคงพิกเซลนอก mask ไว้

## วิธีทำซ้ำและผลตรวจ

รันจาก repository root: `python3 output/f12-art/build.py` (Pillow + numpy)

ตรวจจากการเปิด **ไฟล์ WebP ที่บันทึกจริง** เทียบ decoded RGB ของ v3:

- ขนาด 1672×941, RGB
- พิกเซลเปลี่ยนทั้งหมด 4,931
- พิกเซลเปลี่ยนนอก mask ขยาย 6px: **0**
- ค่าสูงสุดของ channel diff นอก mask ขยาย 6px: **0**
- พิกเซลเปลี่ยนนอก mask เดิม: **0**
- พิกเซลเปลี่ยนในกรอบป้องกันน้ำ/บันได: **0**
- ขยาย mask แบบ Chebyshev radius 6 (13×13 max filter) บันทึก hash ต้นฉบับและผลลัพธ์ใน `qa/verification.json`
- บันทึกแบบ lossless เพราะการบีบอัด lossy ใหม่จะทำให้พิกเซลนอกพื้นที่แก้เปลี่ยนด้วย

## ตรวจตนเองตามเกณฑ์รับงาน

1. ไฟล์ v4 1672×941 RGB: ตรวจจากไฟล์จริงแล้ว
2. ไม่มีเสา/ต้นไม้/หญ้า/หินบนพื้น mask: **ยังไม่ครบ** ตามจุดที่ระบุข้างต้น
3. นอก mask(+6px) ไม่เปลี่ยน: วัดได้ diff = 0
4. ราว/บันไดริมทางยังอยู่: ตรวจภาพและคืนพื้นที่บันไดจากต้นฉบับ; ตัวเลขกรอบป้องกัน diff = 0 ไม่ใช่หลักฐานแทนการรับงานภาพทั้งหมด
5. README + ภาพ QA: จัดทำแล้วตามรายการ
