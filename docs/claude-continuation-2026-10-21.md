## งานกำลังตรวจ ตอนเจ้าของสั่งหยุด

**Final court → ลงทัณฑ์ → ending02 ผ่าน UI** ยังไม่ปิดทั้งชุด

- เปิดหน้าศาลจริง เห็นบอสถูกมัดและหน้าต่างกระจก เลือกกระจก/krata/taan/intensity5 ได้ ปุ่มออกหมายจาก disabled เป็น enabled และออกหมายแล้วปิดศาลเข้าสู่แผนที่ escort ได้
- รอบแรก UI ไปถึง sentenceScene และภาพคำตัดสินสุดท้าย แต่ seed เก่าของ fixture ใช้ g.zone='cyberhell' โดยไม่ได้สร้าง `g.zoneEvents.cyberhell` กดดำเนินเรื่องต่อแล้ว TypeError ใน releaseBoss ที่เขียน cyberFinal จึงยังรับว่า ending ผ่านไม่ได้
- เป็นความไม่ครบของ fixture ที่ระบุได้ ห้ามเหมารวมว่าเกมจริงพังหรือแก้ gameplay เพื่อหลบข้อผิดพลาด fixture โดยไม่ reproduce กับเซฟจริง
- แก้ fixture ให้มี `{cyberRescue:'cleared',cyberBreach:'cleared',cyberFinal:'active'}` แล้ว reload/ทำกระจกและออกหมายซ้ำเรียบร้อย
- **สถานะสุดท้ายที่อ่านก่อนสั่งหยุด:** phase escort, elapsed ≈234ms / duration3000ms, paused=false ยังไม่ได้ตรวจ sentenceScene→ending02 ซ้ำด้วย fixture ที่แก้ครบ เพราะเจ้าของสั่งหยุด
- fixture ปัจจุบัน (untracked): `output/final-court-review/index.html` ใน release checkout มี importmap/entry UI รุ่น worker-supplies, ซ่อน enter-gate, seed TUTOR/discovery, เรียก startPlay(false) เพื่อให้ world loop ทำงานจริง, มี `#court-state` แสดง phase/completed/ending ผ่าน DOM
- ใช้ปุ่ม “คดีบอสสุดท้าย” ใน fixture แล้วกดกระจก/ตัวเลือกตามเฉลย/ออกหมาย รอ escort3000ms+punishment8000ms กดดำเนินเรื่องต่อจนจบ ending02 ตรวจ console และเซฟ/โหลดซ้ำด้วย
- ก่อนหน้านี้มี state-machine test ผ่านทั้ง gauntlet9ศึก→ending01→ศาล→ลงทัณฑ์→ending02 แต่ยังไม่เท่ากับ UI/ภาพตลอดเส้นทาง

## งานเหลือ ให้ Claude ทำต่อเรียงลำดับ

1. ปิด final court/ending UI ตามจุดค้างข้างบน รวมปิดกลับ/restore/รับทราบไม่วน จับหลักฐานและอัปเดตสถานะอย่างตรงขอบเขต
2. เล่นจริงทั้งสามเส้นทางตั้งแต่ต้นจนจบ ทุก checkpoint/patrol/หนีแล้วกลับ/โหลดระหว่างทาง และยืนยันทีมหลังคุยบอสจริง ไม่ใช้ seed ผ่านด่านแทนหลักฐานการเดิน
3. ตรวจภาพทุกโซน: พื้น/รอยต่อ/เงาอาคาร/ต้นไม้/ขอบทางตามภาพเจ้าของ, ทุก zoom และ viewport แคบ บทสนทนานิรา/วิญญาณ/ผู้ตรวจการและปุ่มไม่บังตัวละคร
4. ตรวจหน้าสอบสวน/รายงาน/เสบียงกับชื่อและไอเท็มประจำโซน 2–4 ผ่าน UI จริง งานเชิงระบบมี tests ไม่ได้แปลว่าภาพทุกจุดผ่านแล้ว
5. ตรวจภาพต่อสู้: ทิศโจมตี, ท่าบาดเจ็บ, ระยะทีม, เมนูพลัง, transition/พื้นดำเอฟเฟกต์/ซูม, โจมตีหมู่อาวุธบอส, Nira sprites/ท่าไม้ตายสี่โซน เทียบคอมเมนต์เดิม ห้ามนับแค่มี asset ว่าผ่านภาพแล้ว
6. เซฟเก่าที่ farewell/เคยไปปลายทางแล้วอาจไม่มีบอสพาเที่ยวซ้ำตามกติกาเดิม Repeat escort ยังไม่ได้ทำ ห้าม reset ของ/เงินเพื่อเปิดทริปใหม่ ต้องแยก first-time grant ถ้าจะทำ
7. รูป S4 มีขีดทับ header/overview/footer แต่ข้อความไม่ได้แจกแจงการลบ ตัวควบคุมเหล่านั้นยังไม่ได้ลบ อย่าอ้างว่าทุกรอย annotation เสร็จแล้ว
8. หลังงานหลัก ค่อยทดลอง Shado `https://studio.playshado.com` ทำไฟ/ลาวา/น้ำ/ควัน/เมฆ/ใบไม้/วิญญาณ และ Hunyuan `https://hy3d.tencent.ai` ทำแท่นตัดสินเทียบต้นฉบับ
