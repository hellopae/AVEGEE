## งานข้อ 1–7 ที่ทำแล้ว

1. **สำรอง 3D:** ย้ายงานเก่า 81 ไฟล์ประมาณ 20.13MiB ไป Backup/3D พร้อม manifest และวิธีกู้คืน เก็บไว้ในเครื่อง ไม่ขึ้นเว็บ บ้าน/ภาพที่ 2D ใช้ร่วมยังคงใช้งานอยู่ การย้ายไม่ได้ลดพื้นที่ดิสก์รวม
2. **แผนที่ใหม่:** Zone1 โลก 3840×2560 จัดตำแหน่งตาม Map-Zone1.jpg เพิ่มท่าเรือ บ้านหลายแบบและเส้นทางข้ามสะพานแบบโค้ง มีลาวา ภูเขาไฟ น้ำแข็ง ป่า แม่น้ำและน้ำตกในภาพหลัก
3. **กล้อง:** ตาม Yama เป็นค่าเริ่มต้น 5× เลือก 3.5×/5×/6.5× ได้ มีดูทั้งแผนที่และ minimap รวมระบบ viewport/DPR/cached sprites ของ main พิกัดคลิกและป้ายอาคารตรงกับกล้อง หลีกเลี่ยงการสร้าง canvas พื้นขนาด 20k เมื่อซูม
4. **งานภาพ:** มีฉากเมือง/ต่อสู้หลักใหม่ + ฉากต่อสู้ภูเขาไฟ น้ำแข็ง ป่า 3 ภาพ + ดันเจี้ยน 9 สถานที่ ภาพใหม่สร้างด้วย built-in imagegen บีบอัด WebP94 และเชื่อมเข้าเกมแล้ว
5. **ต่อสู้:** คิวฝ่ายเรา/ศัตรูตามความเร็ว แสดงรอบปัจจุบันและถัดไป เลือกคำสั่ง→เป้าหมาย→ยืนยัน ยืนเฉียง Perspective คนถึงเทิร์นเดินออกหน้า/กลับที่ โปรไฟล์เรียงตามช่องยืน ทีมใหญ่ใช้สองแนวเฉียง สัดส่วนสมาชิกใกล้กัน รักษา cooldown/ท่าพิเศษ/HP ของ main
6. **เดินทาง:** ชนะบอสเปิดทางชายแดน ต้องเดินผ่านดันเจี้ยนสาม checkpoint ก่อนเข้าเมืองใหม่ เมื่อเดินไปเปิดท่าเรือปลายทางจึงใช้ Fast Travel ได้ทั้งสองเมือง มี Yama/Nira นั่งเรือและลงเรือ ดันเจี้ยนเปลี่ยนภาพตาม checkpoint; แยกตำแหน่ง Nira ให้ไม่บัง Yama ตอนเข้าฉาก
7. **เซฟ/ตรวจระบบ:** ย้ายเซฟเมืองเดิมครั้งเดียว รักษาความก้าวหน้าเมืองที่เคยไป ตำแหน่ง/จุดที่ผ่านในดันเจี้ยนบันทึกได้ ศัตรูไม่ให้ข้ามจุด การหนีไม่ปลด checkpoint
