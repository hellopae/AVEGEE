# Z1-TOUCHUP — ซ่อมพื้นสองจุด · 13 พ.ย. 2569

ชุดส่งต่อให้ Claude ประกอบเข้า `img/map-zone1/v7r/` เท่านั้น ยังไม่ได้ติดตั้งในเกม
ใช้ crop จากไทล์ v7r ใน worktree นี้เป็นภาพแนบให้ **ImageGen ในตัว** จุดละ 1 ครั้ง รวม **2/6 ครั้ง, retry 0/2**
ไม่แก้โค้ดเกม ไทล์ที่ใช้งาน walkmask หรือ sprite และไม่ได้ commit/push/merge/deploy

## ผลและพิกัด

พิกัดทุก rect ใช้ `[x0,y0,x1,y1)` เริ่มมุมซ้ายบน ปลายขวา/ล่างไม่รวม
map 1× = 4915×3277; พื้น v7r 2× = 9830×6554

| จุด | rect map 1× | rect v7r 2× | ผลที่ตรวจจากภาพ |
|---|---|---|---|
| lava-north-stair | `[610,810,866,1066]` | `[1220,1620,1732,2132]` | ขอบใบไม้แดงที่เคยตั้งตรงจบเป็นปลายใบและเงาสัมผัสพื้น |
| heaven-bridge | `[3492,620,3748,876]` | `[6984,1240,7496,1752]` | บริเวณขอบตัดในเมฆใต้ซ้ายสะพานต่อด้วยละอองเมฆนุ่ม |

`native.webp` ทั้งสองภาพเป็น **lossless WebP 512×512** บนกริดเดียวกับพื้น 2× พร้อมวางตรง rect
เป็นภาพส่งมอบที่รับเฉพาะส่วนซ่อมจาก ImageGen ผ่าน mask ไม่ใช่ raw output ของโมเดล
raw output 1254×1254 เก็บแยกเป็น `generated.webp` แบบ lossless

## วิธีประกอบ

1. ตรวจ SHA-256 ไทล์ต้นทางใน `registration.json` ว่ายังตรงกับ v7r ที่จะประกอบ
2. วาง `native.webp` ที่มุมซ้ายบนของ `contextRectPx2x` ขนาด 512×512 โดยไม่ resize/warp เพิ่ม
   `nativeToContextPx2x` เป็น identity; `nativeToMapPx2x` เป็น translation ไปพิกัด global
   มี affine สำหรับ map 1× (`nativeToContextPx1x`, `nativeToMapPx1x`) ให้ด้วย
3. วางได้ทั้ง crop เพราะพิกเซลนอก `edit-mask.png` เป็นต้นฉบับ v7r ตรงทุกพิกเซล
   ขอบ mask feather 8 output px ทำไว้แล้ว ไม่ต้อง blend mask ซ้ำ
4. การเข้ารหัสไทล์ปลายทางแบบ lossy อาจเปลี่ยนพิกเซลเพิ่ม จึงควรตรวจภาพหลังประกอบอีกครั้ง

พื้นที่ที่เปลี่ยนจริงใน native (พิกัด local 2×):

| จุด | bounds พิกเซลที่เปลี่ยน | จำนวนพิกเซล | นอก mask |
|---|---|---:|---:|
| lava-north-stair | `[137,231,221,307]` = 42×38 map px | 4,940 | 0 |
| heaven-bridge | `[224,176,315,270]` = 45.5×47 map px | 5,304 | 0 |

พื้นที่ซ่อมลาวาอยู่ใต้ตีนบันไดและห่างจากขอบชาน ส่วนเมฆซ่อมเฉพาะเนื้อเมฆ
บันได/ราว/ขอบชานลาวาและหินด้านหน้าเก็บจากต้นฉบับ ส่วนตัวสะพานอยู่นอก crop จึงไม่รับพิกเซลสร้างใหม่
บริเวณโครงสร้างที่ระบุใน `checks.json` และทุกพื้นที่นอก mask มีผลต่างพิกเซล 0
ข้อจำกัด: การตรวจนี้พิสูจน์ความคงเดิมในพื้นที่ที่ระบุ ไม่ใช่การวัด semantic edge ทุกเส้นในเนื้อเมฆ

## ไฟล์

แต่ละโฟลเดอร์มี `native.webp`, `registration.json`, `compare.jpg` ตาม brief
และหลักฐาน `source.webp`, `generated.webp`, `edit-mask.png`, `prompt.txt`
prompt ที่ส่งจริงอยู่ใน `prompt.txt` ของแต่ละจุด
`build.py` ทำ registration แบบ similarity จาก SIFT นอกพื้นที่ซ่อม แล้วรับพิกเซลสร้างใหม่ผ่าน mask เท่านั้น
`checks.json` เก็บผลตรวจไฟล์และพิกเซลจากการรันจริง

`compare.jpg` เรียง **ก่อน | หลัง** ที่สเกล zoom 5, จอกว้าง 390 CSS px, DPR 2
จำลองเฉพาะพื้นตาม `src/scene.js::mapViewport` และขนาดโลก `src/town-layout.js`
(465×465 ต่อฝั่ง; อัตราขยายประมาณ 0.908 output px ต่อพิกเซล native)
เป็นการจำลองสเกลกล้อง **ไม่ใช่ screenshot จากเกมจริง** ไม่มี shader/แสง runtime/วัตถุ overlay
