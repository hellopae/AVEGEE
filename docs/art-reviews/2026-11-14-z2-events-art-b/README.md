## คำสั่งตรวจที่รัน

จากราก repo:

```sh
python3 docs/art-reviews/2026-11-14-z2-events-art-b/verify_assets.py
git diff --check
```

`verify_assets.py` จบด้วย exit 0: อ่านและถอดรหัส WebP ครบ 8/8 ตรวจรายชื่อ ขนาด โหมด SHA-256 อัลฟาและมุมโปร่ง ตรวจงบ/retry จากบันทึก และเปิด JPEG contact sheet ได้ รายละเอียดใน `checks.json` ตรวจอัลฟาเทียบ PNG โดยตรงขณะส่งออกด้วย จากนั้น script ตรวจซ้ำกับค่าแฮชที่บันทึกไว้ได้โดยไม่ต้องเข้าถึง PNG นอก repo

`git diff --check` จบด้วย exit 0; เนื่องจากเป็นไฟล์เพิ่มใหม่ทั้งหมด คำสั่งนี้ไม่ได้ตรวจเนื้อหาไฟล์ untracked จึงตรวจ whitespace ของไฟล์ข้อความใหม่ทั้ง 4 ไฟล์ด้วย Python แยกอีกครั้ง ไม่พบ trailing whitespace และทุกไฟล์มี newline ปิดท้าย ใช้ตัวตรวจไฟล์ภาพข้างต้นสำหรับเนื้อหาภาพ ไม่ได้รันเกมหรือชุดทดสอบ gameplay เพราะไม่ได้แก้โค้ดหรือการผูก event ใน branch นี้
