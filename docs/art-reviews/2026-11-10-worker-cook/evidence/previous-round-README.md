### Alpha จุดเท้า และ loop

ตรวจภาพ `evidence/native-alpha-<zone>-<anim>-<dir>-1-4.jpg` และ `-5-8.jpg` ครบ **24 แผ่น / 96 เฟรม / 288 ภาพบนพื้นหลัง** ช่องภาพ 320×320 จริง พื้นขาว ดำ เขียว ไม่เห็นขอบแดงหรือเหลืองแปลกปลอม มีสีแดงผิวคนงาน TH และสีทองของเครื่องแต่งกายตามปกติ หลักฐานเป็น JPEG composite จึงไม่อ้างว่าพิสูจน์การไม่มีพิกเซลสีผิดได้แบบสมบูรณ์หรือทดสอบบนฉากเกมแล้ว

ตรวจพิกเซล alpha จริงพบขอบบน/ซ้าย/ขวาใสทั้งหมด ไม่มีเศษแยกเมื่อใช้ alpha>40 ทุกเฟรมมีพิกเซล alpha ที่ขอบล่าง y=319 ค่านี้กับ manifest anchor ไม่ได้พิสูจน์ว่าตำแหน่งฝ่าเท้าตรงต้นฉบับ ขนาดหัวกับขาที่ต่างยังเป็นข้อค้าง ต้องตรวจร่วมกับ inset/fit ของ renderer หลังวาดแก้

ถอด GIF ครบทุกเฟรมและเทียบกับ sheet หลังรวมพื้นหลัง ค่าความต่างจาก palette ของ GIF ต่ำกว่า 3/255 ต่อช่องสี/พิกเซลโดยเฉลี่ยทุกเฟรม เวลาและจำนวนเฟรมถูกต้อง ภาพเรียงเฟรมกับรอยต่อเดิมอยู่ที่ `evidence/gif-frames-*.jpg` และ `evidence/seam-*.jpg`

**ไม่ได้ดู playback ต่อเนื่องจริง**: ทดลอง inventory ใหม่แล้ว CUA ส่งคืน `browsers=[]` พร้อม `Browsers: Error: The browser access host is unavailable` ความไม่ซ้ำของเฟรมและค่าความต่าง 8→1 ไม่พิสูจน์ว่า loop ลื่น จึงไม่รับรองความต่อเนื่อง
