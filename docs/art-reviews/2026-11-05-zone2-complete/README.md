# โซน 2 — เมืองบูรพา ชุดวัตถุและผังเสนอ

**วาดแล้ว:** Sky / ภูเขาเอเชียหมอก RGBA แยกชั้น และวัตถุ 33 ชนิด (วาดใหม่ 24 / ใช้คลังโซน 1 เดิม 9) จัดวาง 117 ชิ้นบน atlas เดิม 2304×1536 ใช้ **built-in ImageGen 12 ครั้ง** ไม่ใช้ Shado คำสั่งเต็มและภาพอ้างอิงทุกครั้งอยู่ใน `generation-prompts.json` และจำนวนครั้งอยู่ใน `imagegen-ledger.md`

**ตรวจภาพแล้ว:** ดูภาพย่อทีละภาพ ตรวจ contact sheet ภาพรวม และ `style-compare.jpg` แก้ตำแหน่งของตกแต่งที่ฐานลงน้ำก่อนส่ง เก็บภาพวาดพื้นผิวด้าน แสงจากซ้ายบน และหลังคาเอเชียสีหยก/เสาแดง ผังเสนอมีต้นไม้แดงทางลาวา สนเขียวกลางเมือง และสนหิมะด้านบนขวา พื้นต้นทางมีมุม/ผิวที่กำหนดมาแล้ว จึงไม่วาดทับเพื่อเปลี่ยนสไตล์พื้น

**ยังไม่ประกอบในเกม:** ไม่แก้ `src/`, หน้าเกม, tests เกม, walkmask, collision หรือ border topology ไม่ใช่การอนุมัติ QA และยังรอคุณเป้พิจารณาสไตล์/ขนาด/ตำแหน่ง

- `composite-preview.jpg` — ภาพครบทุกชั้น กว้าง 1600 พิกเซล

- `kit-contact-sheet.jpg` / `object-catalog.json` — รวม 33 ชิ้นและ `foot` ของแต่ละไฟล์
- `layout.json` — **ข้อเสนอให้คุณเป้ปรับ ไม่ใช่ผังสุดท้าย** `x,y` มุมซ้ายบน, `w,h` ขนาดบน atlas, `foot` พิกเซลใน PNG ต้นฉบับ, `anchor` จุดแตะพื้นใน atlas; `flipX` พลิกตำแหน่ง foot ตามภาพ; กลุ่ม back/mid/front เรียงตาม anchor.y ภายในกลุ่ม

- `terrain-alpha-preview.png`, `manifest.json`, `tile-review.json` — พื้น/พิกัดและหลักฐานต่อ tile

## ข้อไม่แน่ใจและสิ่งที่ต้องให้เจ้าของกำหนด

1. **ทางออก 2–3 ยังยืนยันพิกัดไม่ได้:** `Map Zone2.ai` อ่านเฉพาะหน้า 1 และภาพผังเก่าระบุทางใต้เพียงแนวเดียว จึงเสนอประตูเข้า (1110,1500) และประตูออก (1110,1245) บนแนวใต้เดิม ไม่ย้าย/วาดทางเชื่อมใหม่ ตำแหน่งและปลายทางทั้งสองเป็นข้อเสนอ ห้ามใช้เป็น border anchor จริงก่อนเจ้าของกำหนด
2. ผังเก่า 2500×1400 กับพื้นใหม่ 2304×1536 มีรูปทรงลานต่างกัน ใช้ลำดับ/ฝั่งของลานและเครื่องหมายต้นไม้อ้างอิง แล้ววางฐานบนพื้นใหม่ ไม่ถือว่าพิกัดในผังเก่าลงทะเบียนตรงพิกเซลกัน `placement-adjustments.json` บันทึกการเลื่อนของตกแต่งกลับขึ้นพื้นทึบ
3. `lan` ใช้รูปทรงแท่นหินแขวนจาก sprite เดิม ส่วน canteen ตีความเป็นซุ้มอาหารเอเชียขนาดเล็ก ต้นไม้ขาวใช้สนหิมะตามทางเลือกใน brief สัดส่วนเทียบโซน 1 ยังรอเจ้าของอนุมัติ
4. ฐานตัวอย่างทึบทุกชิ้น และตรวจระยะฐานสถานี/บ้าน/ต้นไม้/พุ่ม/หินจากแนวเชื่อมเดิมใน `path-reservations.json` แล้ว แต่ไม่ใช่หลักฐานว่าเดิน/เรือผ่านได้ ราวมี front/back แยกแล้ว การบังตัวละครและ collision ต้องทดสอบเมื่อนำเข้าเกม ไม่มีการทดสอบเปิด SVG ใน Illustrator จริง
5. เครื่องมือเบราว์เซอร์แจ้ง `browser access host is unavailable` จึง **ยังไม่ได้ตรวจ UI ในเบราว์เซอร์จริง/มือถือจริง** การตรวจตัวพรีวิวด้านล่างเป็น DOM/Canvas จำลอง และโหลดไฟล์ผ่าน HTTP local จริง

## ผลตรวจที่ทำ

- `python3 scripts/verify_art.py` — SHA-256 ไฟล์พื้น/ของเหลว 72 ไฟล์เทียบต้นทางทุกไบต์; ต่อ PNG และ WebP 15 tile กลับตรง atlas ทุกพิกเซล; ตรวจ RGBA/foot, anchor บน terrain alpha ≥240, 33 id ครบ, SVG ลิงก์สัมพัทธ์ 137 รายการ, HTTP resources และขนาด output <80,000,000 ไบต์ ผลละเอียด `artifact-checks.json` / `source-hashes.json`
- `node --check scripts/preview.mjs` และ `node scripts/check_preview.mjs` — syntax และการทำงานด้วย DOM/Canvas จำลอง ตรวจกล้อง 6 ตำแหน่ง ซูม/เลเยอร์/น้ำ/ลากกล้อง การกลับมุมเดิม ความกว้างจำลอง 390 px และคืน bitmap เมื่อปิด; รายละเอียด/หน่วยความจำจริงตามขนาดไฟล์อยู่ใน `preview-checks.json`
- ดู `composite-preview.jpg`, contact sheet และภาพเทียบสไตล์ด้วยตาแล้ว ไม่สรุปเป็น QA ผ่านหรือการรับรองจากเจ้าของ

สคริปต์ `build_art.py` ใช้ตัด RGBA/ย่อสำเนาพรีวิวและประกอบ ไม่วาดด้วยโค้ด ไม่สร้างภาพแทน ImageGen; ใช้ `--layout-only` เพื่อประกอบจาก PNG สุดท้ายที่ส่งไว้แล้ว การตัดใหม่ทั้งหมดต้องมีภาพต้นฉบับ ImageGen ตาม path ที่บันทึก และคลังอ้างอิง read-only เดิม

## เช็กเกณฑ์รับงานด้วยตนเอง

1. มีเมืองครบชั้นและชุดสถานี ไม่ใช่ภาพร่าง; ดูภาพรวม/เทียบโซน 1 แล้ว **ยังรอเจ้าของรับสไตล์และสัดส่วน**
2. วัตถุแยก PNG RGBA พร้อม foot; พื้นและของเหลวไม่แก้ ยืนยัน hash และ tile reconstruction แล้ว
3. สถานีครบ 11 id พร้อมแท่นตัดสิน บ้านพัก 4 และชุดประกอบ; ตารางด้านบน/JSON ครบ; output ต่ำกว่า 80 MB ดูจำนวนไบต์ในผลตรวจ
4. บันทึก ImageGen 12 ครั้ง ข้อไม่แน่ใจ และสถานะวาดแล้ว/ตรวจภาพแล้ว/ยังไม่ประกอบในเกมแยกกันแล้ว
