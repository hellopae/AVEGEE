# FB3-C3 แบบลูซิเฟอร์สำหรับคุณเป้พิจารณา

แบบเสนอและแผ่นเทียบเสร็จแล้ว มีแบบเสนอหนึ่งภาพ รอคุณเป้อนุมัติก่อนวาดไฟล์เกมทั้ง 7 รายการด้านล่าง

## แบบที่เสนอ

ลูซิเฟอร์ยืนเต็มตัวในมุม 3/4 หันซ้าย เขาดำโค้งเป็นปล้องสองข้างและดวงตาแดงให้กลิ่นปีศาจ ปีกขนนกเป็นชั้นแบบเทวดา ด้านซ้ายของภาพเป็นสีดำถ่าน ด้านขวาเป็นสีขาวงาช้าง ใบหน้าเรียว ผมเงินยาว เกราะดำขอบทอง เสื้อคลุมซับในแดงไวน์ และไม้เท้าคริสตัลทองช่วยให้จำเจ้าของสังเวียนจากแบบเดิมได้

ใช้ ImageGen ในตัว 2 ครั้ง ครั้งแรกขึ้นแบบโดยกำหนดสัดส่วนชิบิหัวโตตัวสั้น เส้นขอบคม แสงอำพัน และพื้นโปร่งใส ครั้งที่สองปรับท่าทั้งตัวให้หันซ้ายและเก็บเขา ปีก และปลายรองเท้าไว้ในเฟรม ใช้ c1 และ c2 เป็นแนวเขาโค้งและปีกขนนก แล้วอิงงานภาพชิบิของเกมจากฉากขุนแผน สีดา และกวนอู [ฉากขุนแผน](../../../img/z1-events/cut-khunphaen-gift-th.webp), [ฉากสีดา](../../../img/z1-events/cut-sita-lamp-th.webp), [ฉากกวนอู](../../../img/z2-events/cut-guanyu-gate-asia.webp)
