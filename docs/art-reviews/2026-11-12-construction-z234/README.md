## สัญญาของภาพและ animation

อ้างอิง `img/construction/th/stage-{1,2,3}.webp` และ manifest โซน 1 ทั้งสามโซนใช้กรอบเดียวกัน:

- ช่องเฟรม 704×704 จำนวน 8 ช่องแนวนอนต่อแถบ ภาพแถบเต็ม 5632×704
- จุดเท้า `[352,640]`, `worldWidth: 256`, 8 fps ทั้งสามระยะ วนหนึ่งรอบต่อวินาที
- WebP แบบ lossless RGBA พื้นหลังโปร่งใสจริง ตรวจข้อมูลไฟล์พบ chunk `VP8L` ทุกแถบ และอัลฟามีค่าตั้งแต่ 0 ถึง 255
- ปรับขอบเขตฉากฐานทุกระยะให้เป็น `[51,114,653,640]` ภายในเฟรม เพื่อคงขนาดและแนววางเท้าเดียวกัน
- ทุกระยะมีเฉพาะฐานราก เครน เสาที่ยังไม่สมบูรณ์ นั่งร้าน และวัสดุก่อสร้าง ไม่มีหลังคาหรืออาคารเสร็จ
- ใช้คนงาน 4 ตัวจาก `img/workers/worker-<zone>-sheet-v2.webp` ของโซนนั้นโดยตรง แถว build (2) และ repair (8) ไม่วาดตัวละครแทนใหม่

ImageGen วาดพื้นฐานระยะละหนึ่งภาพ จากนั้นใช้ Pillow ตัดเซลล์คนงานตาม inset เดิม ย่อ/จัดตำแหน่ง และประกอบ 8 เฟรม การเคลื่อนไหวอยู่ที่ท่าทำงานของคนงาน เครนและวัสดุแขวนยกคงที่ภายในแต่ละระยะ ระยะ 2–3 วาดต่อจากภาพของโซนนั้นเพื่อคงองค์ประกอบเดิม

บันทึกแต่ละโซนเก็บ prompt เต็ม จำนวนครั้ง SHA-256 ของภาพที่เลือก และสูตรจัดเฟรม/คนงาน ภาพสร้างดิบไม่รวมในชุดส่งออก

GIF ใช้พื้นตารางเทาและพาเลต 256 สีสำหรับตรวจภาพเท่านั้น จังหวะ GIF สลับ 120/130 ms เพราะรูปแบบ GIF เก็บเวลาเป็นหน่วย 10 ms รวม 8 เฟรมเป็น 1,000 ms ส่วน manifest เกมกำหนด 8 fps (125 ms ต่อเฟรม) ตามต้นแบบ

## การตรวจที่ทำและข้อจำกัด

รันจากราก repo โดยใช้ Python ที่มี Pillow:

```sh
python3 docs/art-reviews/2026-11-12-construction-z234/check_assets.py
```

ตัวตรวจยืนยันเฉพาะไฟล์ที่ brief ต้องการมีครบ, JSON/ข้อความอ่านได้, WebP และทุกเฟรม GIF เปิดได้, และขนาดภาพถูกต้อง ผลรัน: ภาพ 18 ไฟล์, manifest 3 ไฟล์ และ README ของโซน 3 ไฟล์อ่านได้ตามเงื่อนไขนี้ การตรวจอัตโนมัติไม่ประเมินความสวยหรือคุณภาพการเคลื่อนไหว

ตรวจภาพด้วยตาเพิ่มเติมจากเฟรมแรกของ WebP ทั้ง 9 แถบ และ GIF ระยะ 3 ที่เฟรม 0, 2, 4, 6 ของทุกโซน: เห็นความต่างของวัสดุและความคืบหน้าแต่ละระยะ คนงานใช้หน้าตาของแต่ละโซน และไม่มีหลังคา/อาคารเสร็จ ขยับคนงานด้านหลังของ west ให้พ้นเสากลางหลังตรวจภาพประกอบ

ยังไม่ได้ทดสอบในเกมจริงหรือประเมิน cross-fade ใน runtime ชุดนี้อยู่ในโฟลเดอร์ art review ตาม brief การติดตั้งเข้าสู่ `img/construction/<zone>/` ยังไม่ได้ทำ
