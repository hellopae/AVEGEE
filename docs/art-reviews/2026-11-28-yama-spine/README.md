# ต้นแบบริกยามาชุดสุวรรณภูมิ · ท่าเดินถือสมุด

[ดูจังหวะเดินเทียบทั้งสี่ทิศ](four-direction-walk.gif) · [ดูภาพเทียบ 16 เฟรม](four-direction-comparison.webp)

อ้างอิงชีต `hero-yama-walk-4dir-v2` ที่คุณเป้แนบ ใช้ภาพ WebP ชื่อเดียวกันในเกมกับพิกัดครอปจริงจาก `src/hero-walk-assets.js` เอียงหน้าตามมุมเดิม กอดสมุดติดอก และคงท่ายกเข่าและทรงชายเสื้อของทุกเฟรม ต้นแบบใช้ส่วนหัวซ้ำหนึ่งภาพต่อทิศและเปลี่ยนภาพช่วงลำตัวลงไปตามจังหวะต้นฉบับ ตรวจเทียบครบ 16 เฟรมแล้วว่าช่วงลำตัวลงไปและแนวเท้าตรงกัน ส่วนหัวมีรายละเอียดต่างกันเล็กน้อยตามที่เห็นในภาพเทียบ

- [ข้อมูลโครงและท่า Spine 4.2](yama-th-four-directions.spine.json) มีท่ายืนและเดินถือสมุดทั้งสี่ทิศ ใช้ภาพ PNG ในโฟลเดอร์ `images/` สำหรับ Import Data
- [แผ่นภาพชิ้นส่วน WebP](yama-th-atlas.webp) และ [พิกัดชิ้นส่วน](yama-th-atlas.atlas) ใช้ตรวจขนาดชุด runtime
- แผ่นภาพและข้อมูลรวม 193,572 ไบต์ เทียบกับชีต 16 เฟรมที่จัดวางใหม่จากเซลล์เดียวกันและบีบอัด WebP ด้วยค่าคุณภาพเดียวกัน 319,746 ไบต์ ลดประมาณ 39% สำหรับชุดนี้ก่อนนับ runtime และไฟล์เดิมที่ยังต้องเก็บ ชีต WebP ต้นฉบับในเกมมีขนาด 882,596 ไบต์
- ตรวจด้วย Spine Core 4.2.120 แล้วว่าอ่าน atlas ได้ 20 ชิ้น โหลดแอนิเมชันได้ 8 ท่า และเลือกเฟรมเดินได้ทั้ง 16 เฟรมโดยจุดพื้นอยู่ที่ y=0 ใช้ดูความตรงและขนาดเบื้องต้น ต้นแบบยังไม่ได้ผูกกับการเล่นจริง
