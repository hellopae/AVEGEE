# ชายแดน 1–2 — งานร่าง ยังไม่ผ่านเกณฑ์

- วาดแล้ว: terrain และปากถ้ำอย่างละ 1 ภาพ ด้วย built-in ImageGen รวม **2 ครั้ง** (prompt ใน `generation-prompts.json`)
- ตรวจภาพแล้ว: ตรวจภาพย่อและค่า alpha ของทั้งสองไฟล์ ภาพพื้นมีผังสามระดับและสะพาน แต่ต้นฉบับกว้างเพียง 1536 px; alpha บนพื้นตัวอย่างเป็น 252 ไม่ใช่ 255 จึงยังรับรองทางเดินทึบไม่ได้ ปากถ้ำมีภายในมืดและธรณี แต่ยังไม่ได้แยกชั้นภายในหรือกำหนด foot
- ยังไม่ประกอบในเกม และยังไม่ได้ตรวจในเกม

ยังขาด atlas ≥2300 px, ฉากไกล, ของเหลวและลูป, วัตถุอื่นและ layout, composite, tiles และ tile-review, connection-review, manifest และพรีวิวแบบโต้ตอบ จึงยังไม่สามารถรับรองเกณฑ์ใดว่าผ่านครบได้ ต้องตรวจความต่อเนื่องทางเดินและสัดส่วนกับตัวละครหลังประกอบชั้นจริง ภาพสองไฟล์นี้เป็นร่างสำหรับทำงานต่อ ไม่ใช่แพ็กพร้อมใช้งาน

ข้อไม่แน่ใจ: มุมปากถ้ำและขนาดเมื่อวางบนลานยังไม่ได้ตรวจเทียบตัวละครจริง; จุดต่อกับชายแดนโซน 1 ที่ทำคู่กันยังไม่ได้ตรวจร่วมกัน
