## ภาพและการเคลื่อนไหว

ใช้ **ImageGen ในตัวเท่านั้น 12 ครั้ง**: ของเหลว 8 ครั้ง, เมฆม้วน 2 ครั้ง, ก้อนเมฆ 1 ครั้ง, แก้ลาวาผิว 1 ครั้ง ภาพลาวาชุดต่อเนื่องครั้งแรกถูกแทนด้วยผลแก้ เนื่องจากขอบชุดต่างกันราว 5.6× เหลือภาพต้นทางที่ใช้จริง 11 ภาพ เก็บ lossless WebP ใน `sources/` พร้อม [prompt ทุกครั้ง](generation-prompts.json) การขอ 2048×2048 ได้กลับ 1254×1254 จึงตัดแบบ 2×2 ได้ 627×627 ต่อช่อง ไม่มีการขยายแล้วเรียกว่า native HD

ลาวาผิว ลาวาตก ลำธารฟ้า น้ำตกฟ้า และเมฆม้วน มีชนิดละ **8 เฟรมวาดที่แตกต่างกัน** อ่านเรียง A1–A4 แล้ว B1–B4 ทุกชุด B ใช้เฟรม A4 เป็นภาพตั้งต้น ส่วนลาวาที่แก้ใช้ทั้งชีต A และ A4 เป็น reference แม่น้ำม่วงและ bank foam ใช้ของที่ยอมรับจากรอบก่อน ไม่มี generation เหลือปรับแม่น้ำม่วง

ตัดขอบโปร่งใสรอบน้ำตกแต่ละภาพวาดเพื่อเอาระยะ packing ออก แล้วลดให้ใช้ export rectangle ร่วมกัน ไม่เพิ่มจำนวนเฟรม ไม่ย้ายภาพเดียวไปสร้างหลายเฟรม และไม่เพิ่มข้อมูลด้วยการ upscale รายละเอียด crop อยู่ `sources/*-extraction.json` ไทล์ผิวจับคู่ขอบตรงข้ามภายในภาพเดียวในแถบ 16 px เป็นการเตรียมขอบเชิงพื้นที่ ไม่ผสมภาพคนละเวลา

ใช้ขอบเขตของเหลวเดิม และเกลี่ย alpha **เข้าด้านใน** 2.5 master px เพื่อลดขั้นบันได โดยไม่ขยาย support ของ mask ของเหลว ภาพเปรียบเทียบฝั่งเก่าอ่านชีตและ mask ต้นฉบับที่คัดลอกไว้ใน `reference/` ไม่มีการเปลี่ยน baseline ตาม mask ใหม่

`cloud-sea` ขีดเฉพาะเมฆที่เห็นชัด 4 หย่อมรอบประตูสวรรค์ จากตำแหน่งและสีใน v5 รวม 44,141 master pixels พื้นที่ตั้งใจอนุรักษ์นิยมและยังไม่ครอบคลุมทะเลเมฆทั้งหมด เว้นลาน บันได ทางเดิน สะพาน ต้นไม้ทอง และไม่เลือกหิมะทางขวา ใช้ feather ภายในขอบ polygon เพื่อลดขอบแข็งของ color gate

เมฆม้วนเล่นอยู่กับที่ 3 fps ส่วนก้อนเมฆ RGBA ที่วาดมา 4 ก้อนเป็นภาพวาดนิ่งตามข้อยกเว้นใน brief เคลื่อน 2–3 หน่วยโลก/วินาทีตาม `driftWorld:[dx,dy]` มี `clipRegion:'cloud-sea'` และ mask ที่ตรงกันทุกชิ้น วนตำแหน่งตามกรอบ mask พร้อม periodic copies ที่ขอบ ชิ้นที่เข้าไปในช่องว่างของ mask จะถูกตัดจนมองไม่เห็นและกลับมาเมื่อเดินเข้าพื้นที่ mask อีกครั้ง ไม่มี parallax กล้อง, DOF, การเฟดตามเวลา หรือ bloom ทั้งจอ

## ผลความคมและข้อจำกัด

| ชนิด | เก่า Laplacian variance | ใหม่ | อัตราส่วน |
|---|---:|---:|---:|
| lava | 141.43 | 455.67 | 3.22× |
| lavafall | 87.76 | 140.04 | 1.60× |
| ice-stream | 91.82 | 183.71 | 2.00× |
| waterfall | 59.88 | 126.95 | 2.12× |

วัด grayscale Laplacian variance ที่ซูมส่งออกประมาณ 2.56 px/หน่วย ภายใน mask ที่ erode 7 output px เลือกหน้าต่างที่มี coverage หนาแน่นจาก mask เดิม ไม่เลือกตามภาพใหม่ ใช้เฟรม 0 ทั้งสองฝั่ง ค่านี้เป็นตัวแทนรายละเอียด/contrast เฉพาะบริเวณ ไม่ใช่คำตัดสินทางศิลป์ และรวมการเพิ่ม opacity เพื่อให้เห็นชัดขึ้น (ลาวาผิว .68, ลาวาตก .72, ลำธาร .58, น้ำตก .70) จึงไม่ควรตีความเป็นการเพิ่ม resolution เพียงอย่างเดียว ไม่มี sharpening filter

## Loop review — ข้อค้างจริง

MAE ของ premultiplied RGBA ที่ proxy 128×128 เทียบ A4→B1 และ B4→A1 กับ median ของขอบภายในชุด ห้ามเกิน 1.5× ไม่ผสมเฟรม ไม่ทำ crossfade ไม่ซ่อนรอยต่อด้วยภาพซ้ำ ผลปัจจุบัน:

| ชนิด | ขนาด export ต่อเฟรม | A4→B1 / median | B4→A1 / median | สถานะ |
|---|---|---:|---:|---|
| lava-surface | 627×627 | 1.70× | 1.98× | ยังไม่ถึงเกณฑ์ |
| lavafall | 314×534 | 1.04× | 1.93× | ยังไม่ถึงเกณฑ์ |
| ice-stream | 627×627 | 1.96× | 3.06× | ยังไม่ถึงเกณฑ์ |
| waterfall-ice | 242×541 | 0.95× | 1.81× | ยังไม่ถึงเกณฑ์ |
| cloud-sea | 627×627 | 4.10× | 4.45× | ยังไม่ถึงเกณฑ์ |

ยังมีรอยต่อข้าม generation ที่ไม่สม่ำเสมอ โดยเฉพาะเมฆ ควรใช้คลิปและแถบเฟรมใน `strips/` ประกอบการตรวจ ไม่ถือว่าภาพเคลื่อนไหวต่อเนื่องผ่านเกณฑ์ ภาพวาดครบ 8 เฟรมไม่ได้รับประกัน loop ที่ดี ใช้โควตา 12 ครั้งครบแล้วจึงเก็บปัญหานี้ในหลักฐานอย่างตรงไปตรงมา

## การตรวจและสร้างซ้ำ

ต้องมี Python, Pillow, NumPy, OpenCV และ ffmpeg/ffprobe สคริปต์ทั้งหมดอ่าน/เขียนในโฟลเดอร์รีวิวนี้ ยกเว้นโปรแกรม ffmpeg ไม่เรียก ImageGen เพิ่มเมื่อ build ซ้ำ:

```sh
python3 scripts/build-cloud-mask.py
python3 scripts/build-assets.py
python3 scripts/render-offline.py
python3 scripts/review-clips.py
python3 scripts/verify-artifacts.py
```

- `node --check` ตรวจ syntax JavaScript ใน `index.html`
- `python3 -m py_compile` และ AST parse ตรวจ syntax สคริปต์ทั้งหมด
- ตัว render บันทึกคลิปมุมละ 144 เฟรม 1280×720 12 fps = 12 วินาที ตรวจ container ด้วย ffprobe
- ตรวจ changed pixels นอก cloud mask ที่ 0, .125, .5, 1, 3, 6, 11.9, 80, 300 และ 900 วินาที รวมทั้งจุดเข้าใกล้การวนกรอบ
- ตรวจการมองเห็นและการเคลื่อนจริงของก้อนเมฆแยกทีละก้อนที่ 0 และ 6 วินาที
- ตรวจ sheet dimensions, alpha, references, 8 hashes ที่ต่างกัน, guard พื้นเดิน/สะพาน, หิมะ, prompt count และขนาดรวม

ผลแต่ละ check เก็บใน `verification.json` แยกจากเกณฑ์ศิลป์ ไม่มีการอ้างว่า QA ผ่าน ไม่มีการรันชุดทดสอบเกมเพราะไม่ได้เปลี่ยนโค้ดเกม

## ตรวจตนเองเทียบเกณฑ์รับงาน

1. **ความคม + loop:** มีภาพเทียบและค่าความคมเพิ่มทั้ง 4 ชนิด แต่ loop ยังเกิน 1.5× และ native cell ยังต่ำกว่า ~800 px — **ยังไม่ครบ**
2. **เมฆม้วน + ก้อนลอยไม่ทับพื้น:** มี 8 เฟรมเมฆม้วนและก้อนลอย 4 ก้อนพร้อม clip/wrap และคลิปประตูสวรรค์; coverage ยังเป็น 4 หย่อมปลอดภัยและ loop เมฆยังสะดุด — ต้องดูคลิป/อนุมัติภาพต่อ ไม่อ้างอนุมัติแล้ว
3. **README ไทย + ≤80 MB:** มี README นี้และตรวจขนาดด้วยสคริปต์ (ใช้เพดาน 80,000,000 bytes ซึ่งเข้มกว่า 80 MiB) ดูขนาดจริงใน `verification.json`
