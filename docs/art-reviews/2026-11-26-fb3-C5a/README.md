## แนวทางที่ใช้สั่ง ImageGen

วาดแต่ละจังหวะใหม่โดยยึดตำแหน่งตัวละครและท่าหลักจากภาพเดิม ใช้ภาพขุนแผน สีดา และกวนอูเป็นแบบอนิเมะ chibi รายละเอียดสูง แสงอุ่น และขอบคม ยามาใช้ชฎาทอง ชุดดำขอบทอง ผ้าแดง และเท้าเปล่าตามแบบโซน 1 นิราใช้เสื้อดำ กระโปรงแดง ผมมวย และถือแฟ้ม ยมทัตใช้ผิวม่วง เกราะดำแดงขอบทอง และผ้าคลุมแดงตามภาพท่าเรือและท่าดาบเพลิง

สั่งวาดเต็มกรอบโดยเว้นข้อความทั้งหมด วาดซ้ำฉาก 05 เพื่อคืนมุมสูงเฉียง และปรับฉาก 03–04 เพื่อคืนผู้ชมไกล ๆ ตามภาพเดิม ปรับความกว้างของผลวาดฉาก 03 จาก 1671 เป็น 1672 px ตอนบันทึก WebP
