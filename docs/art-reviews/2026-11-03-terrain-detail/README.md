## ผลตรวจ / ห้ามแทนพื้นทั้งหมดจากชุดนี้

รายละเอียดรอยต่อแผ่นหิน ใบไม้ หิมะ และคริสตัลชัดขึ้นจริง แต่แนวขอบลาน/ขั้นบันไดและหินบางตำแหน่งยังเปลี่ยนเล็กน้อยเมื่อเทียบพิกัดภาพเดิม. ขอบ tile ยังไม่ผ่านการต่อกับเพื่อนบ้าน. โซน2 r1-c1 มีวัตถุขาวคล้ายตัวละคร/มังกรบนเขาด้านซ้าย ซึ่งไม่มีในต้นฉบับและต้องเอาออก. ภาพ TH r2-c3 รอบแรกเปลี่ยนผังมากกว่า จึงลอง prompt รอบสองและเก็บรอบสองเป็นภาพร่างนี้.

ไม่มีการเปลี่ยน zone-skin, townChunkUrl, walkmask หรือซ่อนภาพเบลอด้วยการจำกัด zoom. ยังใช้พื้นเดิมใน runtime จนกว่างานวาดจะผ่านเงื่อนไขด้านล่าง.

## ลำดับทำต่อ

1. แก้ภาพร่างลานกลางให้ขอบลาน ขั้นบันได และปากทางตรงพิกัดต้นฉบับ; เปรียบเทียบ overlay กับ walkmask ในเกมจริง.
2. ทำพื้นที่ข้างเคียงทีละกลุ่มที่ต่อกัน พร้อมตรวจแนวขอบและโทนสี; ห้ามขยาย generation เป็นทุก tile ก่อนแก้ปัญหารอยต่อของกลุ่มแรก.
3. ทำต่อครบ 20 tiles ต่อโซน รวม80ตำแหน่ง; ตอนนี้สร้างภาพร่าง8ตำแหน่ง **ผ่านติดตั้ง0/80**. แถวสุดท้ายสูง205px/คอลัมน์สุดท้ายกว้าง819px ต้องรักษา crop จริง.
4. สร้าง preview จากแผนที่ที่ต่อสำเร็จจริง ตรวจกล้องสูงสุด desktop/mobile ทั้งสี่โซน; ทดสอบเดินบนสะพาน/บันไดและห้ามลงลาวา; จากนั้นจึงเปลี่ยน runtime asset paths และตรวจแสง/flow mask.

หลักฐานต้นฉบับ PNG และภาพเกมตรวจเงาเมฆอยู่ใน Output/Codex/2026-11-03-cloud-organic-detail ภายนอก repo. คิว MAP-DETAIL-4 ยังเปิดเป็นอันดับแรก.
