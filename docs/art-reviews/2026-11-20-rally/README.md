## ขอบเขตและวิธีทำ

แก้ภาพด้วย ImageGen ในตัวเท่านั้น โดยแนบภาพเดิมและต้นแบบที่อนุมัติทั้ง 4 ภาพทุกครั้ง ภาพเดิมเป็นหลักสำหรับองค์ประกอบ ฉาก มุมกล้อง แสง ท่าทาง และตำแหน่งตัวละคร ใช้ Pillow เฉพาะแปลงไฟล์/คืนขนาดเดิมและจัดหน้าภาพเปรียบเทียบ ไม่ใช้วาดชุดหรือตัวละครแทน ImageGen

- ยามา: ชุดเกราะดำ–เงิน ขอบม่วง เส้นวงจรไซแอน หมวกและรองเท้าเข้าชุด คงท่าทางและสมุดเดิม
- ภาพกองหนุน: Guard ม้าซามูไร → กวนอู, Guard นกเกราะดำ → แวน เฮลซิง, Guard ไซเบอร์เดิมที่ถือคทา → WATSON-03
- คงกุมภัณฑ์ยักษ์เขียวโซน 1 และสมาชิกทีมอื่น รวมถึงตัวถือปืนใหญ่ซึ่งเป็นคนละตัวกับ Guard ไซเบอร์

## ผลตรวจและทบทวนเกณฑ์รับงาน

ใช้ ImageGen รวม **5 ครั้งจากเพดาน 10 ครั้ง** ใช้เวลาประมาณ 6 นาทีจากงบ 25 นาที ไม่มีไฟล์ภาพที่ขาดตามรายการ 5 ไฟล์

| เกณฑ์รับงาน | ผลตรวจตนเอง |
| --- | --- |
| 1. ครบ 5 ไฟล์ ชื่อและขนาดตรงเดิม | เปิดอ่านด้วย Pillow ครบ 5 WebP ตรวจชื่อและขนาดกับ manifest ก่อนแก้ตรงกันทุกไฟล์ และ hash ของภาพใหม่ต่างจากภาพเดิม |
| 2. ยามาชุดใหม่ทุกภาพ และ Guard ใหม่ในภาพ 4–5 | ดูผลลัพธ์ครบ 5 ภาพและภาพเปรียบเทียบแล้ว พบชุดเกราะดำ–เงิน–ม่วง เส้นไซแอนของยามาทุกภาพ กวนอู/แวน เฮลซิง/WATSON-03 อยู่ในภาพกองหนุนทั้งสอง ยักษ์เขียวกับทีมอื่นยังอยู่ ไม่พบข้อความใหม่ที่อ่านได้ การตัดสินความตรงแบบสุดท้ายเป็นของผู้ตรวจงานศิลป์ |
| 3. มี compare.jpg และ README ภาษาไทย | มีไฟล์ทั้งคู่ เปิดอ่าน JPEG ได้ ขนาด 2120 × 3751 พิกเซล ภาพเดิมซ้าย/ภาพใหม่ขวาครบ 5 แถว |

ตรวจเพิ่มเติม: hash ของสำเนาต้นฉบับทั้ง 5 ตรงก่อนแก้, SHA-256 ของ MP4 ทั้ง 2 ตรงก่อนแก้, `git diff --check` ไม่พบปัญหา, tracked diff มีเฉพาะ 5 ภาพที่ระบุ และไฟล์เพิ่มทั้งหมดอยู่ในโฟลเดอร์รีวิวนี้ ดูผลบันทึก [validation.json](validation.json)

ไม่ได้รันชุดทดสอบแอป เนื่องจากเป็นงานภาพล้วน ไม่ได้ทดสอบการเล่นในเกม และไม่ถือว่าการตรวจไฟล์นี้เป็นการอนุมัติ QA
