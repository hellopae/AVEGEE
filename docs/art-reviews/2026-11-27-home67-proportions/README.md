# AVEGEE · สัดส่วน HOME-67

ปรับ HOME-67 จากทรงสูงเพรียวเป็นชิบิผู้ใหญ่ให้เข้ากับมูซาชิและเซเวอริน เพิ่มสัดส่วนศีรษะ ลดช่วงขาและเก็บเอกลักษณ์แว่น หมวก เสื้อโค้ต และแผ่นบัญชี ภาพยืนและภาพเดินหันขวา ใช้เส้นเท้าและความสูงที่สอดคล้องกับกรอบเดิม ภาพโปรไฟล์กับคัตซีนตรวจแยกด้วยภาพตัวละครในเฟรมเดียวกัน

ใช้ ImageGen ในตัว 2 ภาพ ภาพแรกวาดท่ายืนเต็มตัวโดยอิงรูปเดิม และภาพที่สองใช้ท่ายืนใหม่เป็นแบบหน้าตา ชุด และสัดส่วน สลับเท้าลงน้ำหนักสี่ท่าแล้วจัดกรอบโปร่งใสให้ตรงกับสัญญา T-WALK
