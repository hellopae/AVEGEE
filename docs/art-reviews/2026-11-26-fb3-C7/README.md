วาดชุดเดินสี่เฟรมต่อคนด้วย ImageGen ในตัว อิงหน้าตาและเครื่องแต่งกายจากภาพยืน ลำดับเป็นลงเท้า ก้าวผ่าน ลงอีกเท้า และก้าวผ่าน ทุกชุดหันขวา เท้าอยู่บนเส้นเดียวกัน โปร่งใสและไม่มีเงาพื้น ขอบภาพจัดจากตำแหน่งช่วงหัวและลำตัวเพื่อลดอาการตัวขยับไปด้านข้างระหว่างก้าว
