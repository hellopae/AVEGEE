## ผลตรวจด้วยตนเอง

1. วันทองหันซ้ายในสไปรต์และโปรไฟล์ และเป็นวิญญาณในฉากขุนแผนบุกกับขุนแผนยอม ฉากมอบของมีสามตัวละครตามภาพเดิม ได้แก่ ยามา กุมารทอง และขุนแผน
2. ฉากขุนแผนทั้งสามภาพและฉากหนุมานยอมเห็นบันไดหิน บัลลังก์กลางแจ้ง ท้องฟ้า และลาวา ไม่มีประตู
3. ฉากท่าเรือเห็นแขนทั้งสองข้างของยมทัตอยู่ต่ำขณะยืนคุย
4. เปิดไฟล์ส่งออกทั้ง 7 ไฟล์ด้วย Pillow แล้วตรวจชื่อ ขนาดพิกเซล โหมดสี และขนาดไฟล์กับต้นฉบับ แต่ละไฟล์อยู่ในเพดาน +15% และเพดาน 450 KB สำหรับคัตซีนหรือ 300 KB สำหรับสไปรต์และโปรไฟล์ รวม WebP จาก 2,286.72 KB เหลือ 2,222.02 KB จุดกึ่งกลางแถวล่างสุดของสไปรต์ที่อัลฟา ≥ 16 อยู่ที่ (570, 1242) px ทั้งก่อนและหลัง นับจากมุมซ้ายบนแบบเริ่มที่ 0
