# Frontier 1 — ภาพร่าง ยังไม่พร้อมใช้งาน

- วาดแล้ว: ภาพร่างแนวคิด `terrain-concept-draft.png` ขนาด 1198 × 1313 px สร้างด้วย ImageGen ในตัว 1 ครั้ง ดู prompt ใน `generation-prompts.json`
- ตรวจภาพแล้ว: `owner-overlay-draft.jpg` ซ้อนภาพร่างที่ปรับขนาดกับผังเจ้าของอย่างละ 50% เห็นบันไดและลานหลักใกล้เคียง แต่ขอบหน้าผา รูปร่างลาน และแนวทางเข้าด้านล่างยังไม่ตรงกันทั้งหมด สีและรายละเอียดต้องตรวจเทียบโซน 1 อีกครั้ง
- ยังไม่ประกอบในเกม และยังไม่ใช่ terrain atlas: ภาพร่างรวมท้องฟ้า ภูเขา น้ำ และพื้นเข้าด้วยกัน ไม่มี alpha สำหรับร่องน้ำ ขนาดยังไม่ถึง 2300 px ไม่มีประตูแยกหรือ foot ไม่มี liquid loop, tiles, manifest, layout หรือ interactive preview
- ยังไม่ตรวจ tile reconstruction หรือความต่อเนื่อง alpha ของทางเดิน จึงไม่มีผลผ่านสำหรับสองรายการนี้
- สิ่งที่ยังไม่แน่ใจ: ความตรงของแนวหน้าผากับผัง การแยกขอบพื้นและของเหลวโดยรักษารายละเอียด รวมถึงการจัดตำแหน่งประตูและ foot หลังแยกชั้น
