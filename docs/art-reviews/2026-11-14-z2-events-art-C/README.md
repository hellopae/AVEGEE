## ภาพอ้างอิงและการตรวจด้วยสายตา

อ่านตารางภาพข้อ 14–21 จากใบงาน Claudy และเรื่องคดีญาติข้อ 7.2–7.7/สรุปข้อ 9 จากบท Rae ของวันที่ 14 พ.ย. 2569 ก่อนสร้างภาพ อ้างสไตล์ กล้อง แสง เส้นขอบ สัดส่วนหัวโต และหางวิญญาณจาก `img/Asia/spirit-officer-asia-v2.webp`, `spirit-business-asia-v2.webp`, `spirit-woman-asia-v2.webp`; ใช้ `img/z1-events/soul-sita-th-profile.webp` อ้างกรอบครึ่งตัว

โปรไฟล์แต่ละคนใช้ตัวเต็มที่สร้างแล้วเป็นภาพอ้างอิงโดยตรง ตรวจคู่ภาพจาก WebP ปลายทางใน [contact-sheet-characters.jpg](contact-sheet-characters.jpg): หน้า ผม หมวก/ปิ่น เสื้อ เกราะ และสีหลักสอดคล้องกันทั้งห้าคู่ การตรวจนี้เป็นการประเมินด้วยสายตา ไม่ใช่การยืนยันอัตลักษณ์อัตโนมัติ ตัวพ่อค้ามีผิวการลงสีละเอียดและนุ่มกว่าทหารเล็กน้อย

รายละเอียดที่เห็นในภาพ: ทหารผอม เปลือกตาบวมและมองออกข้าง; ผู้บังคับการหนวดเรียบ เกราะเก่าขัดเงาและตรวนขาดสองห่วง; พ่อค้าประคองกล่องไม้เปิดเห็นผ้าไหม; พี่สาวผอม มือด้าน ผ้าซิ่นปะและยิ้มอ่อน; หัวหน้าโจรผอม สงบ แววตาเจ้าเล่ห์โดยไม่มีอาวุธ

แก้โปรไฟล์ผู้บังคับการหนึ่งครั้งหลังตรวจ contact sheet: ภาพส่งมอบสุดท้ายกำตรวนสองห่วงด้วยมือเดียวตรงตาราง อีกมือว่างอยู่ที่เอว โดยคงหน้า หมวก หนวด เกราะ และสีชุดจากตัวเต็ม

ตรวจ [contact-sheet-props.jpg](contact-sheet-props.jpg) จากไฟล์ปลายทางแล้ว: ตรวนคู่เดียวมีรอยค้อนที่ห่วงซ้ายและโซ่ขาด; ก้นถ้วยมีลายเปลวไฟสามเส้น เส้นขวาสั้นปลายขาด พร้อมเคลือบใสทับรอยร้าว; ยุ้งโล่งมีข้าวไม่กี่เมล็ด รอยน้ำท่วมและข้าวต้มใสข้างประตู ไม่พบตัวอักษรในภาพเกมจากการตรวจด้วยสายตา ป้ายชื่อใต้ภาพใน contact sheet เป็นส่วนของเอกสารตรวจรับเท่านั้น

อ่านคู่ชื่อทีมจาก `src/data.js`: `taan` = โกคุ, `plerng` = โฮมุระ, `boon` = เมกุมิ, `dam` = คุโร, `guard` = ยักษ์ทวารบาล ชุด C ไม่มีภาพยามา นิรา หรือทีมเดิมให้วาดซ้ำ จึงไม่มีการเปลี่ยนหน้า/ชุดของตัวละครเดิมเหล่านั้น

## คำสั่งตรวจที่รัน

จากราก worktree:

```sh
python3 docs/art-reviews/2026-11-14-z2-events-art-C/verify_assets.py
node --test tests/z2-events-order.test.mjs
git diff --check
```

- ตัวตรวจภาพ: `checked=13 failures=0 alpha_identical=10/10` ตรวจ decode จริง ขนาด โหมด WebP ความโปร่งใส และ SHA-256 พร้อมสร้าง contact sheet สองไฟล์
- ชุดทดสอบเดิม: 16 สำเร็จ / 0 ล้มเหลว / 0 ข้าม, exit 0 มีคำเตือน Node เรื่อง `localStorage` โดยไม่ทำให้ทดสอบล้มเหลว
- `git diff --check`: exit 0 ไม่มีข้อความผิดพลาด
- ไม่ได้เปิดเล่นเกมหรือทดสอบการวางภาพใน UI จริง ผลข้างต้นเป็นการตรวจไฟล์ภาพและชุดทดสอบโค้ดที่ระบุเท่านั้น

ตัวตรวจต้องมี Python และ Pillow หากเครื่องอื่นไม่มี PNG ต้นฉบับในที่เก็บ ImageGen เดิม จะยังตรวจ WebP และสร้าง contact sheet ได้ แต่ค่า `source_alpha_identical` จะเป็น `null` และจำนวนการเทียบอัลฟาจะลดลง รายงานที่ส่งในรอบนี้เทียบต้นฉบับได้ครบทั้ง 10 ภาพ
