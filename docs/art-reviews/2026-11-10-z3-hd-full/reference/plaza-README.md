## ประกอบและรอยต่อ

SIFT + RANSAC partial affine แยกแต่ละส่วน เลือก reference ที่มี inlier มากกว่า (q11/q12 อิง pilot, q21/q22/t31 อิง v5) แล้ว warp จาก native ตรงไปกริด output ไม่ downsample เป็น 1× ก่อน ตัวเลข affine/match/inlier/residual อยู่ใน `registration.json` ไม่มี dense optical flow หรือ local deformation

ลดความต่างสนามสีด้วย Gaussian sigma 35 map px แล้วเลือกแนวต่อที่ความต่างกำลังสองของสีต่ำที่สุดภายใน overlap ใช้ feather 8 output px ต่อด้านของแนว seam ประกอบแถวบน/ล่างก่อน แล้วเชื่อมสองแถว ตรวจภาพเต็มและแถบ seam แล้วไม่พบเส้นแบ่งสี่เหลี่ยมชัดหรือวงลานกระโดดที่แนวต่อในการดูรอบนี้ ลายรอยแตกเล็กที่วาดคนละครั้งยังอาจต่างกันใกล้ seam ต้องเปิดภาพเต็มดู 100% ประกอบการตัดสิน

## ผลวัดความคม

วัดภาพที่ decode แล้วก่อนใส่ sprite ต้นไม้ ใช้ crop ตายตัว ไม่เลือกเฉพาะจุดที่ผลดีที่สุด ค่า primary คือ chunk-local `[0,341,342,683]` ซึ่งทั้งสี่เวอร์ชันมีพื้นที่วาดจริงครอบคลุม ใช้ Lanczos ที่ **2.8 device px/world unit = 2.187589 device px/map px**

Laplacian variance ใช้ grayscale, ksize=1; high-pass เป็นค่าเฉลี่ยกำลังสองของ residual จาก Gaussian sigma=1 device px; FFT ใช้ Hann window และนับพลังงานที่ความถี่ ≥0.25 cycles/device px

| เวอร์ชัน | Laplacian variance | เทียบ v5 | High-pass energy | FFT high-frequency / total |
|---|---:|---:|---:|---:|
| v5 | 75.34 | 1.00× | 13.86 | 0.0172% |
| pilot | 214.62 | 2.85× | 38.57 | 0.0322% |
| 2x2 | 1892.84 | 25.12× | 199.21 | 3.1586% |
| 3x3 | 3158.23 | 41.92× | 235.26 | 5.7937% |

2×2 สูงกว่าเกณฑ์ตัวเลข 1.8×; crop เสริมลาน/บันได/พื้นล่าง/ทั้ง chunk อยู่ใน `sharpness.json` และได้อัตรา Laplacian 53.38× / 23.29× / 31.12× / 25.00× ตามลำดับ ตัวอย่าง 3×3 มี Laplacian ~1.67× ของ 2×2 ใน crop ร่วมเท่านั้น

**ข้อจำกัดของตัวเลข:** ค่าเหล่านี้ตอบเรื่อง edge/texture energy ไม่ใช่ความละเอียดการมองเห็นเพิ่ม 25 เท่าหรือคะแนนความงาม การเพิ่ม contrast, ผิวขรุขระ และการเปิดพื้นที่ที่เคยถูกพุ่มบังมีผลต่อค่า จึงรายงานหลายตัวชี้วัดและหลาย crop พร้อมภาพจริง baseline pilot สำหรับการวัด/ภาพเทียบคือไฟล์ export 2× ของรอบนำร่องที่คัดลอกตรงมา; reference ของการวาดยังเป็น crop จาก pilot base 1× ตามที่ส่งให้เครื่องมือจริง

## โครงสร้างและเสา

ตรวจ local template correspondence บนภาพประกอบกับ v5 + repairs แยกจาก SIFT: 31 จุดตายตัวตามวงลาน ลายกลาง บันได หน้าผา และเสา ใช้ patch 49×49 หลัง difference-of-Gaussian และค้นหา ±12 map px ได้ **26/31 จุดที่ correlation ≥0.6 ระยะเลื่อนสูงสุด 1.414 px, p95 1 px** จุดที่ไม่มั่นใจ 5 จุดยังอยู่ใน JSON ไม่ปัดทิ้งเพื่อประกาศผล ตัวอย่าง 3×3 ตรวจได้ 6 จุดที่มั่นใจ ระยะสูงสุด 1 px

ผลจุดตรวจสอดคล้องกับกรอบ ≤4 px แต่ **ยังไม่ได้ยืนยันทุกเส้นขอบเชิงความหมาย** และ patch ตำแหน่งหนึ่งไม่พิสูจน์รูปทรงทุกพิกเซล โดยเฉพาะขอบที่เดิมมีพุ่มบังและขั้นบันไดซ้ำ เก็บ `semanticStructureVerified: false` และ `wholeStructureWithin4pxVerified: false` ไว้ จึงไม่ประกาศ QA ผ่านหรือรับรอง acceptance ข้อ 3 ครบทั้งหมด

crop ล่างติดยอดเสาสะพาน/ราวเดิมจริง จึงกำชับ q21/q22 ให้เก็บเสา/ราวจาก v5 แม้ pilot ลบออก ภาพประกอบยังมีเสาทั้งสองฝั่ง ไม่ได้ export ราวแยกในรอบนี้ **งานรอบเต็มต้องวาดราวแยกหน้า/หลัง** เพื่อให้ตัวละครถูกบังได้ถูกต้อง ไฟล์เดิมใน `img/` ไม่เปลี่ยน

ภาพเทียบใส่ sprite ต้นไม้เดิมของ pilot ด้วย rect/foot เดิมเหมือนกันทุกช่อง เก็บเฉพาะ 7 sprite ที่ตัดกับ chunk ใน `inputs/sprites/` และพิกัดใน `inputs/sprites.json` พิกัดเหล่านี้ยังมี `placementVerified: false` ตามหลักฐานรอบก่อน; v5 ยังมีต้นไม้ baked เดิม จึงอาจดูรกกว่าเมื่อใส่ sprite ซ้ำ
