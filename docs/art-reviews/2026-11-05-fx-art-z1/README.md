## ไฟล์สำหรับผู้ประกอบเกม

- `fx-manifest.json`: 25 รายการ มี `id, sheet, frameW, frameH, frames, fps, loop, tileable, blend, suggestedPlacement` และ `playbackOrder` ชัดเจน พิกัด **ok-space 2500×1759**; ภาพอ้างอิงจริงสูง 1758 จึงเผื่อแถวล่างว่าง 1 px
- `sheets/<id>.webp`: ทุกชิ้นแถวเดียว RGBA lossless, `frameW×frames` โดยสูง `frameH` มีเฟรมต้นฉบับ 6 หรือ 8 เฟรม ไม่เพิ่มเฟรมหลอก
- `clouds/<id>.png`: ภาพเฟรมแรกของเมฆ 6 ก้อนแยกไฟล์พร้อม alpha สำหรับดู/นำไปวาง; การเล่นจริงใช้ sheet
- `preview/<id>.gif`: เล่นตาม `playbackOrder` บนพื้นม่วงเข้มสำหรับตรวจภาพ ไม่ใช้ GIF เป็น asset ในเกม
- `strips/<id>-frame-strip.jpg`: เฟรมวาดทั้งหมดเรียงตามลำดับต้นทาง และ `frame-strip.jpg` เป็นสารบัญ 25 ชิ้น
- `loop-review.json`: ค่าต่างเฟรมต้นทาง, ค่ารอยต่อก่อนเลือกลำดับ, ลำดับจริง, ค่า loop สุดท้าย, hash ของทุกเฟรม และผลขอบ tile
- `style-compare.jpg`: ภาพ ok เทียบกับ FX ที่ซ้อนบน proof **เรนเดอร์ออฟไลน์ด้วย Pillow ไม่ใช่ screenshot browser**; `evidence/` มีภาพประกอบออฟไลน์และ tile ซ้ำ

พิกัดต้นไม้และเสาไฟอ้างจาก `layout.json` ของงาน `2026-11-05-zone1-layout`; พื้นที่แม่น้ำ/ลาวาและใต้สะพานอ่านจาก proof และ terrain-registration แนะนำตำแหน่งด้วยตา ไม่ใช่พิกัด emitter ที่ผ่านการเล่นในเกม เมฆมีค่า parallax 0.35 (ใกล้) / 0.18 (ไกล)

`suggestedOpacity` ใช้ระดับคงที่ต่อชิ้นในการประกอบ (หมอก 0.42, ฟองตลิ่ง 0.5, ลำแสง 0.25, ฝุ่น 0.65) ไม่ใช่การสร้างเฟรมเฟด ภาพ GIF/strip แสดงเฟรมวาดระดับ alpha ของ asset เดิมเพื่อให้ตรวจได้ชัด

## ผลตรวจ loop และขอบ

คำนวณ MAE ของ premultiplied sRGB+alpha บน union ของพื้นที่ที่ alpha > 0.015 แล้ววัด `N→1 / ค่าเฉลี่ยเฟรมติดกัน` เกณฑ์ ≤ 1.5 ตรวจซ้ำจาก **ไฟล์ WebP ที่เปิดกลับมา** ทุกชิ้นมี hash เฟรมต่างกันครบจำนวน

25 ชิ้นมีค่า loop ที่ใช้เล่นอยู่ในเกณฑ์ ตัวเลขไม่รับรองความเป็นธรรมชาติของทิศไหลหรือความเร็ว ต้องดู GIF/strip ประกอบ ชิ้นที่ loop ตรงไม่อยู่ในเกณฑ์และเปลี่ยนเป็น pingpong ได้แก่ `cloud-01`, `cloud-04`, `cloud-far-02`, `god-ray-01`, `air-dust` ไม่ใช้การเฟดแทรก เฟรมหัว/ท้ายของ pingpong ไม่เล่นซ้ำค้าง

`spirit-river` และ `lava-surface` ต่อขอบ **แกน x เท่านั้น** ซ่อมสีขอบซ้าย–ขวาใน band 20 px ของแต่ละเฟรมโดยเฉลี่ยเชิงพื้นที่ ไม่แตะลำดับเวลา ค่า pixel-difference ที่คอลัมน์ขอบซ้าย–ขวาหลัง export เป็น 0 ทุกเฟรม เก็บค่าก่อนซ่อมไว้ด้วย ภาพ repeat แสดง 3 tile ในแนวนอน; แนวตั้งไม่ได้ระบุว่าต่อได้

## เปิดหน้า review และตรวจซ้ำ

ต้องมี Python 3, Pillow, numpy, Playwright และ Chromium ที่ Playwright ใช้ได้ จากราก worktree:

```sh
python3 docs/art-reviews/2026-11-05-fx-art-z1/scripts/build.py
python3 -m http.server 8943 --bind 127.0.0.1 --directory docs/art-reviews/2026-11-05-fx-art-z1
# เปิดอีก terminal หลัง build จบ
python3 docs/art-reviews/2026-11-05-fx-art-z1/scripts/verify.py --port 8943
```

เปิด `http://127.0.0.1:8943/index.html` ใช้ HTTP เพราะมี fetch หน้า review มีซูม 1×/2×, เลื่อนกล้อง, เล่น/หยุด, เปิด/ปิด FX, เลือกชิ้น, ปิดการเคลื่อนตำแหน่งเพื่อดูเฟรมล้วน และโหลด sheet เฉพาะ placement ที่เข้ากล้อง GIF ด้านล่างโหลดใกล้ viewport และถอด src เมื่อนอกจอ

`verification.json` บันทึกผลสคริปต์จริง: เปิดกลับ 25 sheets, ตรวจขนาด/hash/จำนวนเฟรม/รอยต่อ/GIF/ไฟล์อ้างอิง/ขนาดรวม สคริปต์เตรียม browser checks ที่ 1440×1100 และ 390×844 แต่ **ยังรันส่วน browser ไม่ได้**: Chromium ถูก sandbox ปฏิเสธ MachPortRendezvous `Permission denied (1100)` และ in-app browser แจ้ง host unavailable จึงไม่มีหลักฐานทดสอบเล่น–หยุด ซูม/เลื่อน หรือ responsive ด้วย browser และไม่ได้อ้างว่า QA ผ่าน

คำสั่งที่รันจบสำหรับแพ็กภาพ: `python3 docs/art-reviews/2026-11-05-fx-art-z1/scripts/verify.py --art-only` ส่วนคำสั่งโดยไม่ใส่ `--art-only` ลองแล้วและติดที่เปิด Chromium ผลนี้ **ไม่ใช่การทดสอบเกม**

ตรวจ JavaScript ด้วย `node --check` แล้วไม่พบ syntax error และทดสอบ HTTP ของไฟล์ส่งออก 102 path ได้สถานะ 200 ตาม `static-review.json` การตรวจสองอย่างนี้ไม่ได้ยืนยันการโต้ตอบใน browser
