# E4b · แวน เฮลซิง v2 · 20 พ.ย. 2569

แบบเสนอให้คุณเป้อนุมัติ ยังรอการอนุมัติด้านศิลป์

- [แบบเดี่ยว v2](guard-vanhelsing-west-v2.webp)
- [v2 เทียบยามาชุดโซน 3](guard-vanhelsing-west-v2-with-yama.webp) — Guard ซ้าย ยามาขวา เท้าอยู่แนวเดียวกัน
- ทั้งสองไฟล์เป็น WebP lossless ขนาด **1024×1536** พื้นหลังเทาเข้มเรียบ ยืนเต็มตัว มุม 3/4 หันขวา

คงชายแก่ผมหงอก หนวดเรียบ ตาละเอียดไม่ยิ้ม เสื้อคลุมยาวสีเข้ม กระเป๋าหนัง ซองไม้แหลม และขี้ผึ้งห่อผ้าที่เข็มขัด เพิ่มหมวกปีกกว้างสีน้ำตาลเข้ม ถือหน้าไม้ธรรมดามือขวาปลายลง และคงตะเกียงแสงขาวในมือซ้าย ใช้เส้นขอบเข้ม สัดส่วน chibi และกลุ่มเงาแบบทีมเดิม เป็นภาพแบบสำหรับอนุมัติ

แนบ [v1](guard-vanhelsing-west-v1.webp), [สไตล์ Guard ไทย](../../../img/crew-combat-v1/th/guard.webp) และ [ยามาโซน 3 เฟรมแรก](../../../img/yama-animation-v1/west/sword-idle.webp) ทุกครั้ง ภาพเทียบแนบ v2 เพิ่มด้วย ยามาคงหมวกเขา ชุดขนสัตว์ รองเท้าบูต และดาบสีเงินตามชุดโซน 3

ใช้ **ImageGen ในตัว 2 ครั้ง** ภายในงบ 15 นาที; [พรอมป์ต์เต็มและลำดับไฟล์แนบ](guard-vanhelsing-west-v2-prompts.md) แปลง PNG เป็น WebP ด้วย Pillow แบบ lossless โดยไม่วาดเพิ่ม ครอป หรือปรับขนาด

ตรวจที่ทำ: เปิดภาพทั้งสองดูรายละเอียดตามโจทย์ ไม่พบตัวอักษร เลือด ไม้กางเขน สัญลักษณ์ศาสนา หรือใบมีดหมุน ใช้แบบนักล่าทั่วไปโดยไม่ได้อ้างภาพนักแสดงหรือภาพยนตร์ ตรวจรูปแบบไฟล์ ขนาด พื้นหลังทึบ และความตรงกันของพิกเซลกับ PNG แล้ว ไม่รันทดสอบเกมเพราะไม่มีการแก้โค้ด
