## วิธีทำ

ตัดต้นฉบับตามกริดก่อนส่ง ImageGen ทีละเฟรม พร้อมภาพแบบอนุมัติ ใช้ built-in ImageGen 9 ครั้ง (8 ท่าหลัก + retry hurt เฟรม 3 หนึ่งครั้งเพราะเสื้อครั้งแรกยังไม่มีลาย cyan ครบ) prompt จริงอยู่ใน [prompts.md](prompts.md) ไม่มีการส่งทั้ง sheet เพื่อวาดใหม่

ใช้ Pillow ย่อรายละเอียดภาพใหม่ตาม bbox พิกเซลทึบของต้นฉบับ แล้วประกอบเฉพาะชุด/หมวกภายใน alpha silhouette เดิม พื้นหลังผล ImageGen เป็นโปร่งใส แต่มี alpha จางมากรอบนอก จึงใช้ alpha ≥ 128 สำหรับการจัดขนาด ไม่ใช้ bbox ของ alpha > 0 จากภาพวาดใหม่เป็นฐาน ขอบ alpha ของไฟล์ส่งใช้ต้นฉบับทุกพิกเซล จึงไม่เพิ่มขอบหรือเลื่อนเท้า

เก็บพิกเซลต้นฉบับใน mask ผิวแดง/หน้า/เขา/มือและ polygon ดาบ รวมตา คิ้ว ปาก และแสงขอบดาบ แล้วนำกลับทับรายละเอียดชุดใหม่ ช่องว่าง texture ที่เกิดจาก silhouette ต่างกันเล็กน้อยเติมด้วยสีชุดใหม่ที่ใกล้ที่สุด ไม่มีการวาดหน้า/ดาบทับด้วย Pillow

idle ใช้ภาพใหม่จากเฟรม 0 เป็นฐานทั้งหกเฟรม และยืดแนวตั้งตามความสูงเดิมเพียง 0–2 px โดยล็อกแนวเท้า เก็บหน้าของแต่ละเฟรมเดิมจึงยังมีลืมตา → หรี่ตา → หลับตา → ลืมตา ส่วนดาบและ alpha ของแต่ละเฟรมใช้ของเฟรมนั้นโดยตรง

**เฟรมที่ขาด: ไม่มี** — ครบ 13 เฟรม ไม่มีเฟรมที่ต้องใช้ภาพเดิมทั้งเฟรมแทนชุดใหม่
