# Y2 — ชุดยามาโซน 4 ใหม่ (G9)

แก้เฉพาะภาพคัตซีนชุด Y2 จำนวน 11 ไฟล์ วันที่ 20 พฤศจิกายน 2569 ใช้ branch/worktree ที่ได้รับมาเดิม งานนี้ไม่มีการแก้โค้ดเกม

## แบบและวิธีสร้าง

แนบภาพเดิมเป็นเป้าหมายแก้ไข และ [แบบชุดที่อนุมัติ](../../2026-11-20-design-approval/yama-cyberhell-costume-v1.webp) เป็นภาพอ้างอิงทุกครั้ง ใช้ ImageGen ในตัว 12 ครั้ง: 11 ภาพ + สร้าง valkyrie-spear ใหม่ 1 ครั้งเพราะผลแรกสเกล/ผืนคลาด ผลแรกนั้นไม่ได้ใช้ในเกม

ชุดใหม่ใช้หมวกแถบไฟฟ้าฟ้าและอัญมณีฟ้า เสื้อคลุมดำม่วง ขอบม่วงเงิน ลายกนกเชื่อมกับเส้นวงจรนีออนฟ้า เก็บท่าต่อสู้และพร็อพของแต่ละภาพไว้ ไม่เพิ่มดาบจากภาพอ้างอิงในคัตซีนที่เดิมไม่มีดาบ

## จุดเท้าและการตรวจ

ใช้ Pillow อ่านและถอดรหัสไฟล์จริงทั้ง 11 ภาพ ตรวจชื่อ ขนาด โหมดสี จำนวนเฟรม และกริดเต็มผืน พร้อมยืนยันว่าเนื้อไฟล์ใหม่ต่างจากเดิม บันทึก SHA-256 เดิม/ใหม่และผลวัดใน [checks.json](checks.json)

เทียบแพตช์รองเท้าเดิมกับภาพใหม่ด้วย NumPy: ภาพเทา หาค่าเฉลี่ยความต่างสัมบูรณ์ต่ำสุดเมื่อเลื่อน dx/dy ทีละ 1 px ในช่วง −8 ถึง +8 พิกัดเริ่มที่มุมซ้ายบน ผลด้านล่างเป็นค่าประมาณการเลื่อนแพตช์ ไม่ใช่หลักฐานว่าเส้นขอบทุกพิกเซลหรือรายละเอียดพื้นหลังเหมือนต้นฉบับทุกจุด

| ภาพ | ผลแพตช์รองเท้า (dx, dy), px |
|---|---|
| atk | (-1, 0); (-1, 0) |
| fire | (0, 0); (0, 0) |
| hypno | (0, -1); (-1, 0) |
| ice | (0, 0); (0, 0) |
| mirror | (0, -1); (0, -1) |
| roar | ไม่มีเท้าในเฟรม (ภาพครึ่งตัว) |
| clock-reset | (0, 0); (0, 0) |
| flame-charge | (0, 0) — ปลายรองเท้าที่เห็นในท่าลอยตัว ไม่ใช่จุดสัมผัสพื้น |
| rage | (0, -1); (0, 0) |
| valkyrie-spear | (0, -1); (0, -1) |
| wind | เท้าถูกเอฟเฟกต์บังตามต้นฉบับ |

ภาพที่มีแพตช์รองเท้าให้วัดพบค่าการเลื่อนสูงสุด 1 px ต่อแกน อยู่ในช่วง ±2 px ตามวิธีวัดนี้ ภาพ roar และ wind ไม่มีจุดเท้าที่เห็นให้ยืนยันโดยตรง

ตรวจด้วยตาจากภาพเดิม/ภาพใหม่: คงตัวละครผิวแดง เขา ใบหน้าและอารมณ์เดิม ท่า/พร็อพและเอฟเฟกต์หลักอยู่ในองค์ประกอบเดิม ไม่มีตัวอักษรหรือเลือดเพิ่ม ผล ImageGen มีการวาดรายละเอียดเส้น/แสงบางส่วนใหม่ จึงไม่ได้อ้างว่าพิกเซลนอกชุดเหมือนต้นฉบับทุกพิกเซล

## ชุดพรอมป์ต์ที่ใช้

พรอมป์ต์ร่วม (ปรับชื่อฉากและขนาดตามแต่ละไฟล์):

> Use case: precise-object-edit. Image 1 is the edit target; image 2 is only the approved costume reference. Change only Yama hat and clothing surfaces to black-purple, purple-silver trim, cyan luminous hat band and forehead gemstone, cyan circuit-kanok traces on coat/cuffs. Keep original face, red skin, horns, expression, pose, hands, scale, silhouette and boot positions within 2px. Preserve original scene, props, effects, lighting, camera and rendering style. Do not copy reference pose or add its sword. No text, blood or new objects. Opaque RGB; retain original canvas dimensions.

ข้อกำชับเฉพาะฉาก: atk เก็บลำไฟและหิน; fire เก็บลูกไฟ/เสา/คบเพลิง; hypno เก็บเกลียวม่วงเขียวและผี; ice เก็บผลึก/วงเวท/ลำพลัง; mirror เก็บกระจกทอง ภาพในเศษกระจกและเงาสะท้อน; roar เก็บเสือไฟและเฟรมครึ่งตัว; clock-reset เก็บโล่นาฬิกา ลูกศรและยมทูต; flame-charge เก็บท่าพุ่งและไฟที่ทับตัว; rage เก็บพื้นที่ดำ เปลวไฟและลาวา; valkyrie-spear เก็บหอก/มือจับ/อาร์กพลัง; wind เก็บพัดขนดำและเส้นลมที่บังเท้า

รอบแก้ valkyrie-spear ย้ำ full bleed 1672×941 ไม่เติมขอบดำ ไม่ย่อหรือเลื่อนตัว และตรึงตำแหน่งรองเท้าซ้าย x0..125/y755..830 รองเท้าขวา x695..878/y800..870 ปลายหอก x1606/y458 และหมวก x345..622/y150 ตามต้นฉบับ

## ตรวจตนเองตามเกณฑ์รับงาน

1. ครบ Y2 11/11 ไฟล์ ชื่อเดิม ขนาด/เซลล์/1 เฟรม/RGB ตรงต้นฉบับ ตรวจด้วยการอ่านไฟล์จริง; จุดเท้าจากแพตช์ที่เห็นเลื่อนสูงสุด 1 px ต่อแกน ข้อยกเว้นการมองเห็นและข้อจำกัดการวัดระบุข้างต้น
2. ตรวจเทียบกับแบบ: มีแถบหมวก/อัญมณีฟ้า เสื้อดำม่วงและวงจรฟ้า หน้า เขาและผิวแดงยังเป็นยามาคนเดิม องค์ประกอบ/ท่า/เอฟเฟกต์หลักคงเดิม มีความต่างระดับรายละเอียดจากการสร้างภาพ
3. มี compare.jpg เดิม | ใหม่ครบทุกไฟล์ และ README ไทยนี้ พร้อม checks.json เป็นหลักฐานทางเทคนิค

การตรวจที่รัน: metadata/decode assertions ด้วย Pillow, การเทียบแพตช์ด้วย NumPy และ git diff --check ไม่รันชุดทดสอบโค้ดหรือเกม เพราะเป็นงานภาพล้วน ยังไม่มีการทดสอบแสดงผลในเกมหรือการรับรอง QA
