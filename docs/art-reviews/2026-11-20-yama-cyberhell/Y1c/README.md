## สิ่งที่เปลี่ยนและรักษาไว้

เปลี่ยนหมวกและเสื้อคลุมให้ดำม่วง ขอบม่วงเงิน เส้นวงจรนีออนฟ้า ลายกนกแบบวงจร แถบไฟฟ้าฟ้าบนหมวก และอัญมณีฟ้าด้านหน้า แปลรายละเอียดต้นแบบให้เข้ากับลายพิกเซล/ลายเส้นของภาพเดิมแต่ละไฟล์ ไม่ใส่ตัวอักษรหรือเลือด

ImageGen วาดรายละเอียดชุด จากนั้นใช้ Sharp จัดภาพกลับเข้าพิกัดเดิมและรับเฉพาะบริเวณหมวก/เสื้อผ้า ใช้พิกเซลเดิมนอกบริเวณแก้และบริเวณที่กันไว้ รักษา alpha ของต้นฉบับทุกพิกเซล บันทึก WebP แบบ lossless ไม่วาดใบหน้าใหม่ลงไฟล์ส่งมอบ

คงถ้วยชา ไอน้ำ เสื่อ เปลวไฟ มือ เท้า และดาบเดิม ภาพ KO ยังคง 640×320 หัวซ้าย เท้าขวา นอนสลบ ตำแหน่งบนผืนเดิม ไม่มีเฟรมหรือคลิปเพิ่ม

## การตรวจที่รัน

1. เปิดต้นฉบับและผล ImageGen ทุกไฟล์ ตรวจภาพเทียบหลังประกอบบนพื้นตารางโปร่งใสครบ 7 แถว
2. ตรวจด้วย Pillow โดยอ่านต้นฉบับผ่าน `git show HEAD:<path>` แยกจากการประกอบภาพ: ชื่อ ขนาด RGBA และจำนวนเฟรมตรงกันทั้ง 7 ไฟล์; alpha ต่างกัน 0 พิกเซลทุกไฟล์
3. เปรียบเทียบ RGBA ของพิกเซลที่มองเห็น (alpha > 0) ในบริเวณเท้า: ต่างกัน 0 พิกเซลทั้ง 7 ไฟล์ จึงรักษาตำแหน่งเท้าที่มองเห็นเดิม (0 px ภายในเกณฑ์ ±2 px)
4. เปรียบเทียบบริเวณหน้าส่วนกลางที่บันทึกใน JSON: ต่างกัน 0 พิกเซลทั้ง 7 ไฟล์ ตรวจพิกเซลแดงของเขาในบริเวณที่กำหนด: ต่างกัน 0 พิกเซลทั้ง 7 ไฟล์ การตรวจด้วยตาประกอบแสดงหน้า เขา และผิวเดิม
5. ตรวจขอบเขตไฟล์ด้วย `git status --short` / `git diff --stat` และตรวจ whitespace ด้วย `git diff --check`

การตรวจ RGB ใต้พิกเซลโปร่งใสเต็ม (alpha = 0) แบบเข้มงวดพบความต่างจาก encoder ซึ่งอาจล้างค่าสีที่มองไม่เห็น จึงตรวจ alpha ทั้งผืนแยกจากสีของพิกเซลที่มองเห็น ไม่อ้างว่าไบต์หรือ RGB ใต้ความโปร่งใสเต็มเหมือนเดิม

ระหว่างตรวจพบขอบดำใต้แก้มและพิกเซลแดงบริเวณเขาของภาพสลบบางส่วนเปลี่ยน จึงเพิ่มบริเวณป้องกันและรันตรวจชุดสุดท้ายอีกครั้ง ผลสุดท้ายตาม JSON ไม่ใช่ผลจากรอบก่อนแก้

ไม่ได้รันเกมหรือทดสอบการเล่น งานนี้ไม่มีการเปลี่ยนโค้ด ไม่มีการอ้างว่า QA ในเกมเสร็จแล้ว

## ตรวจตนเองตามเกณฑ์รับงาน

1. **ครบไฟล์/โครงสร้าง/เท้า:** มี Y1c ครบ 7 ไฟล์ ชื่อเดิม ขนาดและเซลล์เดิม RGBA เดิม 1 เฟรมเดิม alpha ทั้งผืนตรงต้นฉบับ และพิกเซลเท้าที่มองเห็นตรงเดิม รายละเอียดผลในตารางและ JSON
2. **ชุดและตัวละคร:** ตรวจภาพเทียบเห็นแถบไฟ อัญมณีฟ้า เสื้อดำม่วง และวงจรกนกฟ้าตามแบบอนุมัติ ใช้หน้า เขา ผิวและท่าเดิม; ผลตรวจหน้าส่วนกลางและพิกเซลแดงบริเวณเขาที่กำหนดต่าง 0 พิกเซล
3. **เอกสาร:** มี `compare.jpg` เดิมซ้าย/ใหม่ขวาครบทั้ง 7 ไฟล์ และ README ภาษาไทยนี้ พร้อม `validation.json` เป็นหลักฐานประกอบ

ไม่ได้แตะ `src/`, `tests/`, hooks, `status.json`, `worklog.json` หรือไฟล์ชุดอื่น ไม่สร้าง/สลับ branch หรือ worktree ไม่ commit/push/merge/deploy ไม่มีสิ่งที่ต้องทำด้วยมือเพื่อให้ครบรายการ Y1c; การอนุมัติภาพขั้นสุดท้ายและการดูในเกมยังเป็นงานตรวจรับภายหลัง
