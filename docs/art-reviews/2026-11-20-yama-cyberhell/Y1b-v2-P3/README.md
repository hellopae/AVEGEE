## วิธีประกอบ

1. เปิด sheet เดิม ตัดตามกริด 640×640 และวัด alpha bbox กับเท้าก่อนเรียก ImageGen
2. ส่งเฟรมเดิมหนึ่งเฟรมและ [แบบชุดอนุมัติ](../../2026-11-20-design-approval/yama-cyberhell-costume-v1.webp) เป็น input คนละภาพในทุกการสร้าง ไม่ส่ง sheet รวมให้วาด ไม่ใช้ Shado หรือ API/CLI ภายนอก
3. ขอพื้นหลังโปร่งใส ใช้ alpha ของผล ImageGen และล้างพิกเซล alpha ≤4 ซึ่งพบกระจายอยู่นอกตัวละคร จากนั้นใช้ Pillow LANCZOS ย่อ bbox สูงเท่า bbox ต้นฉบับ รายละเอียด scale และตำแหน่งอยู่ใน JSON
4. ประกอบเฉพาะชุด/หมวกด้วย mask ภายใน silhouette ของต้นฉบับ คง alpha เดิมทั้งช่อง เพื่อคงรูปร่าง ขอบ และจุดเท้าเดิม โดยนำพิกเซลนอก mask จากต้นฉบับโดยตรง รวมหน้า เขา ผิว มือ ดาบ Trojan และแสงดาบ ไม่ใช้ดาบเงินของภาพอนุมัติแทนดาบ Trojan
5. พื้นที่ชุดที่ผลสร้างไม่มีพิกเซลทึบพอใช้พิกเซลต้นฉบับรองไว้ จึงยังมีขอบชุด/รองเท้าเดิมบางส่วน ส่วนนี้ช่วยรักษาขอบและตำแหน่งเดิม ไม่ได้เปลี่ยน alpha ให้ตาม silhouette ใหม่ รายละเอียดลายกนกและการวางเกราะมีความต่างระหว่างเฟรมจากผล ImageGen
6. ใส่ผลกลับช่องเดิม บันทึก WebP lossless และเปิดอ่านกลับเพื่อตรวจค่าของไฟล์ส่งจริง

ผลสร้างสำเร็จ 8 ภาพ (เฟรมละ 1 ภาพ) รวมความพยายามเรียก ImageGen 12 ครั้ง: มี 4 การเรียกที่ไม่ออกภาพจากตัวแปรข้ามเซลล์ยังไม่พร้อม จึงเรียกใหม่ด้วย input ชัดเจน ไม่ได้สร้างเพิ่มเพื่อแก้ท่าซ้ำ และไม่เกินเพดาน 12 ครั้ง ไม่มีเฟรมที่แขน/ดาบถูกเปลี่ยนในผลประกอบ เพราะส่วนที่สงวนใช้พิกเซลเดิม

## การตรวจและ self-check ตามเกณฑ์รับงาน

1. **ขนาด/กริด/จำนวนเฟรม/RGBA/ตำแหน่ง:** เปิดอ่าน WebP กลับแล้วได้ 5120×640 RGBA ครบ 8 ช่อง และข้อมูล RGBA ตรงกับภาพก่อน encode ทุกพิกเซล ทุกช่อง alpha ตรงต้นฉบับ จึงวัด bbox สูงต่าง 0% และเท้าต่าง (0,0) px ตามตาราง ภายใน ±2% และ ±2 px
2. **ชุด/อัตลักษณ์:** เปิดดูภาพประกอบครบ 8 เฟรม มีเกราะดำ–ม่วง ขอบเงิน ลายวงจรไซแอน แถบหมวกและพลอยไซแอนตามแบบอนุมัติ เก็บต้นฉบับในพื้นที่หน้า เขา ผิว มือ ดาบและแสง; ตรวจ RGBA นอก mask แล้วตรงต้นฉบับทุกพิกเซล การเหมือนแบบและความต่อเนื่องของลายเป็นการพิจารณาด้วยสายตา ไม่อ้างว่าผ่าน QA หรือได้รับอนุมัติภาพรอบนี้ ขอบชุด/รองเท้าบางส่วนยังเป็นของเดิมตามวิธีประกอบข้างต้น
3. **หลักฐานส่งงาน:** มี compare.jpg ครบทุกเฟรม, GIF เทียบพร้อมกันเล่นวนหนึ่งไฟล์สำหรับ sheet นี้, validation.json และ README ไทย ไม่มีเฟรมขาดให้ทำต่อด้วยมือ
