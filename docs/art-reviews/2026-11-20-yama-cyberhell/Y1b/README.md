# Y1b — ร่างชุดต่อสู้ CyberHell · 20 พฤศจิกายน 2569

**สถานะ: งานยังไม่ครบเกณฑ์รับเข้าเกม — ไฟล์ใช้งานจริงที่วาดทับสำเร็จ 0/10**

รอบนี้ทำเฉพาะ Y1b ใน branch/worktree ที่ได้รับ ใช้ ImageGen ในตัว 12 ครั้ง (10 เป้าหมาย + ลองแก้ `atk` และ `sword-hurt` อย่างละ 1 ครั้ง) เลือกร่างเก็บ 10 ไฟล์ ไม่มีการเรียก API/CLI สร้างภาพหรือใช้ agent อื่น ทุกครั้งแนบ `docs/art-reviews/2026-11-20-design-approval/yama-cyberhell-costume-v1.webp` เป็นภาพอ้างอิงชุด และแนบไฟล์เดิมเป็นเป้าหมายแก้ไข

ImageGen ส่งภาพกลับขนาดไม่ตรงผืนเดิมทั้ง 10 ไฟล์ และวาดรูปทรง/ตำแหน่งบางส่วนใหม่ แม้สั่งล็อกแล้ว รวมถึงการย่อ/จัดช่องใหม่ในแผ่นแนวนอน จึงเก็บผลใน `drafts/` โดยไม่เขียนทับ `img/` เพื่อไม่ให้ส่งภาพที่ยังไม่ตรงท่าและจุดเท้าไปใช้งานจริง ไม่ยืดภาพแผ่นยาวกลับเป็นขนาดเดิม เพราะตัวละครจะผิดสัดส่วน

## ผลตรวจและข้อจำกัด

ตรวจด้วย Python 3/Pillow และ hashlib โดยอ่านต้นฉบับก่อนสร้างภาพ เก็บขนาด/โหมด/จำนวนเฟรม/กริด/ขอบ alpha/SHA-256 แล้วอ่านผลที่บันทึกจริงอีกครั้ง:

- ต้นฉบับ 10/10 มี SHA-256 ตรงกับก่อนเริ่มงาน ไม่มีการเขียนทับ
- ร่าง 10/10 เปิดอ่านได้ เป็น RGBA มี alpha ต่ำสุด 0 สูงสุด 255 และ 1 เฟรมใน PNG container
- **ขนาดผืนร่างตรงต้นฉบับ 0/10**; ช่องจริงของแผ่นยาวไม่ตรงช่องเกมเดิม
- ไม่รับรองจุดเท้า ±2 px สเกล ท่า หรือการคงหน้า/เขาเดิม การตรวจ metadata ไม่พิสูจน์สิ่งเหล่านี้
- เปิดตรวจต้นฉบับทั้งสิบ ภาพอ้างอิง ผล ImageGen และ `compare.jpg` แล้ว ภาพเทียบแสดงว่ารูปทรงชุด/สเกล/บางท่ายังต่างจากเดิม โดยเฉพาะ atk-L/R และแผ่นยาว
- ไม่ได้ทดสอบในเกม ไม่ได้รันชุดทดสอบแอป เนื่องจากไม่มีการเปลี่ยนไฟล์ใช้งานหรือโค้ด และไม่อ้างว่าผ่าน QA

Pillow ใช้เฉพาะอ่าน/วัดภาพและจัดภาพเปรียบเทียบ ไม่มีการวาด แก้พิกเซล ยืด หรือประกอบร่างภาพใหม่เพื่อส่งเข้าเกม ร่าง PNG ที่บันทึกเป็นสำเนาโดยตรงจากผล ImageGen

## ตรวจตัวเองตามเกณฑ์รับงาน

1. **ยังไม่ผ่าน:** มีร่างครบ 10 เป้าหมาย แต่ไม่มีไฟล์ WebP เดิมที่เปลี่ยนพร้อมใช้ ขนาด/ช่อง/ตำแหน่งเท้าของร่างยังไม่ตรง ไม่ถือว่าการนับจำนวนตัวละครด้วยสายตารับรองเฟรม/ท่าถูกต้อง
2. **ได้บางส่วน:** เห็นหมวกแถบฟ้า อัญมณีฟ้า เสื้อดำม่วง และลายกนกวงจรตามต้นแบบ แต่รูปทรงและการรักษาหน้า/เขา/ผิว/ดาบเดิมยังรับรองไม่ได้ ต้องตรวจแก้อีก
3. **มีหลักฐานรีวิวครบ:** มี `compare.jpg` เดิม | ร่างใหม่ ทุกไฟล์ และ README ไทยนี้ โดยระบุชัดว่าร่างใหม่ยังไม่รับเข้าเกม

## งานที่ยังขาด

ต้องแก้ชุดบนต้นฉบับทั้ง 10 ไฟล์ให้เปลี่ยนเฉพาะชุด/หมวก คงพิกเซลที่ไม่เกี่ยวข้อง ตรวจจุดเท้ารายช่องให้คลาดไม่เกิน ±2 px คงสเกล ท่า และชนิดอาวุธ/เอฟเฟกต์เดิม จากนั้น export เป็นชื่อ WebP เดิม ขนาด/ช่อง/จำนวนเฟรม/โหมดเดิม และสร้างภาพเทียบกับผลพร้อมใช้ใหม่ การแก้ต่อควรใช้ขั้นตอนที่ล็อกพื้นที่แก้ไขได้ละเอียด; ร่างรอบนี้ใช้ดูรายละเอียดชุดได้ แต่ไม่ควรถูกนำไปแทนไฟล์เกมโดยตรง
