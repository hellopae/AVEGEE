# Y1b-v2-P4 — cane และ fang

## วิธีทำและข้อจำกัด

1. ตัด sheet เดิมเป็นกริด 8×1 ช่องละ 640×640 วัด alpha bbox และจุดสัมผัสเท้าก่อนวาด ภาพตัดล้าง RGB ที่ซ่อนอยู่ในพิกเซล alpha=0 เพื่อไม่ให้สีที่มองไม่เห็นรบกวน ImageGen
2. ส่ง cane ทีละเฟรมพร้อมแบบอนุมัติ `docs/art-reviews/2026-11-20-design-approval/yama-cyberhell-costume-v1.webp` เน้นชุดดำม่วง ขอบเงิน วงจร cyan และหมวกใหม่ โดยล็อกท่า/หน้า/ดาบ
3. ผลดิบมีขนาด 1254×1254 และมี alpha จางมากนอกตัวละคร จึงตัด noise ที่ alpha<9 ก่อนลงทะเบียนภาพ ใช้ Pillow LANCZOS ย่อและจัดแนวตามยอดหมวก ฐานรองเท้า และช่วงกว้างรองเท้า ดูค่า transform รายเฟรมใน JSON
4. ใช้เฉพาะ RGB ของชุดใหม่ภายใน silhouette/alpha เดิม โดยใช้ SciPy หา RGB ชุดที่ใกล้ที่สุดเมื่อ sample ตกนอกชุดหรือบนผิวของภาพสร้าง วิธีนี้คง alpha เดิมทุกพิกเซล จึงคง bbox และจุดเท้า รวมทั้งขอบแสงดาบไว้ได้ ไม่ได้นำหน้า/ดาบที่ ImageGen วาดใหม่มาใช้
5. เก็บผิวแดง เขา มือ และช่องภายในผิว เช่น ดวงตา ด้วย mask สีที่เติมรูและขยาย 2 px รวมกับ mask ความต่าง cane/fang ที่ขยาย 2 px เพื่อเก็บอาวุธเดิม บริเวณนอกตัวละครยังใช้ภาพเดิมทั้งหมด จึงมีรายละเอียดเสื้อเดิมเล็กน้อยติดอยู่รอบจุดจับอาวุธที่ mask ป้องกันไว้ ไม่มีการวาดอาวุธ fang ใหม่
6. บันทึก WebP แบบ lossless, exact RGBA แล้วเปิดไฟล์กลับมาวัด การตรวจภาพเทียบเห็นหมวก วงจร cyan ขอบเงินม่วง และรองเท้าเกราะตามแบบ ภาพส่งมอบรักษาโครงร่างชุดเดิม จึงไม่ใช่การนำ silhouette ของแบบอนุมัติมาแทนทั้งตัว

จุดเท้าใช้กลางช่วง x ของแถวล่างสุดที่เป็นรองเท้าทึบ (alpha>128, y≥540, x<370) เพื่อไม่เลือกเศษแสงดาบที่อยู่ต่ำกว่าเท้า ส่วน bbox เต็มวัดจาก alpha>0 และรายงาน bbox ทึบ alpha>128 แยกด้วย การเก็บ alpha เดิมทำให้แม้เปลี่ยน threshold ค่าขอบของเดิม/ใหม่ก็ยังเท่ากัน
