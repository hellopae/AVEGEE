# Y1b-v2-P5 — ยามา CyberHell ท่าดาบโซ่

ทำเฉพาะ P5 วันที่ 20 พฤศจิกายน 2569 บน worktree/branch ที่ได้รับ ใช้ ImageGen ในตัว 8 ครั้ง แก้ทีละเฟรมโดยแนบเฟรมเดิมและ [แบบชุดอนุมัติ](../../2026-11-20-design-approval/yama-cyberhell-costume-v1.webp) ทุกครั้ง ไม่มีการส่ง sheet ทั้งแผ่นเข้า ImageGen ไม่มีเฟรมขาด ไม่มีเฟรมใช้ภาพเดิมทั้งเฟรมแทน และไม่มีการสร้างซ้ำ

ไฟล์เกมที่เปลี่ยน: `img/yama-sword-weapons/hero-yama-cyberhell-sword-chain.webp` เท่านั้น ไม่แก้ `src/`, `tests/` หรือชุด P1–P4

## ไฟล์ตรวจงาน

- [compare.jpg](compare.jpg): เดิมซ้าย | ใหม่ขวา ครบ 8 เฟรม แต่ละภาพใช้ช่องเต็ม 640×640 เท่ากัน
- [chain-compare.gif](chain-compare.gif): เดิมซ้าย | ใหม่ขวา เล่นวน 8 เฟรม เฟรมละ 120 ms เป็นความเร็วสำหรับตรวจภาพ ไม่ใช่การยืนยันความเร็วในเกม
- [validation.json](validation.json): ขนาด โหมด กริด bbox จุดเท้า และจำนวนพิกเซลที่เปลี่ยนในแต่ละบริเวณ วัดจาก WebP ที่บันทึกแล้ว
- [process.py](process.py): ประกอบซ้ำและตรวจค่าด้วย Pillow + NumPy โดยไม่เรียก ImageGen
- [inputs/original.webp](inputs/original.webp): สำเนาพิกเซล sheet ต้นฉบับก่อนแก้ เก็บไว้ตรวจเทียบ
- [inputs/generated.webp](inputs/generated.webp): ผล ImageGen ทั้ง 8 ภาพที่แยกสร้างแล้ว ล้าง alpha ต่ำกว่า 8 และย่อเป็นช่อง 640×640 ก่อนรวมเพื่อเก็บหลักฐานเท่านั้น ไฟล์นี้ไม่เคยใช้เป็นอินพุต ImageGen
- [prompts.json](prompts.json): คำสั่ง ImageGen แต่ละครั้งและบทบาทภาพอ้างอิง

## วิธีประกอบและการคงท่า

1. ตัดต้นฉบับ 5120×640 ตามกริด 8×1 ช่องละ 640×640 วัด alpha bbox และเลือกบริเวณรองเท้าจากภาพเดิม แยกจากดาบ/แสงที่ต่ำกว่าเท้าในเฟรม 6–7
2. แก้ภาพทีละเฟรมด้วย ImageGen ให้เปลี่ยนเฉพาะหมวกและเสื้อผ้าเป็นเกราะดำ–ม่วง เสื้อคลุมขอบเงิน/ม่วง ลายวงจรไซแอน แถบไฟหมวกและอัญมณีกลางหน้าผาก โดยคงท่า หน้า เขา ผิว อาวุธ และแสง
3. ผล ImageGen เป็น RGBA 1254×1254 มี alpha จางกระจายรอบฉาก จึงล้าง alpha <8 แล้วลดภาพด้วย LANCZOS เป็น 640×640 ปรับสเกลแบบสม่ำเสมอตามจุดบนหมวกและพื้นรองเท้า และเลื่อนกลับตำแหน่งต้นฉบับ ค่า transform รายเฟรมอยู่ใน JSON เฟรม 7 ต้องปรับมากที่สุด
4. ใช้ mask หมวก/เสื้อผ้าบน silhouette เดิม นำเฉพาะ RGB ของชุดใหม่มาประกอบ เก็บ alpha เดิมทั้งช่อง และเก็บพิกเซลต้นฉบับนอก mask โดยตรง ป้องกันผิวแดงรวมขอบ 2 px และ polygon ดาบ/ด้าม/ลูกตุ้มที่พาดผ่านเสื้อผ้า ไม่ใช้ดาบหรือแสงที่ ImageGen วาดซ้ำ หมวกและชายเสื้อใหม่จึงถูกจำกัดด้วย silhouette เดิมเพื่อรักษาสัดส่วนและกรอบภาพ
5. ปรับพื้นผิวรองเท้าใหม่ตามช่วงพิกเซลรองเท้าเดิมทีละแถวด้วย Pillow เพื่อไม่เหลือปลายรองเท้าเดิมซ้อนกับรองเท้าใหม่ บันทึก WebP lossless RGBA ด้วย `exact=True` แล้วเปิดไฟล์กลับมาวัด

ตัวเลข bbox ที่เท่ากันเกิดจากการคง alpha เดิมอย่างจงใจ ไม่ใช่ข้ออ้างว่า ImageGen ส่งขนาดหรือตำแหน่งตรงเอง รายละเอียดเสื้อผ้าใหม่ใช้ mask ประกอบกับต้นฉบับ จึงอาจเห็นขอบชุดเดิมบางส่วนบริเวณรอยต่อที่ต้องป้องกันผิว/อาวุธ

## ผลวัดทุกเฟรม

bbox ใช้ alpha ≥128 และพิกัดแบบ Pillow `[ซ้าย, บน, ขวาไม่รวม, ล่างไม่รวม]` รวมอาวุธ/แสงที่ทึบด้วย ใน JSON มี bbox สำหรับ alpha >0 เพิ่มด้วย จุดเท้าวัดแถวล่างสุดที่ alpha ≥128 ภายใน ROI รองเท้า `x=[100,365), y=[530,590)` แล้วใช้กึ่งกลาง x ของช่วงพิกเซลในแถวนั้น รองเท้าซ้ายของต้นฉบับต่ำกว่าขวา จึงได้จุดอ้างอิงใกล้รองเท้าซ้าย ไม่ใช่กึ่งกลางตัวละคร

## ตรวจด้วยคำสั่งและตรวจภาพ

รันจาก root ของ repo:

```sh
python3 docs/art-reviews/2026-11-20-yama-cyberhell/Y1b-v2-P5/process.py
```

คำสั่งนี้เขียนเฉพาะ sheet P5, compare, GIF และ validation ในชุดนี้ แล้วตรวจไฟล์ที่อ่านกลับด้วย assertion: RGBA 5120×640, 8 ช่อง, bbox สูงไม่เกิน ±2%, จุดเท้าไม่เกิน ±2 px, alpha เดิมเท่ากันทุกพิกเซล, ไม่มีพิกเซลเปลี่ยนนอก mask ชุด และไม่มีการเปลี่ยนใน mask ผิว/อาวุธที่ป้องกันไว้ ผลรอบส่งงาน: bbox สูงต่าง 0% และเท้าต่าง 0 px ครบ 8 เฟรม จำนวนพิกเซลที่เปลี่ยนในบริเวณป้องกันเป็น 0

ตรวจเพิ่มแบบอ่านอย่างเดียวด้วย Python โดยอ่านภาพต้นฉบับจาก `git show HEAD:img/yama-sword-weapons/hero-yama-cyberhell-sword-chain.webp` เพื่อเทียบกับสำเนา evidence และไฟล์ส่งออก ตรวจ GIF ว่าเปิดอ่านได้ 8 เฟรมและ `loop=0` ตรวจ `git diff --check` และขอบเขตไฟล์ที่เปลี่ยน

เปิดดู compare ที่บันทึกแล้วครบ 8 แถว ชุดมีเกราะดำ–ม่วง ขอบเงิน/ม่วง ลายวงจรไซแอน แถบและอัญมณีหมวกตามแบบ ตำแหน่งหน้า แขน ดาบ และแสงยังอิงต้นฉบับ เก็บรอยต่อชุดกับส่วนที่ป้องกันไว้ ไม่รับรองความเหมือนเชิงศิลป์ระดับพิกเซลของลายชุดระหว่างเฟรม ไม่ได้เปิดเกมหรือรัน animation ใน runtime และไม่ได้รันชุดทดสอบแอป งานนี้ยังต้องให้เจ้าของตรวจความต่อเนื่องของลายชุดขณะเล่นจริง ไม่กล่าวว่า QA ผ่าน

## ตรวจตนเองตามเกณฑ์รับงาน

1. **ขนาด/กริด/จำนวนเฟรม/RGBA และตำแหน่ง:** ไฟล์ส่งออก 5120×640, 8×1, ช่อง 640×640, RGBA ครบ 8 เฟรม ค่า bbox สูงและจุดเท้าทุกเฟรมอยู่ในเกณฑ์ มีตารางใน validation.json
2. **ชุดและอัตลักษณ์:** วาดชุดด้วย ImageGen ตามแบบอนุมัติครบ 8 เฟรม ใช้การประกอบเพื่อคงหน้า เขา ผิว ดาบ และแสงจากต้นฉบับ ตรวจเชิงตัวเลขเฉพาะ mask ป้องกันและตรวจภาพเทียบด้วยตา ความต่อเนื่องในเกมยังไม่ได้ตรวจ
3. **หลักฐานและเอกสาร:** compare.jpg ครบเดิม/ใหม่ทุกเฟรม มี GIF เล่นวน 1 ไฟล์สำหรับ sheet นี้ และ README ไทยฉบับนี้ ไม่มีเฟรมขาด
