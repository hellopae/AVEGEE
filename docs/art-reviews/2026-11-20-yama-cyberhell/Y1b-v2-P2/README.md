# P2 — Y1b-v2 ชุดต่อสู้ CyberHell

ทำเฉพาะ `img/yama-sword-v4/hero-yama-cyberhell-sword.webp` จำนวน 8 เฟรม ไม่แก้ชุด P1/P3/P4/P5 หรือโค้ดเกม

## สิ่งที่ส่ง

- sheet ชื่อเดิม ขนาด 5120×640, RGBA, กริด 8×1, เซลล์ 640×640 บันทึก WebP แบบ lossless
- `compare.jpg`: เดิมซ้าย / ใหม่ขวา ครบทั้งเซลล์ทั้ง 8 เฟรม
- `hero-yama-cyberhell-sword-compare.gif`: เล่นเดิม/ใหม่ข้างกัน 8 เฟรม วนไม่สิ้นสุด
- `validation.json`: bbox ทั้ง alpha≥1 และ alpha≥128, จุดเท้า, จำนวนพิกเซลที่เปลี่ยน, SHA-256 และผลอ่าน WebP กลับ
- ภาพเดิมแยกเฟรม ภาพจาก ImageGen แยกเฟรม ภาพประกอบสุดท้าย และ mask ของบริเวณชุด เพื่อย้อนตรวจได้
- `prompts.json`: prompt จริงที่ใช้ทั้ง 7 ครั้ง ผ่าน ImageGen ในตัว ไม่มี CLI/API ภายนอก

## วิธีทำและข้อจำกัด

ตัด sheet เดิมเป็น 8 ช่องก่อนส่ง ImageGen ทีละภาพ พร้อมแบบอนุมัติ `docs/art-reviews/2026-11-20-design-approval/yama-cyberhell-costume-v1.webp` ไม่ส่ง sheet ทั้งแผ่นให้วาดใหม่ ใช้ 7 ครั้งสำหรับเฟรม 1–7 ไม่มีการ retry; เฟรม 8 ท่าใกล้เฟรม 1 มาก จึงใช้ภาพชุดจากเฟรม 1 แล้ววางตาม bbox ของเฟรม 8 (เลื่อน x 2 px; ปรับความสูง 1 px ตาม alpha≥128)

ผล ImageGen มี alpha โปร่งใสอยู่แล้ว ตัด noise นอกตัวละครด้วย alpha≥16 เพื่อหา bbox จากนั้นย่อ/ขยายแบบ uniform ด้วย Pillow ตามความสูง bbox ทึบเดิม (alpha≥128) แล้ววางในช่องเดิม ชุดสีดำ/ม่วง ขอบเงิน ลายวงจร cyan และอัญมณีหมวกนำมาจากผลสร้างรายเฟรม

เพื่อป้องกันท่า/หน้า/ดาบเพี้ยน นำ RGB ชุดใหม่ใส่เฉพาะ mask เสื้อผ้าและหมวก แล้วคง alpha เดิมทุกพิกเซล หน้า เขา ผิว มือ ดาบ และแสงดาบใช้พิกเซลต้นฉบับนอก mask โดยล้างเฉพาะ RGB ที่ alpha=0 ให้เป็นศูนย์ ไม่เปลี่ยนรูปร่างหรือขนาดภาพ ความสูง bbox และจุดเท้าจึงตรงเดิมทุกเฟรม ไม่ได้อาศัย ImageGen รักษาพิกัดเอง

เฟรม 6 มีระยะรองเท้าจากผลสร้างแคบกว่าเดิม จึงปรับ RGB ของชุดช่วงล่างด้วย affine ตามตำแหน่งรองเท้าเดิมก่อนใส่ mask ค่า transform อยู่ใน `validation.json` และ `assemble.py` ไม่ขยับ alpha หรืออวัยวะเดิม ขอบและทรงหมวก/ชายเสื้อยังยึด silhouette เดิม ลายจากผลวาดจึงถูกตัดให้พอดีขอบเดิม งานนี้ไม่ได้เปลี่ยน silhouette ให้ตรงภาพอนุมัติทั้งภาพ

จุดเท้าใช้แถวล่างสุดที่ alpha≥128 ใน ROI รองเท้าคงที่ x90:380, y520:600 แล้วหาค่ากลางระหว่าง x ซ้ายสุด/ขวาสุดของแถวนั้น แยกจาก bbox ทั้งภาพ เพราะเฟรม 6–7 มีดาบ/แสงต่ำกว่าเท้า ขอบ bbox ด้านขวาและล่างเป็น exclusive

ไม่มีเฟรมขาด และไม่มีเฟรมที่ fallback ใช้ชุดเดิมทั้งเฟรม การตรวจเชิงตัวเลขยืนยันเฉพาะขนาด/พิกัด/พิกเซลในบริเวณป้องกัน ไม่ใช่การอนุมัติความงามหรือ QA ในเกม

## ตรวจซ้ำ

จาก root ของ worktree (ต้องมี Python 3, Pillow, NumPy, SciPy):

```sh
python3 docs/art-reviews/2026-11-20-yama-cyberhell/Y1b-v2-P2/assemble.py
python3 docs/art-reviews/2026-11-20-yama-cyberhell/Y1b-v2-P2/verify.py

git diff --check
```

`assemble.py` เขียนเฉพาะ sheet P2 และไฟล์ในโฟลเดอร์รีวิวนี้ ส่วน `verify.py` อ่านไฟล์อย่างเดียว ตรวจขนาด, กริดโดยตัดครบ 8 ช่อง, alpha, bbox, จุดเท้า, พิกเซลนอก mask ที่มองเห็น, การอ่าน WebP กลับ และ GIF 8 เฟรม loop=0 ผลที่รันจริงเก็บใน `verification-result.json`

ยังไม่ได้ทดสอบในเกมหรือให้ผู้อนุมัติแบบตรวจรับงาน ไม่ได้แก้ `src/`, `tests/`, hooks, `status.json` หรือ `worklog.json` และไม่ได้ commit/push/merge/deploy
