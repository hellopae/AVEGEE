## ภาพอ้างอิงและวิธีแก้

- ชุดยามาใช้เกราะดำอมม่วง หมวกทรงเตี้ยประดับอัญมณีสีฟ้า และลายวงจรไซแอนตามแบบอนุมัติ [แบบอนุมัติ 20 พ.ย.](../2026-11-20-design-approval/yama-cyberhell-costume-v1.webp) · [ภาพท่าโจมตี](../../../img/hero-yama-cyberhell-atk-cutscene-v3.webp)
- ชุดนิราใช้เสื้อคลุมสีถ่าน เกราะไหล่ขลิบทองแดง ขอบสีน้ำเงิน และลายเรขาคณิตสีทองแดง [ภาพท่ารักษา](../../../img/nira-combat/nira-cyberhell-heal-cutscene-v1.webp) · [ภาพยืน](../../../img/nira-idle-v1/cyberhell.webp)
- ฉากหลังภาพ 4–7 ใช้เมืองนรกเครือข่ายในฝน มีตึกเซิร์ฟเวอร์ สะพาน และแสงนีออนม่วงกับฟ้า [ภาพฉาก 1](../../../img/story-cyberhell-01-v2.webp) · [ภาพฉาก 2](../../../img/story-cyberhell-02-v3.webp)

ใช้ ImageGen ในตัว 7 ครั้ง โดยใช้ภาพเดิมเป็นฐานและสั่งให้แก้เฉพาะชุดของทั้งคู่ รวมถึงฉากหลังในภาพ 4–7 ยึดตำแหน่ง ท่าทาง ใบหน้า หนังสือของนิรา ตัวบอส โซ่ม่วง และท่าพิเศษตามภาพเดิม ไฟล์ส่งใช้เฉพาะส่วนที่แก้จากภาพร่างและประกอบกลับกับพิกเซลต้นฉบับ มีรายละเอียดขอบหมวก ใบหน้า และแสงรอบตัวที่ต่างเล็กน้อยตรงรอยต่อ ภาพ 4–7 มีแสงสะท้อนจากฉากใหม่บนพื้นบางจุด

## ตรวจไฟล์

เปิดและถอดรหัสไฟล์จริงครบทั้ง 7 ภาพเป็น RGB WebP ขนาด 1672 × 941 พิกเซล ที่ชื่อและตำแหน่งเดิม ตรวจขนาดเทียบกับไฟล์ใน Git และตรวจโครงสร้างด้วย `webpinfo` ไฟล์ที่เพิ่มมากที่สุดคือภาพ 5 ที่ +14.97%

ตรวจพิกเซลบริเวณนอกชุดในภาพ 1–3 และบริเวณตัวบอสในภาพ 4–7 เทียบกับต้นฉบับ พื้นที่ตัวอย่างตรงกันก่อนเข้ารหัส ภาพ 1–2 เก็บค่านั้นได้แบบไม่สูญเสีย ส่วนภาพ 3–7 เข้ารหัสแบบบีบอัดคุณภาพสูง ค่าผลต่างเฉลี่ยต่อช่องสีในพื้นที่ตัวอย่างหลังเข้ารหัสอยู่ที่ 1.21–1.46 จาก 255

ตรวจภาพเทียบกับไฟล์ต้นทางทั้ง 14 ช่องและเปิดดูภาพเทียบกับชุดอ้างอิง ท่าพิเศษทั้ง 4 ยังเห็นชัด ได้แก่ คลื่นหน้าบัญชี ตราหยก ลำแสงตะเกียง และสายข้อมูล
