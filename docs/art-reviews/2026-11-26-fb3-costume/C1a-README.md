## วิธีแก้และข้อสังเกต

- เปิดภาพเดิมและภาพอ้างอิงของแต่ละโซนก่อนวาด แล้วให้ ImageGen แก้บริเวณชุด กำชับให้คงมุมหน้า ท่าทาง มือและหนังสือของภาพเดิม โซน 1 ใช้ชฎาทอง เสื้อดำขอบทอง ผ้าแดง และเท้าเปล่าสำหรับยามา กับเสื้อดำขอบทองและผ้าแดงสำหรับนิรา โซน 2 ใช้หมวกดำขลิบทองคาดปิ่น เสื้อแดงลายดอก กางเกงกรม และถุงเท้ากับรองเท้าตามอ้างอิงของยามา
- ประกอบบริเวณชุดที่แก้กลับบนต้นฉบับ เก็บรายละเอียดใบหน้าและหนังสือจากภาพเดิม รอยต่อแคบรอบชุดมีการเติมฉากหรือขอบผมและผิวที่ชุดเก่าเคยบัง ก่อนบันทึกเป็น WebP พิกเซล RGB นอกพื้นที่ประกอบตรงกับต้นฉบับที่จัดขนาดแล้วทุกภาพ
- ภาพสิตาปรับขนาดจาก 1375×768 เป็น 1672×941 ทั้งเฟรมเพื่อให้ตรงสเปก การย่อขยายและการบันทึก WebP แบบบีบอัดมีผลต่อค่าพิกเซลของไฟล์สุดท้าย
- ตรวจว่าไฟล์ทั้งเจ็ดเปิดอ่านได้เป็น WebP สี RGB ขนาด 1672×941 ที่ชื่อและตำแหน่งเดิม ขนาดเพิ่มสูงสุด 14.40% ที่ภาพสิตา เทียบภาพชุดและฉากด้วยสายตาจากภาพเดิมและภาพใหม่
