## ภาพอ้างอิงและวิธีแก้

- โซน 2 ยามาใส่หมวกขุนนางสีดำและชุดแดงลายดอก นิราใส่ชุดครามลายดอกทองและสายคาดเอวแบบโอบิ [ยามาท่าโจมตี](../../../img/hero-yama-asia-atk-cutscene-v3.webp) · [ยามาท่ากระจก](../../../img/hero-yama-asia-mirror-cutscene-v3.webp) · [นิราท่าฮีล](../../../img/nira-combat/nira-asia-heal-cutscene-v1.webp) · [นิราท่ายืน](../../../img/nira-idle-v1/asia.webp)
- โซน 3 ยามาใส่หมวกโลหะเขาโค้งประดับอัญมณีฟ้า เสื้อเขียวขอบแดงทอง และผ้าคลุมขน นิราใส่ชุดหนังสีน้ำตาล ปกขนสีอ่อน และรองเท้าบูต [ยามาท่าโจมตี](../../../img/hero-yama-west-atk-cutscene-v3.webp) · [ยามาท่ากระจก](../../../img/hero-yama-west-mirror-cutscene-v3.webp) · [นิราท่าฮีล](../../../img/nira-combat/nira-west-heal-cutscene-v1.webp) · [นิราท่ายืน](../../../img/nira-idle-v1/west.webp)

ใช้ ImageGen ในตัว 7 ครั้ง คำสั่งของแต่ละภาพให้เปลี่ยนเฉพาะชุด หมวก เครื่องประดับ และรองเท้าตามภาพอ้างอิง โดยยึดใบหน้า ผม เขาธรรมชาติ สีผิว มือ ของที่ถือ ท่า และตำแหน่งจากภาพเดิม จากนั้นนำเฉพาะบริเวณชุดกลับมาซ้อนบนภาพเดิมและเกลี่ยรอยต่อรอบขอบชุด

## ผลตรวจไฟล์

ตรวจภาพเทียบเต็มเฟรมและขยายบริเวณตัวละครครบ 7 ภาพ ก่อนเข้ารหัส พิกเซลนอกบริเวณซ้อนภาพตรงกับต้นฉบับทุกภาพ ไฟล์ Jormungandr ใช้ WebP แบบไม่สูญเสียและยังตรงกันนอกบริเวณแก้หลังเข้ารหัส ส่วนไฟล์ WebP อีกหกภาพมีความคลาดเคลื่อนของค่าสีเล็กน้อยจากการบีบอัดซ้ำ

ไฟล์ทั้งเจ็ดเป็น WebP แบบ RGB ขนาด 1672 × 941 พิกเซล อยู่ที่พาธเดิม และเพิ่มขนาดสูงสุด 9.30%
