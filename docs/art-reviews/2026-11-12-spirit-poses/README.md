## การตรวจที่ทำได้

ตรวจอัตโนมัติเฉพาะจำนวนไฟล์ การเปิดอ่าน และขนาดเทียบต้นฉบับ ตามข้อจำกัดของ brief:

```sh
python3 docs/art-reviews/2026-11-12-spirit-poses/review-assets.py check
python3 docs/art-reviews/2026-11-12-spirit-poses/review-assets.py sheet
```

ผลล่าสุดอยู่ใน `checks.json`; คำสั่ง check คืน exit code 1 เมื่อยังมีไฟล์ขาดหรือข้อผิดพลาด การคืน code 1 เพราะส่งไม่ครบตามงบต้องไม่รายงานว่าเทสต์ครบชุดผ่าน ไม่มีการรันเกมหรือทดสอบ integration

ผลรันสุดท้าย: เปิดอ่านและขนาดตรง 34 ไฟล์, ขาด 5 ไฟล์, `errors: []`, exit code **1** เพราะจำนวนยังไม่ครบ สร้าง contact sheet ได้ 34 คู่

ข้อสังเกตจากภาพใหม่: scared ของ worker/officer/executive/woman คงตาหรือเลนส์ขาวไว้; girl คงม่านตาสีม่วง; cry ของ worker/officer/woman เป็นน้ำตาพร้อมสีหน้าผ่อนคลาย ไม่เห็นเลือดหรือบาดแผล ชุดและของถือยังตรงในภาพรวม แต่เฉดและรายละเอียดของร่าง/หางถูกวาดใหม่ จึงยังต้องตรวจซ้อนและตรวจรับด้วยคน
