## ภาพอ้างอิงและพรอมป์ต์

ดูคำสั่งที่ส่ง ImageGen และรายการภาพแนบแต่ละรอบใน [prompts.md](prompts.md)

- e2: ภาพฉากเดิม + sprite ยามาโซน 1; รอบแก้ใช้ภาพผลลัพธ์ก่อนหน้า + sprite เดิม
- e3: ภาพแฟ้มเดิม + sprite ยามาโซน 1
- ฉากตะเกียง: ภาพเดิม + e2 ที่แก้มือ/ท่าไหว้แล้ว + sprite ยามาโซน 1
- ไอคอนดับ: ฉากตะเกียงใหม่ + `img/ui/icon-defend-shield.webp`
- ไอคอนติด: ไอคอนดับใหม่
- ปุ่มเรียก: `img/ui/power-heal-lotus.webp` + `img/ui/icon-defend-shield.webp` + ไอคอนติดใหม่
- ต้นทอง: `img/theme-v4/town-tree-th-v1.webp` + `img/map-zone1/v7r/sprites/pilot-gold-tree-00.webp`

ใช้ Pillow เฉพาะแปลงไฟล์/ปรับขนาดส่งออก เก็บ alpha จาก ImageGen และจัด contact sheet ภาพฉากบันทึก WebP quality 95 ส่วนภาพโปร่งใสบันทึก WebP แบบ lossless ไม่ได้ใช้เครื่องมือวาดอื่นหรือ API ภายนอก

## ผลตรวจไฟล์และข้อจำกัด

ผลตัวเลขและ SHA-256 ของภาพทั้ง 7 อยู่ใน [validation.json](validation.json)

1. เปิดและถอดรหัสภาพทั้ง 7 ด้วย Pillow ได้ เป็น WebP และมีขนาดตรงตามตาราง
2. ไอคอน 3 ไฟล์และต้นทองเป็น RGBA ทุกไฟล์มี alpha ต่ำสุด 0 และสูงสุด 255 และมีพิกเซลโปร่งใสจริง
3. สำเนาไฟล์ส่งออกทั้ง 7 ตรงกับไฟล์ในเกมทุกไบต์
4. เปิดดูภาพที่สร้างและ contact sheet แล้ว: ไม่พบตัวอักษรที่อ่านได้ในภาพส่งออก ยามาทั้งสามฉากสวมมงกุฎทองไทยและชุดดำ/แดงขลิบทอง ไม่มีชุดกิโมโนซากุระ
5. ตรวจ `git diff --check` แล้วไม่พบปัญหา whitespace ตรวจสถานะ Git แล้วมีเฉพาะไฟล์ภาพตามใบงานและโฟลเดอร์รีวิวนี้

ภาพ e3 คงตำแหน่งและองค์ประกอบจากการเทียบด้วยตา ไม่ได้รับรองว่าพิกเซลนอกยามาเหมือนต้นฉบับทุกจุด เพราะเป็นการแก้ด้วย ImageGen และปรับขนาดตามใบงาน

ไม่มีภาพที่ยังไม่ได้ทำในรายการนี้ ยังไม่ได้เปิดเกมเพื่อตรวจการจัดวาง/ขนาดปุ่มจริง และไม่ได้รันชุดทดสอบโค้ด เนื่องจากเป็นงานวาดล้วน ผลตรวจนี้เป็นการตรวจไฟล์ภาพ ไม่ใช่ผล QA ในเกม การเชื่อมใช้งาน 4 พาธที่ไม่มีอยู่ก่อนต้องให้ผู้ดูแลตรวจในเกมต่อ โดยรอบนี้ไม่แก้โค้ด

ไม่ได้แก้ `src/`, `tests/`, hooks, `status.json` หรือ `worklog.json` ไม่สร้างหรือสลับ worktree/branch ไม่ commit/push/merge และไม่ deploy
