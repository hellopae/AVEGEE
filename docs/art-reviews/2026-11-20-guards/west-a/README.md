## การวัดและผลตรวจ

พิกัดเริ่มที่มุมซ้ายบน กรอบ alpha ใช้ค่าอย่างน้อย 16/255; ขวาและล่างของกรอบเป็น exclusive จุดสัมผัสพื้นใช้มัธยฐานพิกัด x ของพิกเซลใน 3 แถวล่างสุดที่มี alpha ถึงเกณฑ์ และ y ของแถวล่างสุด ไม่ใช่จุดเท้าจากเอนจิน เพราะไม่มีข้อมูล pivot ของเอนจินในใบงาน

| ภาพ | จุดเดิม → ใหม่ | ความคลาด (x,y) | ความสูงเดิม → ใหม่ |
|---|---|---|---|
| ยืนบนแผนที่ | (189.5,511) → (190,511) | (+0.5,0) px | ตัว 480 → 480 px |
| นั่งพัก | (116.5,204) → (116,204) | (-0.5,0) px | 205 → 205 px |
| event guard | (256,497) → (256,497) | (0,0) px | 468 → 468 px |
| คัตซีน เท้าหน้า | (444,697) → (445,697) | (+1,0) px | ตัว 518 → 518 px |
| คัตซีน เท้าหลัง | (729,682) → (730,682) | (+1,0) px | ใช้ความสูงตัวเดียวกัน |

ภาพยืนต้นฉบับมีหอกขึ้นถึง y=0 แต่ยอดศีรษะ/เขาของตัวอยู่ y=32 จึงวัดความสูงตัว 512−32 = 480 px โดย **ไม่รวมหอก** ภาพใหม่ยอดหมวกอยู่ y=32 เท้าอยู่ y=511 ความสูงกรอบ alpha ทั้งภาพจึงเปลี่ยนจาก 512 เป็น 480 px ตามการเปลี่ยนอาวุธ มิใช่การลดความสูงตัว

คัตซีนเดิมเป็น RGB จึงอ่านจุดเท้าและยอดศีรษะด้วยสายตาจากภาพขยาย แล้ววัดภาพใหม่จากมาสก์ alpha ของตัวละครแยกชั้น ความแม่นยำของจุดต้นฉบับจำกัดด้วยการเลือกจุดด้วยสายตา ไม่ใช่การตรวจ pivot ในเกม

placeholder event guard เดิมไม่มีเท้าจริง ใช้จุดกึ่งกลางฐาน silhouette เดิมเป็นตัวแทนวางเท้า ส่วน profile เดิมเป็นข้อความ ไม่มีความสูงตัวหรือจุดเท้าที่เทียบเชิงกายวิภาคได้ จึงตรวจคงขนาด/โหมด/กริด/เฟรม และเปลี่ยนเป็นภาพครึ่งตัว

KO เป็น 640×320 RGBA 1 เฟรม หัวซ้าย เท้าขวา ตาปิด ไม่มีเลือด ความยาวที่เห็น 456 px เท่ากับ 0.95 ของความสูงยืน 480 px ตะเกียงอยู่มือซ้าย หน้าไม้อยู่มือขวา

## คัตซีนและการตรวจด้วยสายตา

สร้างตัวละครกับฉากซ่อมแยกกันใน ImageGen แล้วประกอบด้วย Pillow ตัวละครยังอยู่กลางภาพ ท่าพุ่งต่ำไปทางขวา เปลี่ยนหอกเป็นหน้าไม้และตะเกียง ฉากปราสาทหิมะ ประตู รูปปั้น ดวงจันทร์แดง และแนวเอฟเฟกต์หลักยังอยู่ตำแหน่งเดิม พื้นหลังที่ตัวเดิมเคยบังต้องวาดเติมตามบริบท; พิกเซลนอกมาสก์แก้ไขเก็บจากไฟล์ต้นฉบับแบบตรงตัว และตรวจพบเปลี่ยน **0 พิกเซล**

เปิดภาพส่งออกและภาพเทียบตรวจด้วยสายตาแล้ว: ชายแก่ ผมหงอก หนวดเรียบ หมวกปีกกว้าง เสื้อคลุมเข้ม กระเป๋าหนัง ซองไม้และห่อขี้ผึ้ง หน้าไม้มือขวา ตะเกียงมือซ้าย ไม่พบตัวอักษร เลือด ไม้กางเขน หรือสัญลักษณ์ศาสนา ใช้แบบตัวละครต้นฉบับตามภาพอนุมัติ ไม่อ้างภาพนักแสดงหรือภาพยนตร์

## ทดสอบที่ทำและข้อจำกัด

รัน `validate.py` ตรวจไฟล์ทั้ง 6 รายการ: ขนาด โหมดสี กริด จำนวนเฟรม จุดสัมผัสพื้น ความสูงตัว สัดส่วน KO การเก็บฉากนอกมาสก์ และไฟล์หลักฐาน ผลละเอียดอยู่ใน `validation.json` ตรวจขอบเขต diff ด้วย Git และตรวจภาพส่งออกด้วยสายตา ไม่ได้รันเกมหรือทดสอบ runtime และไม่ถือผลตรวจไฟล์เป็นการอนุมัติด้านศิลป์

Self-check ตามเกณฑ์รับงาน:

1. ครบไฟล์ west-a ทั้ง 6 รายการ ชื่อและขนาด/โหมด/กริด/เฟรมตรงเดิมสำหรับ 5 ไฟล์ที่วาดทับ KO ตรงสเปกใหม่ จุดสัมผัสพื้นและความสูงอยู่ในช่วงที่กำหนดตามวิธีวัดข้างต้น มีข้อจำกัดของ placeholder และ RGB ระบุชัดใน JSON
2. เทียบแบบอนุมัติด้วยสายตาแล้ว อัตลักษณ์ หมวก อาวุธ ตะเกียง และมือที่ถือสอดคล้องกันทั้งชุด ให้ผู้ตรวจเป็นผู้รับรองด้านศิลป์ขั้นสุดท้าย
3. มี compare.jpg และ README ภาษาไทยครบ GIF ไม่เกี่ยวข้องเพราะไม่มี sheet ในชุด a
