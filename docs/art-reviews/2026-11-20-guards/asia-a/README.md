## นิยามพิกัดและข้อจำกัด

จุดฐานของภาพยืนคือกึ่งกลางแนวนอนของขอบเขตเท้าสองข้างและแถวล่างสุดที่ alpha ≥128 ใน ROI ที่ระบุใน `validation.json` ไม่รวมง้าวหรือชายผ้าคลุม ภาพนั่งใช้ฐานส่วนล่างของตัวละคร ภาพยืนเดิมมีฝ่าเท้าขวาถูกตัดที่ขอบล่างอยู่แล้ว จึงคงแถวฐานเดิมไว้

event เดิมเป็น placeholder ไม่มีเท้าจริง จึงใช้แนวฐานของ placeholder `(256,497)` เป็นจุดอ้างอิง ไม่อ้างว่าได้วัดเท้าจาก placeholder

คัตซีนเป็น RGB ที่มีฉากหลัง: เลือกจุดสัมผัสรองเท้ากับพื้นด้วยสายตา 2 จุด แล้วจัดภาพทั้งเฟรมด้วย affine transform ค่า residual ตรวจว่าจุดที่เลือกถูกแปลงตรงเป้าหมาย ไม่ใช่การค้นหาขอบรองเท้าจากพิกเซลภาพสุดท้ายโดยอิสระ

ความยาวท่านอนวัดแนวนอนจากหมวกถึงปลายรองเท้า ไม่รวมริบบิ้น ชายผ้า และง้าว เทียบกับตัวภาพยืน event บน canvas 512 px โดยไม่รวมความสูงง้าว ภาพยืนหลัก 1254 px ต้องเทียบหลังปรับเป็นสเกลเดียวกัน ตัวเลข landmark ของสัดส่วนนี้เป็นการเลือกด้วยสายตา

## ตรวจตนเองตามเกณฑ์รับงาน

1. **ไฟล์และ metadata ครบ**: 7 ไฟล์เดิมรักษาชื่อ/ขนาด/โหมด/เฟรม และเพิ่ม KO ตามขนาดที่กำหนด วัดฐานตัวละครได้ 0 px แต่ **ยังไม่ยืนยันเงื่อนไข ±2 px สำหรับเท้าแต่ละข้างจากพิกเซลโดยอิสระ** โดยเฉพาะคัตซีน ควรตรวจจุดนี้ต่อหากเกณฑ์ต้องการพิกัดรายเท้าแทนจุดฐานตัวละคร
2. **ลักษณะตามแบบ**: ตรวจภาพใหม่ใน compare แล้วพบหน้าแดง เคราดำยาว ผ้าคลุมเขียว มังกรทอง และง้าวมังกรเขียวตรงรายละเอียดหลัก ท่านั่งและท่านอนคงเครื่องแต่งกายเดียวกัน
3. **เอกสารส่งครบ**: มี compare, README และ validation.json พร้อมวิธีตรวจซ้ำและข้อจำกัด
