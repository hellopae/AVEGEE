## วิธีผลิตและขอบเขต

- ทำเฉพาะ `asia-b` บน branch/worktree ที่ได้รับ ไม่เปลี่ยน branch และไม่ commit/push/merge/deploy
- ImageGen ในตัว 12 ครั้ง: ภาพที่ใช้จริง 11 ภาพ และท่าเดินยกเข่าที่ทิ้ง 1 ภาพเพราะถือง้าวผิดด้าน แนบแบบอนุมัติและเฟรมต้นฉบับแยกทุกครั้ง ไม่ส่งทั้ง sheet เข้า ImageGen
- ภาพที่ใช้จริงเก็บเป็น WebP lossless ใน `generated/`; prompt และประวัติภาพที่ทิ้งอยู่ใน `prompts.json`
- ตัด alpha ส่วนโปร่งบางต่ำกว่า 16 ปรับส่วนทึบกลับเป็น 255 แล้วย่อ/ขยายและประกอบด้วย Pillow บันทึก game asset แบบ lossless RGBA
- Combat เฟรม 5 ใช้ภาพยืนจากเฟรม 0 แล้วจัดขนาด/ตำแหน่งตามต้นฉบับ; idle ใช้ภาพหลักเดียวและปรับการหายใจเล็กน้อย เฟรม 2 ทำตาปิดจากการประกอบพิกเซลผิว/ขอบตาของภาพที่วาดแล้ว; walk เฟรม 2 ใช้ท่าก้าวหลักแล้วจัดขนาดตามต้นฉบับ
- ปรับส่วนใบง้าวแยกจากตัวเพื่อให้คงความสูงคนและขอบเฟรมเดิม เฟรมตามแรงย่อเฉพาะส่วนอาวุธที่ยื่นพ้นมือ ไม่บีบตัวทั้งตัว
- ท่าเตรียมแทง combat เฟรม 2 คงการตัดขาหลังที่ขอบซ้ายตามต้นฉบับ และเลื่อนส่วนบนให้เอนเข้าหาทิศแทง จุดเท้าตรวจจากรองเท้าหน้า
- ไม่มีการแก้ `src/`, `tests/`, hooks, `status.json`, `worklog.json` หรือ zone/ชุดอื่น

## ผลตรวจไฟล์ปลายทาง

รันจากราก repo:

```sh
python3 docs/art-reviews/2026-11-20-guards/asia-b/build_assets.py
python3 docs/art-reviews/2026-11-20-guards/asia-b/verify_artifacts.py
```

ตัวตรวจอ่าน WebP ที่บันทึกจริงแยกจากการประกอบภาพ ตรวจ 88 รายการ ครบ 3 sheet / 16 เฟรม และเปิดถอดรหัส GIF ทั้ง 3 ไฟล์ได้ครบ 8/4/4 เฟรม กรอบ atlas ที่เกมใช้อ่านเทียบกับข้อมูลเดิมเท่ากัน

| รายการวัด | ผลสูงสุด | เกณฑ์ |
|---|---:|---:|
| จุดเท้าแกน x | 0.5 px | ±2 px |
| จุดเท้าแกน y | 0 px | ±2 px |
| ความสูงจากยอดศีรษะถึงพื้นรองเท้า | 0% | ±3% |

วิธีวัด: alpha >127; ยอดศีรษะวัดในแถบศีรษะที่ระบุซึ่งไม่รวมอาวุธ จุดเท้าเป็นกึ่งกลางแนวนอนของพิกเซลรองเท้าใน 20 แถวล่าง และ y เป็นขอบล่างแบบ exclusive ภายใน ROI ของรองเท้าที่สัมผัสพื้น ใช้ ROI เดิม/ใหม่ที่บันทึกแยกชัดเจนใน `validation.json` จึงตรวจซ้ำได้ ไม่ใช้กรอบรวม alpha แทนความสูงคน เพราะต้นฉบับมีอาวุธและชิ้นส่วนล้ำเซลล์

`landmarks.jpg` แสดงเส้นยอดศีรษะสีม่วง จุดเท้าสีน้ำเงิน และกรอบรองเท้าสีเขียวประกอบการตรวจตัวเลข

## ตรวจตามเกณฑ์รับงาน

1. **ไฟล์ครบและโครงสร้างเดิม:** ครบทั้ง 3 เส้นทางเดิม ขนาดผืน กริด 8/4/4 เฟรม และ RGBA เท่าเดิม ผลวัดเท้า/ความสูงอยู่ในค่ากำหนด ดู `validation.json` และ `source-metadata.json`
2. **ตัวละครและท่า:** เปิดดูภาพที่ประกอบแล้วเทียบกับแบบอนุมัติ มีหน้าแดง เคราดำยาว เกราะและผ้าคลุมเขียวลายมังกรทอง ถือง้าวมังกรเขียวด้วยท่าทีเคารพ ไม่มีตัวอักษรหรือเลือด ลำดับ combat คือยืน/ง้าง/เตรียมแทง/แทง/ตามแรง/ยืน/โดนตี/ก้มฟื้นท่า; idle และ walk หันซ้ายตามเดิม
3. **หลักฐาน:** `compare.jpg` เดิมซ้าย/ใหม่ขวา, `combat.gif`, `idle.gif`, `walk.gif`, ภาพแยกเฟรม `*-frames.jpg` และ README ภาษาไทยนี้ครบ

ข้อจำกัดการตรวจ: ตรวจไฟล์ภาพและถอดรหัส GIF แล้ว แต่ไม่ได้เปิดเล่นในเกมหรือประเมินการเคลื่อนไหวใน runtime ผลตัวเลขเป็นการวัดตามบริเวณกายวิภาคที่ระบุ ไม่ใช่คำยืนยันว่าทุกขอบของอาวุธ/ผ้าคลุมตรงต้นฉบับ ภาพก่อนส่งยังควรได้รับการตรวจรับด้านศิลป์จากผู้อนุมัติ
