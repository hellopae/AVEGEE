# CONSTRUCTION-ANIM — ไซต์ก่อสร้างโซน 1

ภาพวาดด้วย **ImageGen ในตัวเท่านั้น** จัดทำ 10 พ.ย. 2569 ตาม brief 5 พ.ย. 2569
ไม่ได้ใช้ Shado ไม่แก้ไฟล์เกมใน `src/`, `tests/` หรือ `img/` และไม่ได้ติดตั้งภาพเข้าเกม

## สเปกและการใช้

ทุก stage เป็น **WebP RGBA แบบแถวเดียว 8 เฟรม** ขนาดแผ่น **5632×704 px**
แต่ละเฟรม **704×704 px**, **8 fps**, วนรอบ **1 วินาที** ใช้ `foot: [352,640]` px
และ `worldWidth: 256` (ความกว้างทั้งเฟรมในโลก) เหมือนกันทั้งหมด ไม่มีหลังคา ผนัง ช่อฟ้า หรืออาคารสำเร็จ
มีเฉพาะลานดินขอบหิน เสา ปั้นจั่น นั่งร้าน วัสดุ และวิญญาณคนงานตัวเล็ก
ฐานที่ส่งออกกว้าง **600 px** เท่ากันทุกเฟรม (วัด alpha >100 ในครึ่งล่าง)
ฐานจึงกว้าง **218.18 หน่วยโลก** และได้ **2.75 px/หน่วยโลก**
โดยย่อจากงานวาดต้นฉบับ ไม่ได้เพิ่มขนาดภาพเพื่อให้ถึงเกณฑ์

เลือก stage-1 ที่ 0–33%, stage-2 ที่ 33–66%, stage-3 ที่ 66–100%
ช่องภาพเฟรม `i` คือ `[i*704,0,704,704]` จุดวางใช้ foot ภายในเฟรม ไม่ใช่มุมล่างของแผ่นภาพ
พิกัดเกมปลายทางตาม brief คือ `img/construction/th/stage-N.webp`; งานนี้เก็บเฉพาะชุดตรวจภาพใน docs

## วิธีทำและหลักฐาน

วาด stage-2 ก่อน แล้ว stage-1 แล้ว stage-3 ระยะละสองชุด ชุดละสี่ท่าใหม่
ใช้ภาพชุดก่อนเป็น reference ภาพชุด a และ b เรียงตามแถวซ้ายบน → ขวาบน → ซ้ายล่าง → ขวาล่าง
เฟรมส่งออกใช้ทุก cel หนึ่งครั้ง ไม่มีการสร้างท่าด้วยการเลื่อน เฟด ทำ ping-pong หรือแทรกเฟรมภาพนิ่ง
สคริปต์แยกภาพต้นทาง ย่อลงเล็กน้อยด้วย bilinear ให้ฐานกว้าง 600 px เท่ากัน
แล้วขยับลง canvas ด้วยจำนวนพิกเซลเต็มเพื่อจัด foot ไม่ขยายภาพ ไม่สร้างท่าหรือการเคลื่อนไหวด้วยโค้ด
และส่งออก alpha จากภาพวาด โดยบันทึกอัตราย่อกับตำแหน่งของแต่ละ cel ในรายงาน
เลือก bilinear หลังพบ LANCZOS สร้างพิกเซลขอบแดงจางเพิ่ม 1 พิกเซลในการตรวจรอบแรก

เรียก ImageGen รวม **9 ครั้งจากเพดาน 12**: เลือกใช้ 6 ภาพ,
คัดทิ้ง 1 ภาพเพราะปลายปั้นจั่นคล้ายช่อฟ้า และแทนชุดคืนท่า stage-1 อีก 1 ภาพด้วยฉบับแก้ที่ฐานนิ่งขึ้น
อีก 1 คำขอถูกระบบปฏิเสธในขั้นสร้างผลลัพธ์และไม่มีภาพส่งกลับ จากนั้นวาดคำขอไซต์ก่อสร้างทั่วไปใหม่ได้
ฉบับแก้ stage-1 ทำให้ silhouette ส่วนล่างซ้อนกับเฟรมแรกอย่างน้อย 94.7% แทน 89.5%
และความต่างท้ายลูปกลับต้น (MAE บนพื้นเทา) ลดจาก 5.52 เป็น 4.72 บนสเกลสี 0–255

อ้างอิงวัสดุ แสง และมุมกล้องจาก `canteen-1409.png` ในโฟลเดอร์ owner-1408 ที่ผู้ใช้ระบุ
ใช้ภาพนี้แทนโฟลเดอร์ `AVEGEE-reference/.../New Pic Map Zone1/` ซึ่งไม่มีในเครื่องรอบนี้
อ้างอิงวิญญาณสีขาวจาก `construction-1408.png`; worker sheet ใน repo เป็นคนงานตัวแดง จึงใช้ดูสัดส่วนเท่านั้น
ภาพประกอบอ้างอิงที่ย่อเพื่อเทียบสไตล์อยู่ใน `sources/style-reference.jpg` ไม่มีการเขียนทับต้นฉบับของเจ้าของ

## ตรวจด้วยสคริปต์

```sh
python3 -B docs/art-reviews/2026-11-05-construction-anim/export.py
python3 -B docs/art-reviews/2026-11-05-construction-anim/verify.py
```

การตรวจครอบคลุมจำนวนเฟรม/ความไม่ซ้ำ ขนาด atlas และ RGBA ขอบเฟรมไม่ตัดภาพ metadata ตรงกัน
GIF วนรอบและระยะเวลา ความละเอียดฐาน ≥2.56 px/หน่วย และขนาดชุดไม่เกิน 30 MB
การคัดกรอง fringe นับพิกเซลขอบ alpha 9–247 ที่แดงหรือเหลืองอิ่มจัดตาม threshold ในสคริปต์
เป็นการตรวจเชิงตัวเลขร่วมกับภาพเทียบสามพื้นหลัง ไม่ใช่หลักฐานว่าสีขอบทุกเฉดไม่มีปัญหา

## ข้อจำกัดที่ต้องตรวจรับ

ตำแหน่ง foot และขนาด canvas ตรงกัน แต่ ImageGen วาดรายละเอียดฐาน/เสาใหม่ในแต่ละ cel
จึงมีความคลาดเคลื่อนระดับพิกเซลและ texture เปลี่ยนเล็กน้อย โดยเฉพาะรอยต่อชุด a → b และท้าย → ต้น
รายงานบันทึกความกว้างฐาน silhouette ส่วนล่าง และความต่างเฟรมทุกคู่รวมรอยต่อไว้ตามจริง
ไม่ควรตีความว่าองค์ประกอบนิ่งทุกพิกเซลล็อกตรงกัน หรือว่าตรวจ QA ในเกมแล้ว
งานนี้ตรวจแผ่นภาพและภาพเปรียบเทียบเท่านั้น ยังไม่ได้ทดสอบจุดเสียบของ FX3 หรือการวางบนแผนที่จริง

ผลตรวจและ self-check สรุปเพิ่มเติมใน `loop-review.json`

| เกณฑ์รับงาน | สิ่งที่ตรวจได้ | ข้อที่ยังไม่ยืนยัน |
|---|---|---|
| 1: สามระยะ เฟรมวาดจริง ลูป ฐานตรง ไม่มีอาคาร | ครบ 3×8 ท่า แผ่น RGBA แถวเดียว foot/ความกว้างฐานตรงกัน ไม่มีหลังคา/ผนัง/ช่อฟ้า | contour ฐานยังเปลี่ยนตามงานวาด: ส่วนล่างซ้อนเฟรมแรกอย่างน้อย 94.7%, 95.7%, 95.1% ตามระยะ; ขอบที่แถว y600/620/635 คลาดสูงสุด 9/4/5 px จึงยังไม่ยืนยันว่าลูปไร้รอยต่อและองค์ประกอบนิ่งล็อกตรงทุกจุด |
| 2: สไตล์เข้ากันและ alpha สะอาด | เทียบภาพโรงอาหาร/พื้น HD และตรวจขอบบนสามสี; ไม่พบพิกเซลขอบแดง/เหลืองอิ่มจัดตาม threshold ใน 24 เฟรม | การยอมรับสไตล์เป็นการตัดสินภาพ และยังไม่ได้ตรวจขณะวางบนแผนที่เกมจริง |

บันทึกคำสั่งตรวจไฟล์รอบสุดท้ายอยู่ใน `tests-run.txt` การตรวจไฟล์ไม่ใช่การรับรอง QA ในเกม
