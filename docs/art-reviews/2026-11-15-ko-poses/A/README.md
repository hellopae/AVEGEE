# ชุด A — ท่านอนสลบ โซน th

ส่งครบ **8/8 ตัว**: yama, taan, kan, dam, boon, plerng, guard, nira — ไม่มีตัวที่ขาด
ใช้ **ImageGen ในตัว 8 ครั้ง** แนบ sprite เดิมทุกครั้ง ไม่ใช้ Shado และไม่ทำโซนอื่น

ไฟล์อยู่ที่ `img/ko-pose-v1/th/<key>.webp` ใต้โฟลเดอร์นี้ ทุกไฟล์เป็นภาพเดียว **640×320, RGBA, WebP lossless** มี alpha โปร่งใสจริง ขอบโปร่งใสรอบภาพอย่างน้อย **20 px** ไม่ได้วาดพื้นตารางลงใน sprite

ดู [contact-sheet.jpg](contact-sheet.jpg) เพื่อเทียบภาพตั้งต้นทางซ้ายกับท่านอนทางขวา ที่ขนาดพิกเซลจริง ภาพตั้งต้นยามาใช้ `sword-hurt.webp` เซลล์แรก, ลูกทีมใช้ `<key>.webp` แถวล่างเซลล์แรก, นิราใช้ idle เซลล์แรก; ทัณฑ์ ดำ บุญ เพลิง และยักษ์มี idle sprite ของโซนเดียวกันแนบเพิ่มตอนสร้างเพื่อดูของถือครบ

## สเกล

ย่ออย่างรักษาสัดส่วนจากผล ImageGen ให้ตรงช่วงพิกเซลของใบงาน แล้ววางกึ่งกลางผืน ไม่ยืดเฉพาะแกน ตัวเลขแนวตัวด้านล่างวัดโดยเลือกจุดหัว/เครื่องประดับถึงปลายเท้าด้วยมือแล้วคำนวณระยะ จึงเป็นค่าประมาณ ส่วน bbox ใช้ **alpha > 40** เช่นเดียวกับสคริปต์นำเข้า และไม่ใช้ bbox แทนความยาวแนวตัว

| ไฟล์ | ช่วงใบงาน (px) | แนวหัวถึงเท้า ≈ (px) | ความกว้าง bbox (px) |
|---|---:|---:|---:|
| yama.webp | 290–323 | 323 | 311 |
| taan.webp | 298–331 | 321 | 321 |
| kan.webp | 338–376 | 359 | 361 |
| dam.webp | 320–355 | 339 | 341 |
| boon.webp | 321–357 | 349 | 343 |
| plerng.webp | 348–387 | 374 | 371 |
| guard.webp | 342–380 | 371 | 365 |
| nira.webp | 339–377 | 364 | 359 |

จุดวางที่ `entry_for()` คำนวณได้คือ `[320,300]` ยกเว้น guard/nira เป็น `[320,299]` ของถือวางชิดตัวและไม่มีเงาพื้นแยกออกไป

## ผลตรวจและตรวจตนเองตามเกณฑ์

1. **ไฟล์:** Pillow เปิดครบ 8 ชื่อ ขนาด โหมด RGBA เฟรมเดียว alpha 0–255 และตรวจ chunk `VP8L` ของ lossless; ตรวจขอบพิกเซล alpha ที่ไม่เป็นศูนย์ได้อย่างน้อย 20 px ภาพไม่มีตัวอักษรจากการดูเทียบ
2. **ตัวละคร/ท่า:** ดูเทียบ contact sheet ครบ 8 ตัว คงหน้า ผม/เขา สี ชุด และของถือของโซน th; วาดท่านอนใหม่ หัวซ้าย เท้าขวา ตาปิด แขนขาผ่อนคลาย ไม่มีเลือดหรือบาดแผล
3. **ความยาว:** ค่าประมาณแนวหัวถึงเท้าทั้ง 8 อยู่ในช่วงตาราง ตรวจความกว้าง bbox และจุดกึ่งกลางด้วยสคริปต์เพิ่มเติม
4. **เอกสาร:** มี contact sheet ยืน/นอนครบ 8 ตัวและ README นี้

การตรวจด้วยโค้ด: รัน Pillow assertions สำหรับชื่อไฟล์/ขนาด/alpha/ขอบ/สเกล bbox และโหลด `scripts/add-ko-poses.py` ด้วย `runpy` เรียก `entry_for()` กับไฟล์ส่งออกทั้ง 8 ตรวจ frame, anchor, bodyHeight และโหมด ko ได้ครบ โดยไม่เขียน manifest จริง ไม่ได้รันทดสอบเกมหรือยืนยัน QA ในเกม

## Prompt ที่ใช้ (สรุป)

ใช้ `identity-preserve` ทุกตัว: แนบ sprite โซน th, คงหน้า/สี/ชุด/สัดส่วน/ลายเส้นเดิม, วาดนอนหงายใหม่มุม 3/4 จากบนเล็กน้อย หัวซ้ายเท้าขวา ตาปิด แขนขาผ่อนคลาย, alpha โปร่งใส ผืน 2:1 เผื่อขอบ, ไม่มีข้อความ/พื้น/เงาแยก/เลือด/บาดแผล/ตัวอื่น และไม่หมุนรูปยืน ระบุความยาวเป้าหมาย 310/320/360/340/342/370/365/360 px ตามลำดับตาราง

รายละเอียดแยก: yama มงกุฎ/ดาบทอง; taan ผมหงอก/เกราะไหล่/กระบอง; kan แว่นกลม/ผมมวย/ชุดดำทอง; dam หูค้างคาว/ปีกแดง/ถังถ่าน/ค้อน; boon ผิวมิ้นต์/จีวรส้ม/บัวชมพู; plerng ผมไฟ/ลายไฟแขน/ชุดม่วงขอบทอง; guard ยักษ์เขียว/ชฎา/เกราะตาราง/คทา; nira ผิวม่วง/เขาคู่/ผมมวย/กระโปรงแดง/เอกสารกับตราประทับ ของถือวางชิดลำตัว
