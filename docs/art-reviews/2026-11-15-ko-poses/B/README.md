# ท่านอนสลบ F8 — ชุด B / asia

ส่งครบ 8 ตัว: `yama`, `taan`, `kan`, `dam`, `boon`, `plerng`, `guard`, `nira` — ไม่มีตัวที่ขาด

ไฟล์พร้อมคัดลอกอยู่ใน `img/ko-pose-v1/asia/*.webp` ภายในชุดนี้เท่านั้น เป็น WebP lossless RGBA 640×320 ทุกไฟล์ โปร่งใสจริง ขอบว่างอย่างน้อย 32 px และกึ่งกลางพิกเซลที่มองเห็นอยู่ที่ x=320 (คลาดไม่เกิน 0.5 px) ขอบล่างที่มองเห็นคือ y=287

## ตรวจตามเกณฑ์รับงาน

1. ตรวจชื่อครบ 8 ไฟล์ ขนาด 640×320 โหมด RGBA ค่า alpha 0–255 และ codec VP8L ด้วย Python/Pillow; ตรวจภาพด้วยสายตาไม่พบตัวอักษร
2. เทียบกับ sprite ต่อสู้ asia ใน contact sheet: หัวซ้าย เท้าขวา ตาปิด แขนขาผ่อนคลาย ไม่มีเลือดหรือบาดแผล เก็บชุด สี เขา ผม และของถือของโซนนี้; แก้นิ้วเท้าทัณฑ์ให้ตรงต้นแบบแล้ว
3. ความยาวโดยประมาณในตารางอยู่ในช่วงใบงานทุกตัว วัดเส้นตรงจากจุดขอบหัว/หมวก/ผมด้านซ้ายถึงปลายเท้าขวาที่เลือกด้วยสายตา ไม่รวมอาวุธและของวางข้างตัว
4. มี `contact-sheet.jpg` จับคู่ยืน | นอนครบทุกตัว แสดงสเกลพิกเซล 1:1 พื้นตารางใช้เฉพาะภาพรีวิว ไม่ได้ติดใน WebP

ใช้ ImageGen ในตัว 9 ครั้ง (8 ภาพ + แก้เท้าทัณฑ์ 1 ครั้ง) แนบ sprite เดิมทุกครั้ง บันทึก prompt ทั้งชุดใน `prompts.txt` ต้นแบบยามาใช้ `sword-hurt.webp` เฟรม 2, ลูกทีมใช้ `<key>.webp` เฟรม 5, นิราใช้ `asia.webp` เฟรม 0 (นับจาก 0)

หลังสร้างมีเพียงการตัดขอบโปร่งใส ย่อเท่ากันทั้งสองแกนตามความยาวที่กำหนด จัดวางบนผืน 640×320 และแปลง lossless; ตัดค่า alpha ≤8 ซึ่งเป็นจุดรบกวนเกือบมองไม่เห็นรอบผืน โดยเก็บขอบโปร่งแสงส่วนอื่นไว้

ตรวจไฟล์ที่บันทึกจริงครบ 8 ตัวและเปิด JPEG ได้ ตรวจภาพ contact sheet แล้ว ยังไม่ได้เสียบหรือทดสอบในเกม งานเสียบ manifest และตรวจภาพในฉากจริงยังเป็นขั้นตอนของผู้รับงานตามใบงาน
