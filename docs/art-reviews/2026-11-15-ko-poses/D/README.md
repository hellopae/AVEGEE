# ชุด D — cyberhell: ท่านอนสลบ F8

ส่งครบ 8 ตัว ไม่มีตัวที่ขาด: `yama taan kan dam boon plerng guard nira` ใน `img/ko-pose-v1/cyberhell/<key>.webp` ใต้โฟลเดอร์นี้ ใช้ ImageGen ในตัว 8 ครั้ง พร้อมแนบ sprite cyberhell เดิมทุกครั้ง พรอมป์ต์และวิธีเตรียมภาพอยู่ใน [PROVENANCE.md](PROVENANCE.md)

ภาพใหม่เป็นท่านอนหงาย/เอียงข้าง แขนขาผ่อนลง หัวซ้าย เท้าขวา ตาปิด ไม่มีเลือด บาดแผล หรือข้อความ Guard คงเลนส์ตาไซเบอร์สีฟ้า ส่วนตาธรรมชาติปิด ตรวจเทียบหน้า ชุด สี และอุปกรณ์ด้วยตาจาก [contact-sheet.jpg](contact-sheet.jpg) แล้ว; รายละเอียดลายชุดเป็นภาพวาดใหม่ จึงยังต้องให้ Toby ตรวจรับความตรงกับต้นแบบ

ทุกไฟล์เป็น WebP lossless RGBA 640×320 พื้นหลังโปร่งใสจริง จัดกลางแนวนอน เว้นขอบเกิน 12 px ตัดเฉพาะ alpha≤1 ที่กระจายนอกภาพแล้วปรับสเกลแบบรักษาสัดส่วน ไม่ใช้การหมุนภาพยืน พื้นตารางหมากรุกมีเฉพาะ JPEG สำหรับดูงาน
