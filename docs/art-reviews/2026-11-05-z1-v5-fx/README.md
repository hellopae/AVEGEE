## ทำอะไร

1. **ของเหลว/เมฆเล่นจากเฟรมที่ Codex วาด** — `src/town-fluid-fx.js` อ่าน `img/map-zone1/v5-fx/fx-layout.json` (44 ชิ้น: ลาวา 6, ลาวาตก 8, แม่น้ำม่วง 2, ลำธารฟ้า 5, น้ำตกฟ้า 11, ฟองริมตลิ่ง 7, เมฆม้วน 1 + ก้อนเมฆ 4)
   แต่ละชิ้นถูกตัดด้วย mask (coverage → alpha) แล้ววางทับพื้นด้วย blend/opacity ตามที่ Codex กำหนด (overlay / normal) · พิกัดเป็นหน่วยโลก (3840×2560) จึงไม่ผูกกับความละเอียดพื้น
2. **ผสมเฟรม** — ระหว่างเฟรมวาด N→N+1 (รวม 4→5 และ 8→1) ผสมแบบเส้นตรงตามเวลา ด้วย premultiplied add (1−m, m) = ผสมจริงระหว่างสองเฟรมที่วาด ไม่ใช่เลื่อน/เฟดภาพเดียว
   วัดจากภาพที่เรนเดอร์จริงในเกม (`seam-check.json`): ค่ากลางของการเปลี่ยนต่อเฟรมรอบรอยต่อชุด ÷ กลางเฟรม = **0.99** (ไม่มีสไปก์)
3. **ปิดของเดิมที่ซ้อน** — `town-flow.js` (อนุภาคน้ำ/ลาวา จาก `flow-v4.png`) หยุดทั้งหมดขณะชั้นใหม่ทำงาน (ไม่โหลด flow-v4.png ด้วย) · เมฆ gradient เดิมเหนือประตูสวรรค์ (`drawTownClouds`) ปิดขณะ cloud-sea ทำงาน
   ถ้าโหลด layout ไม่ได้ ระบบเดิมกลับมาเอง
4. **หมอกก้อนขาว "แปะ"** — ไม่ได้นำ `fog-bank` ของ Codex มาใช้เลย · ก้อนหมอกลาเวนเดอร์ที่ขอบแผนที่ (เช่นซ้ายสุดริมลาวา) **วาดมากับพื้น v5 อยู่แล้ว** (ดู chunk `r1-c1`/`r2-c1`; ปิดการตั้งค่า weather แล้วก็ยังอยู่) ไม่มีโค้ดชั้นไหนวาดก้อนพวกนี้
   `MAP_FX.fog` ถูกใช้เฉพาะโซน 3 (west) · ถ้าคุณเป้ไม่อยากเห็น ต้องให้ Codex วาดพื้น v7 ใหม่โดยไม่มีก้อนนี้
5. **เงาเมฆบนพื้น** — ความเข้มสูงสุดยัง `.32` เท่าเดิม · ก้อนเป็นรูปเมฆจริง (5 แบบ ×2 พลิกซ้ายขวา) ตัดจาก alpha ของเมฆที่คุณเป้ส่ง (#27) + `cloud-01..04` แล้วเบลอขอบ · ความครอบคลุมเพิ่ม (ดูตัวเลขใน Output note) · โซน 2–4 และแผนที่ชายแดนไม่เปลี่ยน
6. **ตัวโหลดพื้นรองรับ 2×** — `ZONE1_GROUND_SET` ใน `src/zone-skin.js` ที่เดียว (`'v5'` → `'v7'`) · ทดสอบด้วยชุดจำลอง 2× ในเบราว์เซอร์จริง (ภาพจำลองไม่ได้ commit)
7. **โรงอาหาร** — `img/food-art/canteen-th.webp` ใหม่จากภาพ #4 (`scripts/build-canteen-th.py`) · วางที่เดิม (`TOWN_HOUSE_SITES[3]`) ขนาดเท่าเดิม
