## เลเยอร์และพิกัด

1. ฉากไกล: แยกจากภูเขาใกล้ จึงปรับ Parallax ได้.
2. ผิวของเหลว: หน้ากาก world-locked เว้นรูตรงเกาะ/หิน/ต้นไม้; เลื่อนวัสดุหรือเปลี่ยนเฟรมเฉพาะด้านใน.
3. พื้น/สะพาน/บันได/หน้าผารับพื้น: world-locked ใช้ collision เดิมเป็นเกณฑ์.
4. เกาะหิน/ตลิ่ง/พืชคงที่: แยกจากน้ำ และวางก่อนหรือหลังพื้นตามตำแหน่ง. Nature plate เป็นแหล่งชิ้นภาพ ต้องตรวจแบ่งชิ้น/ฐานก่อนใช้ depth sorting ในเกม.
5. อาคาร/ต้นไม้/ตัวละคร/เสา/ราว: เรียงจากฐานหรือเท้า ไม่ใช้ยอดภาพ. ส่วนบังกับฐาน collision เป็นคนละข้อมูล.
6. ใบไม้ หิมะ ฝน เมฆ หมอก และเงาเมฆ: ใช้ระบบแยกจากภาพหลัก; ไม่อบกลับลงพื้นใหม่.

`map-layers.js` รองรับ rect, source atlas, clip, phase, world lock, pause/reduced-motion และโหลดตามลำดับ.
`map-structures.js` แยก silhouette ของเสา/ราวจาก footprint; ตัด footprint ออกจาก mask สำเนา ไม่แก้ owner mask. Vertical runs เป็นต้นแบบ ต้องตรวจฐานเชิงภาพก่อนลงเกม.
`map-surface-material.js` เป็นตัวอย่างการเลื่อนวัสดุภายใน alpha จาก **liquid-only plate**; ห้ามเอาภาพภูเขาหรือต้นไม้รวมมาสร้างหน้ากากจากสีอย่างเดียว.

## สถานะการตรวจและข้อจำกัด

- ชายแดน1–2 มี floor, rails, nature, liquid, texture atlas และ foliage atlas แยกไฟล์. `terrain-study.png`/`terrain-v2.png` เป็นร่างก่อนแยกราว ไม่ใช่ไฟล์พื้นรุ่นสุดท้าย.
- Foliage atlas มี alpha จริงและผ่านการดูบนพื้นตาราง. ไฟล์ที่ลงท้าย `rejected` เป็นสำเนาจากการวินิจฉัยครั้งแรกก่อนตรวจ alpha ไม่ใช่ผลตรวจสุดท้าย; ไม่ได้ลบไฟล์.
- Nature บางภาพกว้างต่างต้นฉบับ1px; หน้าตรวจใช้พิกัด normalized จึงแสดงผลได้ แต่ยังต้องผ่านการตรวจ registration ก่อนใช้จริง.
- ไม่อ้าง high-detail native tiles ครบ80ตำแหน่ง. ภาพต้นแบบเมือง1536×1024 ใช้แยกโครงสร้างเลเยอร์; งานรายละเอียดเพื่อซูมยังไม่ปิด.
- `registration-audit.json` ตรวจ alpha ครอบ owner floor เท่านั้น ไม่ใช่การรับรองว่าพิกเซลทึบทุกจุดเป็นพื้นเดิน (อาจเป็นหน้าผาหรือเสา).
- จุดต้นไม้ f2 ยังต้องตรวจราก/ขนาด. ภูเขาและพุ่มไม้ใน nature plate ยังต้องแบ่ง foreground ตามฐาน ไม่ควรใช้ทั้งภาพเป็นชั้นบนสุด.
- ยังไม่มี physical mobile FPS; browser viewport390ไม่ใช่มือถือจริง. ไม่มีข้อสรุปเพิ่มframe timeไม่เกิน2ms.
- ยังไม่แก้ conflict ใน worktree onboard-preview หรือแตะไฟล์ค้างของ checkout เก่า.

## ทำต่อก่อนติดตั้ง

ตรวจรอยต่อแบบซ้อนต้นฉบับ, ขอบ alpha, floor/rails alignment, จุดประตู/ถ้ำ/สถานี และการเดินจริง. แบ่ง nature plate เป็นชิ้นที่กำหนด baseline พร้อมฐานกั้นเฉพาะวัตถุ. ตรวจ sprites/UV loop และผิวแม่น้ำแต่ละทิศทาง รวม mask ที่ไม่โดนหิน/พืช. จากนั้นสร้าง native-detail tiles โดยคงขอบชิ้น/ผัง และทดสอบ perf บนอุปกรณ์จริงก่อนเปลี่ยน runtime.
