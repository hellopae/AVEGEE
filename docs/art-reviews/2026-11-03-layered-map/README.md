## กล้องและการโหลด

- เลือกเพียง2ระดับ: ชายแดน2.0×/2.6×, เมือง2.6×/3.4×. ตั้งให้ความสูงตัวละครประมาณ10%/13%ของviewport16:9. ไม่มีระดับดูแผนที่เต็มในหน้าทดลองใหม่.
- กล้องตามเท้าYamaอย่างนุ่มนวลและหยุดที่ขอบโลก. แปลงตำแหน่งคลิกกลับเป็นพิกัดโลกก่อนหาเส้นทาง.
- พื้น/ธรรมชาติ/ราว/ของเหลว/หน้ากากวัสดุถูกส่งออกเป็นชิ้น256pxพร้อมgutter2px. โหลดเฉพาะviewportและขอบเผื่อ96art pixels; เรียกdecodeพร้อมกันไม่เกิน2ภาพ.
- เมื่อชิ้นภาพพ้นบริเวณเก็บ จะปิดImageBitmapและคืนหน่วยความจำ. เปลี่ยนฉากยกเลิกfetchของฉากเก่า. เงื่อนไขพร้อมเดินรอภาพที่จำเป็นในจอ เพื่อไม่เดินเข้าฉากที่ยังไม่โหลด.
- แคชbitmapกำหนด48MiB, แคชเบลอกำหนด12MiB; ไม่ใช่เพดานRAMรวมbrowser/GPU. Backing canvasปรับตามจอ/DPRและไม่เกิน1200px.
- ฉากไกลใช้ภาพเล็ก768×432. ตัวละครใช้แถวแอนิเมชัน160×240ต่อเฟรม แยกทิศทางจากชุดเดิม แทนโหลดชีต2560×1920ทั้งแผ่น. ท่าถือหนังสือ/เดินและจุดเท้าใช้ข้อมูล `yama-fit.js` เดิม.
- น้ำ/ลาวาเปลี่ยนเฟรมเฉพาะหน้ากากของเหลว. หิน พืช ตลิ่ง และแสงเครื่องจักรอยู่ชั้นคงที่. ไม่เลื่อนภาพน้ำทั้งแผ่น.
- DOFเป็นการแบ่งระยะในเกม2D: พื้นและYamaคมชัด, ฉากไกลและวัตถุที่อยู่หน้าระยะโฟกัสเบลอจากแคช. ฉากไกลเคลื่อนช้าตามกล้อง. ฐานต้นไม้ เสา ราว และcollisionใช้พิกัดโลกเดียวกัน ไม่มีparallaxที่ทำให้ฐานลอย.
- สภาพอากาศบนชายแดนเปลี่ยนสัดส่วนตามตำแหน่งYamaอย่างนุ่มนวล เพื่อไม่เกิดเส้นตัดตรงกลางภาพจากการclipคนละbiome.

## แหล่งภาพและลำดับชั้น

ทั้ง7ฉากมีfloor/nature/rails/liquid-onlyแยกอยู่ในfolderนี้. เมือง4โซน1536×1024, ชายแดนประกอบ1672×941. บางrawplateต่างต้นฉบับ1px; ส่งออกด้วยพิกัดnormalizedเดียวกัน.

`object-depth.json` แยกประตู/ปากถ้ำ/เสาประดับ15ชิ้นของชายแดน. `town-object-plan.json` ยึดพิกัดต้นไม้/หิน/บ้าน/สถานี/แท่น176ชิ้นจากเกมเดิม. ชายแดน1–2มีต้นไม้ฉากหน้า21จุดจากf2เพิ่มด้วย. ราวและทุกวัตถุเรียงร่วมกับเท้าตัวละคร; ฐานกั้นทางเป็นข้อมูลแยกจากภาพหลังคา/ยอดไม้.

พื้นชายแดนซ่อมเฉพาะช่องalphaบนเซลล์พื้นเดิม โดยไม่ทับส่วนทึบหรือเปิดทางใหม่:

| ฉาก | พิกเซลซ่อมทั้งหมด | เศษช่องใช้วัสดุจากpatchเดียวกัน | alpha coverageหลังประกอบ |
| --- | ---: | ---: | ---: |
| 1–2 | 836 | 327 | 100% |
| 2–3 | 2126 | 731 | 100% |
| 3–4 | 5207 | 917 | 100% |

`border-floor-repair-review.json` เป็นผลประกอบ; raw PNGในmanifestอาจยังมีช่องก่อนpatch. **100%เป็นเพียงความทึบ ไม่รับรองลวดลาย ผัง หรือการตรวจรับเชิงภาพ.** เศษวัสดุจำกัด1024pixelsหลังทำtargetedpatchแล้ว ไม่ใช้textureกลบmismatchขนาดใหญ่.

Spriteน้ำและลาวาอย่างละ8เฟรม4×2; ใช้8fps/6fps และส่งออกแผ่นเล็ก512×256สำหรับstreaming. ยังต้องเก็บทิศน้ำตก/รอยต่อของloopแต่ละบริเวณก่อนใช้จริง.
