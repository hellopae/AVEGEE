# AVEGEE · FB3-C6 หัวหน้าคนงานบูรพา ปัจฉิม และนรกเครือข่าย

วาดชิ้นตัวด้านหน้า ด้านข้าง และด้านหลัง พร้อมขา กระสอบ ถาดข้าวปั้น และท่ายืนคุมครัวด้วย ImageGen ในตัว อิงชุดเดิมของแต่ละโซน โครงใช้จังหวะขาสลับและยกเท้า ส่วนลำตัวและของที่ถือขยับสัมพันธ์กัน อบเป็นชีตสำหรับตัววาดเดิมของ AVEGEE โดยไม่เพิ่ม runtime

ชีต 2,560×1,280 มี 4 ทิศ × 8 เฟรม ขนาดช่อง 320×320 เฟรมละ 125 ms จุดวางเท้า x=160 และ y=320 ตามสัญญาเดิม สีโปร่งใส นำเข้าเกมผ่าน `damCarryAssets` ตามชื่อไฟล์เดิมที่จองไว้
