# FB3-C4 คัตซีนยามาอัญเชิญด้วยตะเกียงวิเศษ

เสร็จครบ 4 โซน ภาพทั้งสี่ใช้ในจังหวะเริ่มอัญเชิญร่วมกัน ยามาประคองตะเกียงลายกลีบบัวด้วยสองมือ ไส้ตะเกียงปล่อยควันแสงทองและประกายดาวขึ้นเป็นเค้าร่างลาง ๆ ไร้ใบหน้าและลักษณะเฉพาะตัว ทั้งสี่ภาพใช้มุมกล้อง ท่าถือ ตำแหน่งตะเกียง และทิศทางควันเดียวกัน เปลี่ยนชุดยามาและโทนสนามรบตามโซน

## ไฟล์และขนาดก่อน → หลัง

## ภาพอ้างอิงและการตรวจ

- ใช้ ImageGen ในตัว 5 ครั้ง โดยสร้างเฟรมไทยตามภาพสไตล์ในใบงานและทรงตะเกียงที่สีดามอบให้ เก็บปลายชฎาให้อยู่ในเฟรม จากนั้นใช้เฟรมนี้เป็นต้นแบบเปลี่ยนชุดและฉากตามภาพอ้างอิงของอีกสามโซน
- เปิดดูภาพที่เข้ารหัสแล้ว ตรวจทรงชุดกับภาพอ้างอิงรายโซน ตำแหน่งมือและตะเกียง และเค้าควันทองที่ใช้ร่วมกันได้กับทุกตัวอัญเชิญ
- ตรวจชนิดภาพ ขนาด และขนาดไฟล์ทั้งสี่ ตรวจตัวเลือกภาพของเกมกับไฟล์จริงครบสี่โซน และรันทดสอบเดิมที่เกี่ยวกับตะเกียงและการอัญเชิญ 27 รายการ
