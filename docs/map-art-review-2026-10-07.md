# งานแก้ภาพแผนที่ — 7 ตุลาคม 2026

ผู้ใช้แบ่งงานวาดให้ Codex และงานระบบให้ Claude แต่ขณะ Claude ยังไม่ reset ผู้ใช้อนุญาตให้ Codex ทำการเชื่อมภาพ/การแสดงผลก่อนด้วย งานรอบนี้วาดและเชื่อมภาพครบแล้ว เตรียมส่งขึ้น GitHub Pages พร้อม commit นี้

ต้นฉบับ: `files/UI map Zone1/Map-Zone1-1.jpg`

ขอบเขตที่ผู้ใช้ยืนยัน: ใช้หลักเดียวกันครบทั้ง 4 โซน โดยคงธีมแต่ละโซน ไม่ต้องส่งภาพวงจุดเพิ่ม

- `st-sawan` และประตูไปชายแดน: มุมตรง front view (ผู้ใช้ยืนยันว่าไม่ได้หมายถึงช่องลาวาบนพื้นหลัง)
- ประตูไปชายแดน: ซุ้มเปิดหินดำคล้าย reference ประตูก่อนหน้า ไม่มีบานปิด
- ป่าดาบ: ไม่มีอาคาร มีลานดาบกับต้นงิ้ว
- ดงต้นงิ้ว: ไม่มีอาคาร เหลือลานต้นไม้หนาม
- กระทะทองแดง: เน้นกระทะใบใหญ่
- ตะราง หอทะเบียนกรรม หอส่องกรรม และลานตรากตรำ: มุมหันซ้ายและขยายภาพที่แสดงบนแผนที่
- เรือ: เลื่อนลงอยู่ในแม่น้ำ และถูกสะพานบังเมื่อพายลอด

ไฟล์ที่เปลี่ยนในรอบนี้: `src/art.js`, `src/scene.js`, `src/theme-assets.js`, `src/map-art-v5.js`, `scripts/make-preload-catalog.mjs`, `src/preload.js`, `img/preload-catalog.json`, `img/map-v5/`

ภาพใหม่ครบ 36 ชิ้น (9 สถานที่ × 4 โซน) ใน `img/map-v5/` ภาพ production เป็น lossless WebP โปร่งใส มี prompts ใน `img/map-v5/prompts.json` ภาพ raw อยู่ local `img/raw/map-v5/` ไม่รวมใน preload

ตรวจด้วยภาพบน renderer จริงครบ 4 โซน ไม่มี browser error; จุดใช้งานสถานที่ทั้ง 40 จุดวางเส้นทางจากสะพานถึงพิกัดจริงได้ครบ (ไม่มีการเลื่อนเป้าหมาย) ตรวจเรือทั้งฝั่งซ้าย ฝั่งขวา และขณะถูกสะพานบัง ภาพพรีวิวอยู่ `output/zone1-map-v5/`

ชุดทดสอบ 469 ข้อ: รอบแรกผ่าน 468 ข้อ อีกข้อยืนยัน path ภาพตะราง v4 เดิม จึงปรับ expected ให้เป็น v5 และทดสอบไฟล์ 30f ซ้ำเพื่อตรวจ alpha footprint/เส้นทางเดิน/restore save จริง รายงานผลอยู่ local `/tmp/avegee-map-v5-tests.txt`

งานเก่าที่ยังค้าง: ภาพตวาดข่มขู่ v4 ชุดโซน 1 และ 4 ผู้ใช้แจ้งว่าไม่ตรงกับชุดตัวละครจริง ดู `docs/claude-handoff-2026-10-07.md` ยังไม่ได้แก้ชุดนั้นในงานนี้
