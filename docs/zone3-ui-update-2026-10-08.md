# อัปเดตโซน 3 และ UI — 8 ตุลาคม 2026

แก้ไขในโปรเจกต์บนเครื่อง ยังไม่ได้เผยแพร่ขึ้นเว็บไซต์

## เนื้อเรื่องและการต่อสู้

- ชายแดนโซน 3: ลูกน้อง 2 ระลอก → คัตซีนสะกดจิต → ระลอก 3 ต่อสู้กับยมทูตที่เลือกจริงและ Guard ที่ร่วมทีม → ระลอก 4 แวมไพร์
- คัตซีนแสดงยมทูตทุกคนและ Guard โซน 3 ถูกควบคุม ไม่ผูกภาพกับทีมที่ผู้เล่นเลือก
- จับรายชื่อลูกทีมเมื่อเริ่มศึก ไม่กำหนดตายตัวเป็นทัณฑ์/ดำ ลูกทีมที่ถูกควบคุมหยุดช่วยในระลอก 3 และกลับมาช่วยหลังปลดปล่อย
- อ่านคัตซีนจบก่อนเริ่มระลอก 3 เมื่อชนะแวมไพร์จึงได้รับพลังสะกดจิต
- บอสโซน 3 ประกาศเป็นคู่แข่งฮาลวาร์ ต้องการบัลลังก์ และไม่ยอมรับเด็กน้อย หลังแพ้ยอมรับให้ปกครองโซน 3 พร้อมพลังน้ำแข็ง ใช้ story-west-01 และ story-west-02 เดิม

## ภาพและการเคลื่อนไหว

- ปรับ intro-zone3-west เป็นโทนฟ้าเย็น/แสงส้มทองตาม intro-head-west-v2
- วาดภาพใหม่ img/frontier-west-hypnosis-v1.png และเพิ่มใน preload catalog/manifest
- ความเร็วเดินชายแดนใช้ฐานเดียวกับแผนที่ พร้อมปรับรอบก้าวเดิน
- Yama โซน West กลับมาหันขวาหาศัตรูหลังโจมตี และวงคำสั่งวางใกล้ตัวละครที่เลือก

## ห้องและคู่มือ

- ศาลาน้ำชา: HP ใต้ปุ่มนอนพัก, MP ใต้ปุ่มดื่มชา; ตัดข้อความเทาด้านล่าง; HP ค่อย ๆ ฟื้นใน 5 วินาที ไม่มีภาพดำ; MP ค่อย ๆ ฟื้นขณะดื่มชา; เลื่อนท่านอน West ขึ้น
- ประตูสวรรค์: ปุ่มดอกบัวเหนือบุญ รวมตำแหน่งที่บุญเข้าเวร; เปิดตรวจกรรม/ตรวจวิญญาณได้โดยไม่ต้องยืนใกล้บุญ
- ตะราง: เลื่อนวิญญาณให้ตรงแท่นและวาดโซ่ล่าม
- ขนาดตัวอักษร ปุ่ม รายชื่อ และหน้าต่างห้องทุกโซนเล็กลงด้วย compact-ui.css
- คู่มือแบ่งหัวข้อเป็นการ์ด พร้อมสีกรรม/บุญ/บรรเทา สมการ และสเกลความแรง
- หอส่องกรรมทุกโซน: วางกระจกวิเศษบนแท่น → ปรับองศากระจกสะท้อน → ค้างแสงให้ถึงกระจก 1.8 วินาทีเพื่อเติมพลัง +1; ตรวจการปลดล็อก พลังเต็ม และคูลดาวน์เดิม

## โหลดและเสียง

- ตรวจรายการที่โหลดสำเร็จแล้วก่อนแสดงหน้าดาวน์โหลด กลับเข้าโซนเดิมในเซสชันไม่โหลดซ้ำ
- เก็บภาพใน Cache Storage เมื่อเบราว์เซอร์รองรับ; ไฟล์ล้มเหลวยังลองใหม่ได้
- เสียงได้ไอเท็ม/พลังใหม่ และเสียง level up แยกกัน เพิ่มปุ่ม Mute/Unmute ใน Settings พร้อมจำค่าปิดเสียง
