## หลักฐานตรวจจริง และข้อจำกัด

2. อ่าน `docs/handoffs/20261021-interrogation-implementation.md` ประกอบ baseline และ `BACKLOG.md` ใน checkout แม่เพื่อทวนรายการเดิม ห้าม copy ทั้ง BACKLOG/โค้ดสาขาแม่ทับ release
3. เลือกงานค้างด้านบนเป็นชุด ระบุไฟล์ที่รับผิดชอบ เก็บหลักฐาน และไม่ทำซ้ำชุดคนงาน/guide ที่เพิ่งส่ง
4. เมื่อเสร็จ ทดสอบเฉพาะที่เหมาะสมและเช็ก regression ที่เกี่ยวข้อง push ตามสิทธิ์เดิม แล้วเช็ก Pages และไฟล์เว็บจริงก่อนแจ้งผู้เล่น

เอกสารนี้เป็น handoff ใน repository ไม่ใช่หลักฐานว่า Claude อ่านหรือรับงานแล้ว
