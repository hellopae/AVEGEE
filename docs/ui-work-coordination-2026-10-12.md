# AVEGEE — งานเมนูและการประสานงาน 12 ตุลาคม 2026

## ข้อตกลงจากผู้ใช้

- ปรับเมนู UI ได้ โดยคงธีม สี ลวดลาย และภาพของ AVEGEE
- เน้นเวอร์ชันคอมก่อน มือถือเป็นงานภายหลัง
- โซน 1 ต้องเป็นเมืองผังใหม่ขนาดใหญ่ ไม่ใช่การซูมแผนที่เดิม
- เหลือวิดีโอเฉพาะช่วงเปิดเกมและฉากจบหลังชนะบอสโซน 4
- พัก Break / Boost ไว้ ไม่อยู่ในงานพัฒนาหรือส่งต่อ
- หากต้องวาดปุ่มใหม่ ให้ระบุรายการและขนาดที่ต้องการก่อน
- แบ่งงาน Claude ให้ชัด รายงานผล และป้องกันการแก้ไฟล์ชนกัน

## วิธีส่งต่อและรายงาน

1. ระบุรหัสงาน เป้าหมาย ไฟล์ที่อนุญาตให้แก้ และเกณฑ์ตรวจรับก่อนส่ง
2. ผู้รับตอบรับงานพร้อมรายชื่อไฟล์ก่อนเริ่ม สถานะไม่มีคำตอบรับยังถือว่าไม่ได้รับงาน
3. งานภาพให้ส่งในโฟลเดอร์เฉพาะงานก่อน Codex เป็นผู้เชื่อมเข้าระบบและ catalog
4. รายงานผลเป็น: ทำอะไร / ไฟล์ที่เปลี่ยน / ตรวจอะไรผ่าน / ปัญหาค้าง
5. ก่อนแก้ไฟล์ร่วมตรวจ diff ล่าสุด ห้ามแทนที่ไฟล์ทั้งใบหรือ stage งานทั้งหมด
6. ปิดงานพร้อมหลักฐานตรวจ แล้วจึงส่งมอบไฟล์ให้ชุดถัดไป

สถานะ Claude: บันทึกเก่ามีเพียง `Not logged in · Please run /login` ไม่ใช่หลักฐานรับงานใหม่
เอกสารนี้ยังไม่ได้ส่งเข้า session Claude และไม่ได้ตั้งเวลาส่งอัตโนมัติ

## แผนภาพเมืองรอบถัดไป — หลังรีเซ็ต 12 ต.ค. 20:43 เวลาไทย

เวลานี้ผู้ใช้แจ้ง ยังไม่ได้ตรวจจากระบบโควตา และยังไม่ได้ตั้งงานให้เริ่มอัตโนมัติ
รอบนี้จัดแผนเท่านั้น ยังไม่เปลี่ยนภาพ กล้อง หรือการเดินในเกม

เป้าหมาย: เมืองใหญ่เท่าเดิม แต่ภาพขณะเดินเห็นผนังด้านหน้า อาคารสูง และระยะใกล้–ไกลชัดขึ้น โดยคงสถาปัตยกรรมและสีของ AVEGEE ไม่เพิ่มซูมอย่างเดียว

| ลำดับ | งาน | โมเดลที่เหมาะ | เกณฑ์ตรวจรับ |
|---|---|---|---|
| 1 | ทดลองภาพย่านหอทะเบียนหนึ่งย่าน: มุมมองเฉียงจากด้านหน้า สัดส่วนอาคาร/ตัวละคร และลานต่างระดับ | Sol วางขอบเขต; Astra เฉพาะหากต้องวิเคราะห์การฉายภาพ/เส้นทางใหม่ | ภาพเปรียบเทียบจอ 1280×800 กับภาพเดิม เห็นผนังและความสูงมากขึ้น ตัวละคร/ทางเข้าอ่านง่าย |

| 3 | เชื่อมชั้นภาพกับการเรียงวัตถุ เงา และแสง; เติมเบลอฉากไกลแบบเบา | Sol; Astra หากพบปัญหาระยะหรือการบังซับซ้อน | ตัวละครและพื้นเดินคม เบลอไม่กระทบ UI/ป้าย/ประตู กล้องเคลื่อนแล้วชั้นภาพตรงกัน |

เริ่มจากหนึ่งย่านเพื่อพิสูจน์มุมภาพและคุณภาพก่อนทำภาพทั้งเมือง หากมุมภาพใหม่ทำให้พื้นไม่ตรงพิกัด ต้องแก้ภาพและผังเดินร่วมกัน ไม่ปรับภาพอย่างเดียว
Codex ถือไฟล์ระบบเมือง/กล้องทั้งหมดในรอบนี้ งานภาพภายนอกส่งเข้าโฟลเดอร์ output แยกงานและต้องมีผู้รับยืนยันก่อนเริ่ม จึงยังไม่มีงาน Claude ซ้ำซ้อน
โซน 2–4, ดันเจียนชายแดน และ Break/Boost ยังคงอยู่นอกขอบเขตรอบนี้

- ผู้ใช้อนุญาตออกแบบเมืองใหม่ตามธีมโซน 1 โดยคงลานตัดสินไว้กลางเมือง และเพิ่มอาคาร/ต้นไม้/น้ำตกที่ไม่ใช่สถานีก่อสร้าง
